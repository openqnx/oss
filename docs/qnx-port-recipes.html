Two ways to use this. To reproduce a package, run ./scripts/qnxbuild -a aarch64le <name> — the driver does everything below. The expanded commands are here so you can port something new by copying the closest match, or build one package outside the driver. All of them assume source env.sh <arch> has been run, which sets $STAGE, $QCC_TARGET, $QNX_TRIPLE and $WS.
