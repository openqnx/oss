Getting started -- set up a target, install, test (step by step with two samples: INSTALL.md)

1. A QNX 8.0 target

A stock QEMU image from your QNX SDP 8.0 (how), plus a CA bundle and a few QNX run-time libraries from the SDP:

mkqnximage --type=qemu \
  --arch=x86_64 --data-size=4000 \
  --run=-h
scp cacert.pem root@$T:/data/oss-setup/

2. Install

A. apk (dependencies and signatures handled):

apk add curl qnx-test-curl qnx-port-tests

B. Download the archive from the packages-8.0-<arch> release (names 0-9, a-l) or packages-8.0-<arch>-m-z (m-z); the INDEX of each gives dependencies and SHA-256:

curl -fsSLO $GH/packages-8.0-x86_64-m-z/\
  zstd-1.5.6-r0.tar.gz
gzip -dc zstd-*.tar.gz |
  (cd /data/oss && tar -xf -)

Remove: apk del curl, oss-get remove curl, or by hand with the file list saved at install; every package's page shows all three, with its exact URL and SHA-256.

3. Test

Every package has a test on the target; compare its output with the recorded log on the package's page:

cd /usr/local/bin/qnx-port-tests
./run-on-target.sh test_curl
...
PASS test_curl
passed: 1   failed: 0
