Install and remove

A. apk

Dependencies come along, signatures checked:

apk add abuild
apk add abuild=3.16.0-r1   # this version

apk del abuild   # also drops dependencies nothing else needs

Package: abuild-3.16.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install abuild
oss-get install abuild=3.16.0-r1   # this version

oss-get remove abuild   # its files only

Its dependencies stay installed: openssl, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/abuild-3.16.0-r1.tar.gz (94.3 KiB)
SHA-256
84cda5f66dcb703c6be673c8ad809ac4cc12e0e7d1523391a8de5c7500265eb0
Install first
openssl, zlib (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/abuild-3.16.0-r1.tar.gz
[ "$(openssl dgst -sha256 abuild-3.16.0-r1.tar.gz | sed 's/.*= *//')" = 84cda5f66dcb703c6be673c8ad809ac4cc12e0e7d1523391a8de5c7500265eb0 ] && echo OK || echo BAD
gzip -dc abuild-3.16.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/abuild.list
gzip -dc abuild-3.16.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm abuild-3.16.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/abuild.list
rm var/lib/manual/abuild.list

Its dependencies stay installed: openssl, zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
