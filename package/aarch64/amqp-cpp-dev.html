A. apk

apk add amqp-cpp-dev

apk del amqp-cpp-dev   # also drops dependencies nothing else needs

Package: amqp-cpp-dev-4.3.27-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install amqp-cpp-dev
oss-get install amqp-cpp-dev=4.3.27-r0   # this version

oss-get remove amqp-cpp-dev   # its files only

Its dependencies stay installed: amqp-cpp. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/amqp-cpp-dev-4.3.27-r0.tar.gz
[ "$(openssl dgst -sha256 amqp-cpp-dev-4.3.27-r0.tar.gz | sed 's/.*= *//')" = 3da20af5229c30dbebffe4d3050f570cb6be7cd83e366c16ade8623eeb289e18 ] && echo OK || echo BAD
gzip -dc amqp-cpp-dev-4.3.27-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/amqp-cpp-dev.list
gzip -dc amqp-cpp-dev-4.3.27-r0.tar.gz | (cd /data/oss && tar -xf -) && rm amqp-cpp-dev-4.3.27-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/amqp-cpp-dev.list
rm var/lib/manual/amqp-cpp-dev.list

Its dependencies stay installed: amqp-cpp. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is amqp-cpp). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
