Install and remove

A. apk

Dependencies come along, signatures checked:

apk add appstream-dev
apk add appstream-dev=1.0.6-r0   # this version

apk del appstream-dev   # also drops dependencies nothing else needs

Package: appstream-dev-1.0.6-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install appstream-dev
oss-get install appstream-dev=1.0.6-r0   # this version

oss-get remove appstream-dev   # its files only

Its dependencies stay installed: appstream. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/appstream-dev-1.0.6-r0.tar.gz
[ "$(openssl dgst -sha256 appstream-dev-1.0.6-r0.tar.gz | sed 's/.*= *//')" = 2aeccd96926828f3ca99f8187bf4c84c427e88affc5a95457e0a5bcbd289a5f2 ] && echo OK || echo BAD
gzip -dc appstream-dev-1.0.6-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/appstream-dev.list
gzip -dc appstream-dev-1.0.6-r0.tar.gz | (cd /data/oss && tar -xf -) && rm appstream-dev-1.0.6-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/appstream-dev.list
rm var/lib/manual/appstream-dev.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, xz, libxml2, libxmlb, libyaml, appstream. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is appstream). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
