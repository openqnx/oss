Install and remove

A. apk

Dependencies come along, signatures checked:

apk add appstream
apk add appstream=1.0.6-r0   # this version

apk del appstream   # also drops dependencies nothing else needs

Package: appstream-1.0.6-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install appstream
oss-get install appstream=1.0.6-r0   # this version

oss-get remove appstream   # its files only

Its dependencies stay installed: curl, gettext, glib, libxml2, libxmlb, libyaml, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/appstream-1.0.6-r0.tar.gz (1.4 MiB)
SHA-256
cc30dbbfac3e3f64baaed16497c9b64fba8ea2e039077989549274f61d4d849a
Install first
brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, xz, libxml2, libxmlb, libyaml (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/appstream-1.0.6-r0.tar.gz
[ "$(openssl dgst -sha256 appstream-1.0.6-r0.tar.gz | sed 's/.*= *//')" = cc30dbbfac3e3f64baaed16497c9b64fba8ea2e039077989549274f61d4d849a ] && echo OK || echo BAD
gzip -dc appstream-1.0.6-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/appstream.list
gzip -dc appstream-1.0.6-r0.tar.gz | (cd /data/oss && tar -xf -) && rm appstream-1.0.6-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/appstream.list
rm var/lib/manual/appstream.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, xz, libxml2, libxmlb, libyaml. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
