Install and remove

A. apk

Dependencies come along, signatures checked:

apk add asio-dev
apk add asio-dev=1.30.2-r0   # this version

apk del asio-dev   # also drops dependencies nothing else needs

Package: asio-dev-1.30.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install asio-dev
oss-get install asio-dev=1.30.2-r0   # this version

oss-get remove asio-dev   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/asio-dev-1.30.2-r0.tar.gz (608.4 KiB)
SHA-256
854eb5a9ed913c19052c370a291e6fff88f6bbb8fd569efc66ee71a0be35261b
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/asio-dev-1.30.2-r0.tar.gz
[ "$(openssl dgst -sha256 asio-dev-1.30.2-r0.tar.gz | sed 's/.*= *//')" = 854eb5a9ed913c19052c370a291e6fff88f6bbb8fd569efc66ee71a0be35261b ] && echo OK || echo BAD
gzip -dc asio-dev-1.30.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/asio-dev.list
gzip -dc asio-dev-1.30.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm asio-dev-1.30.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/asio-dev.list
rm var/lib/manual/asio-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
