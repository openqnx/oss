Install and remove

A. apk

Dependencies come along, signatures checked:

apk add at-spi2-core
apk add at-spi2-core=2.54.0-r0   # this version

apk del at-spi2-core   # also drops dependencies nothing else needs

Package: at-spi2-core-2.54.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install at-spi2-core
oss-get install at-spi2-core=2.54.0-r0   # this version

oss-get remove at-spi2-core   # its files only

Its dependencies stay installed: dbus, gettext, glib, libx11, libxi, libxtst. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/at-spi2-core-2.54.0-r0.tar.gz
[ "$(openssl dgst -sha256 at-spi2-core-2.54.0-r0.tar.gz | sed 's/.*= *//')" = d9ea6b130d75109da17c3e30e98b36f209e931ca298308e36ccbeea662895ce4 ] && echo OK || echo BAD
gzip -dc at-spi2-core-2.54.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/at-spi2-core.list
gzip -dc at-spi2-core-2.54.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm at-spi2-core-2.54.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/at-spi2-core.list
rm var/lib/manual/at-spi2-core.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
