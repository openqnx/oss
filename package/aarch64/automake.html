Install and remove

A. apk

Dependencies come along, signatures checked:

apk add automake
apk add automake=1.18-r2   # this version

apk del automake   # also drops dependencies nothing else needs

Package: automake-1.18-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install automake
oss-get install automake=1.18-r2   # this version

oss-get remove automake   # its files only

Its dependencies stay installed: autoconf, perl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/automake-1.18-r2.tar.gz (480.8 KiB)
SHA-256
ebf7648b517d8e72a05e75a40fd2e5f00dcfef55d6033ca123a075614a73a0db
Install first
libiconv, m4, libxcrypt, perl, autoconf (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/automake-1.18-r2.tar.gz
[ "$(openssl dgst -sha256 automake-1.18-r2.tar.gz | sed 's/.*= *//')" = ebf7648b517d8e72a05e75a40fd2e5f00dcfef55d6033ca123a075614a73a0db ] && echo OK || echo BAD
gzip -dc automake-1.18-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/automake.list
gzip -dc automake-1.18-r2.tar.gz | (cd /data/oss && tar -xf -) && rm automake-1.18-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/automake.list
rm var/lib/manual/automake.list

Its dependencies stay installed: libiconv, m4, libxcrypt, perl, autoconf. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
