Install and remove

A. apk

Dependencies come along, signatures checked:

apk add azure-iot-sdk-c-dev
apk add azure-iot-sdk-c-dev=0_git-r0   # this version

apk del azure-iot-sdk-c-dev   # also drops dependencies nothing else needs

Package: azure-iot-sdk-c-dev-0_git-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install azure-iot-sdk-c-dev
oss-get install azure-iot-sdk-c-dev=0_git-r0   # this version

oss-get remove azure-iot-sdk-c-dev   # its files only

Its dependencies stay installed: azure-iot-sdk-c. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/azure-iot-sdk-c-dev-0_git-r0.tar.gz (1.1 MiB)
SHA-256
9f8db684cdfce55128ca6d8fa0cc63067b1f89d36cf10db0d8e11f0f403fd677
Install first
brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, azure-iot-sdk-c (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/azure-iot-sdk-c-dev-0_git-r0.tar.gz
[ "$(openssl dgst -sha256 azure-iot-sdk-c-dev-0_git-r0.tar.gz | sed 's/.*= *//')" = 9f8db684cdfce55128ca6d8fa0cc63067b1f89d36cf10db0d8e11f0f403fd677 ] && echo OK || echo BAD
gzip -dc azure-iot-sdk-c-dev-0_git-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/azure-iot-sdk-c-dev.list
gzip -dc azure-iot-sdk-c-dev-0_git-r0.tar.gz | (cd /data/oss && tar -xf -) && rm azure-iot-sdk-c-dev-0_git-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/azure-iot-sdk-c-dev.list
rm var/lib/manual/azure-iot-sdk-c-dev.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, azure-iot-sdk-c. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is azure-iot-sdk-c). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
