Install and remove

A. apk

Dependencies come along, signatures checked:

apk add bison
apk add bison=3.8.2-r0   # this version

apk del bison   # also drops dependencies nothing else needs

Package: bison-3.8.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install bison
oss-get install bison=3.8.2-r0   # this version

oss-get remove bison   # its files only

Its dependencies stay installed: m4. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/bison-3.8.2-r0.tar.gz (473.4 KiB)
SHA-256
2e536bc3d8c9470e17f6c16584c4da6c87d9020c28a9e2b8e5c031058252d059
Install first
libiconv, m4 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/bison-3.8.2-r0.tar.gz
[ "$(openssl dgst -sha256 bison-3.8.2-r0.tar.gz | sed 's/.*= *//')" = 2e536bc3d8c9470e17f6c16584c4da6c87d9020c28a9e2b8e5c031058252d059 ] && echo OK || echo BAD
gzip -dc bison-3.8.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/bison.list
gzip -dc bison-3.8.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm bison-3.8.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/bison.list
rm var/lib/manual/bison.list

Its dependencies stay installed: libiconv, m4. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
