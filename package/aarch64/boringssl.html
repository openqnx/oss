Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/boringssl-0.20260929.0-r0.tar.gz
[ "$(openssl dgst -sha256 boringssl-0.20260929.0-r0.tar.gz | sed 's/.*= *//')" = 00c309a72ff933f1b3ca3be6f306cc4f4f54bc709b5479af43486a95a2c2d9ee ] && echo OK || echo BAD
gzip -dc boringssl-0.20260929.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/boringssl.list
gzip -dc boringssl-0.20260929.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm boringssl-0.20260929.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/boringssl.list
rm var/lib/manual/boringssl.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
