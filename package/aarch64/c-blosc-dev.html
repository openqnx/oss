Install and remove

A. apk

Dependencies come along, signatures checked:

apk add c-blosc-dev
apk add c-blosc-dev=1.21.6-r0   # this version

apk del c-blosc-dev   # also drops dependencies nothing else needs

Package: c-blosc-dev-1.21.6-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install c-blosc-dev
oss-get install c-blosc-dev=1.21.6-r0   # this version

oss-get remove c-blosc-dev   # its files only

Its dependencies stay installed: c-blosc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

SHA-256

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/c-blosc-dev-1.21.6-r0.tar.gz
[ "$(openssl dgst -sha256 c-blosc-dev-1.21.6-r0.tar.gz | sed 's/.*= *//')" = 0e84bf455f334da99080b37be8e218fe7eca69747bda524f0dd1c86a68cffe9b ] && echo OK || echo BAD
gzip -dc c-blosc-dev-1.21.6-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/c-blosc-dev.list
gzip -dc c-blosc-dev-1.21.6-r0.tar.gz | (cd /data/oss && tar -xf -) && rm c-blosc-dev-1.21.6-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/c-blosc-dev.list
rm var/lib/manual/c-blosc-dev.list

Its dependencies stay installed: lz4, zlib, zstd, c-blosc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is c-blosc). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
