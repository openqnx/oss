Package: canopennode-4.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install canopennode
oss-get install canopennode=4.0-r0   # this version

oss-get remove canopennode   # its files only

Its dependencies stay installed: qnx-socketcan. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/canopennode-4.0-r0.tar.gz (298.6 KiB)
SHA-256
4304bf9c333cbd5e9ca7714b38a6efad05d7185168111205712fba71d8b271ff
Install first
qnx-socketcan (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/canopennode-4.0-r0.tar.gz
[ "$(openssl dgst -sha256 canopennode-4.0-r0.tar.gz | sed 's/.*= *//')" = 4304bf9c333cbd5e9ca7714b38a6efad05d7185168111205712fba71d8b271ff ] && echo OK || echo BAD
gzip -dc canopennode-4.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/canopennode.list
gzip -dc canopennode-4.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm canopennode-4.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/canopennode.list
rm var/lib/manual/canopennode.list

Its dependencies stay installed: qnx-socketcan. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
