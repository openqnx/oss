Install and remove

A. apk

Dependencies come along, signatures checked:

apk add cartographer
apk add cartographer=2.0.0-r1   # this version

apk del cartographer   # also drops dependencies nothing else needs

Package: cartographer-2.0.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install cartographer
oss-get install cartographer=2.0.0-r1   # this version

oss-get remove cartographer   # its files only

Its dependencies stay installed: abseil, boost, cairo, ceres-solver, gflags, glog, lua5.3, protobuf. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Install first
abseil, bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, expat, brotli, libpng, freetype, fontconfig, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, gflags, glog, ceres-solver, lua5.3, protobuf (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/cartographer-2.0.0-r1.tar.gz
[ "$(openssl dgst -sha256 cartographer-2.0.0-r1.tar.gz | sed 's/.*= *//')" = 19453829519411d8960fb357150ba9418504f14a9619103594357fc2cbefa349 ] && echo OK || echo BAD
gzip -dc cartographer-2.0.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/cartographer.list
gzip -dc cartographer-2.0.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm cartographer-2.0.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/cartographer.list
rm var/lib/manual/cartographer.list

Its dependencies stay installed: abseil, bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, expat, brotli, libpng, freetype, fontconfig, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, gflags, glog, ceres-solver, lua5.3, protobuf. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
