A. apk

Package: cereal-dev-1.3.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install cereal-dev
oss-get install cereal-dev=1.3.2-r0   # this version

oss-get remove cereal-dev   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/cereal-dev-1.3.2-r0.tar.gz
[ "$(openssl dgst -sha256 cereal-dev-1.3.2-r0.tar.gz | sed 's/.*= *//')" = 5b94e7641530464f9a380751dc3e2077b0278cb6b5859db93b742cc32fc06e65 ] && echo OK || echo BAD
gzip -dc cereal-dev-1.3.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/cereal-dev.list
gzip -dc cereal-dev-1.3.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm cereal-dev-1.3.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/cereal-dev.list
rm var/lib/manual/cereal-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
