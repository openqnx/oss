Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/computelibrary-53.0.0-r1.tar.gz
[ "$(openssl dgst -sha256 computelibrary-53.0.0-r1.tar.gz | sed 's/.*= *//')" = b2d0f3e1eec465cf3f33e1e971c8623f89a944b913757fc63176327835307e56 ] && echo OK || echo BAD
gzip -dc computelibrary-53.0.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/computelibrary.list
gzip -dc computelibrary-53.0.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm computelibrary-53.0.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/computelibrary.list
rm var/lib/manual/computelibrary.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
