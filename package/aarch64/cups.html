Install and remove

A. apk

Dependencies come along, signatures checked:

apk add cups
apk add cups=2.4.16-r0   # this version

apk del cups   # also drops dependencies nothing else needs

Package: cups-2.4.16-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install cups
oss-get install cups=2.4.16-r0   # this version

oss-get remove cups   # its files only

Its dependencies stay installed: avahi, libiconv, libxcrypt, openssl, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/cups-2.4.16-r0.tar.gz (7.7 MiB)
SHA-256
9c562a252ad8997b5954e74f422b7a8333e61bea690ea0bd55bc5b4f799cc663
Install first
expat, dbus, libdaemon, avahi, libiconv, libxcrypt, openssl, zlib (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/cups-2.4.16-r0.tar.gz
[ "$(openssl dgst -sha256 cups-2.4.16-r0.tar.gz | sed 's/.*= *//')" = 9c562a252ad8997b5954e74f422b7a8333e61bea690ea0bd55bc5b4f799cc663 ] && echo OK || echo BAD
gzip -dc cups-2.4.16-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/cups.list
gzip -dc cups-2.4.16-r0.tar.gz | (cd /data/oss && tar -xf -) && rm cups-2.4.16-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/cups.list
rm var/lib/manual/cups.list

Its dependencies stay installed: expat, dbus, libdaemon, avahi, libiconv, libxcrypt, openssl, zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
