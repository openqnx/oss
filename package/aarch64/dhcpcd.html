Install and remove

A. apk

Dependencies come along, signatures checked:

apk add dhcpcd
apk add dhcpcd=10.5.2-r0   # this version

apk del dhcpcd   # also drops dependencies nothing else needs

Package: dhcpcd-10.5.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install dhcpcd
oss-get install dhcpcd=10.5.2-r0   # this version

oss-get remove dhcpcd   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/dhcpcd-10.5.2-r0.tar.gz (174.5 KiB)
SHA-256

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/dhcpcd-10.5.2-r0.tar.gz
[ "$(openssl dgst -sha256 dhcpcd-10.5.2-r0.tar.gz | sed 's/.*= *//')" = 172d125435a62130f2edfc8ae0d2f61757315aec8553ef8310de0d5460398ea4 ] && echo OK || echo BAD
gzip -dc dhcpcd-10.5.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/dhcpcd.list
gzip -dc dhcpcd-10.5.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm dhcpcd-10.5.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/dhcpcd.list
rm var/lib/manual/dhcpcd.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
