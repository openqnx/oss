Install and remove

A. apk

Dependencies come along, signatures checked:

apk add docbook-xsl
apk add docbook-xsl=1.79.2-r0   # this version

apk del docbook-xsl   # also drops dependencies nothing else needs

Package: docbook-xsl-1.79.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install docbook-xsl
oss-get install docbook-xsl=1.79.2-r0   # this version

oss-get remove docbook-xsl   # its files only

Its dependencies stay installed: libxslt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/docbook-xsl-1.79.2-r0.tar.gz
[ "$(openssl dgst -sha256 docbook-xsl-1.79.2-r0.tar.gz | sed 's/.*= *//')" = e2994ef2dec42c8cc52c08e2f6d67a9905029bff569260743c79f8f971ffaa31 ] && echo OK || echo BAD
gzip -dc docbook-xsl-1.79.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/docbook-xsl.list
gzip -dc docbook-xsl-1.79.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm docbook-xsl-1.79.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/docbook-xsl.list
rm var/lib/manual/docbook-xsl.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
