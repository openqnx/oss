B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install emulationstation
oss-get install emulationstation=2.11_git20241212-r2   # this version

oss-get remove emulationstation   # its files only

Its dependencies stay installed: curl, freeimage, freetype, pugixml, sdl2, vlc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

SHA-256

Install first
brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, freeimage, bzip2, libpng, freetype, pugixml, libiconv, sdl2, lz4, libunistring, ncurses, gettext, xz, vlc (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/emulationstation-2.11_git20241212-r2.tar.gz
[ "$(openssl dgst -sha256 emulationstation-2.11_git20241212-r2.tar.gz | sed 's/.*= *//')" = 5d11e38441f189cc1e1adc4b045b12b7976659aa657bacd92636371aabcfe646 ] && echo OK || echo BAD
gzip -dc emulationstation-2.11_git20241212-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/emulationstation.list
gzip -dc emulationstation-2.11_git20241212-r2.tar.gz | (cd /data/oss && tar -xf -) && rm emulationstation-2.11_git20241212-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/emulationstation.list
rm var/lib/manual/emulationstation.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, freeimage, bzip2, libpng, freetype, pugixml, libiconv, sdl2, lz4, libunistring, ncurses, gettext, xz, vlc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
