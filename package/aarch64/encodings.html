Install and remove

A. apk

Dependencies come along, signatures checked:

apk add encodings
apk add encodings=1.1.0-r0   # this version

apk del encodings   # also drops dependencies nothing else needs

Package: encodings-1.1.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install encodings
oss-get install encodings=1.1.0-r0   # this version

oss-get remove encodings   # its files only

B-2. By hand

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/encodings-1.1.0-r0.tar.gz
[ "$(openssl dgst -sha256 encodings-1.1.0-r0.tar.gz | sed 's/.*= *//')" = 5b055b69efa3038e1c098fef864d9a769d107443733690d473c51755f2459c13 ] && echo OK || echo BAD
gzip -dc encodings-1.1.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/encodings.list
gzip -dc encodings-1.1.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm encodings-1.1.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/encodings.list
rm var/lib/manual/encodings.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
