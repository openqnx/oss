Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ensmallen-dev
apk add ensmallen-dev=3.11.1-r1   # this version

apk del ensmallen-dev   # also drops dependencies nothing else needs

Package: ensmallen-dev-3.11.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ensmallen-dev
oss-get install ensmallen-dev=3.11.1-r1   # this version

oss-get remove ensmallen-dev   # its files only

Its dependencies stay installed: armadillo-dev. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/ensmallen-dev-3.11.1-r1.tar.gz (258.8 KiB)
SHA-256
db7849a2f1835d75b23ed26034b01fe437219c4a06ccc92116d8c7a2a3c72e99
Install first
openblas, armadillo, armadillo-dev (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/ensmallen-dev-3.11.1-r1.tar.gz
[ "$(openssl dgst -sha256 ensmallen-dev-3.11.1-r1.tar.gz | sed 's/.*= *//')" = db7849a2f1835d75b23ed26034b01fe437219c4a06ccc92116d8c7a2a3c72e99 ] && echo OK || echo BAD
gzip -dc ensmallen-dev-3.11.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ensmallen-dev.list
gzip -dc ensmallen-dev-3.11.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm ensmallen-dev-3.11.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ensmallen-dev.list
rm var/lib/manual/ensmallen-dev.list

Its dependencies stay installed: openblas, armadillo, armadillo-dev. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
