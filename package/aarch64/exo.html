Install and remove

A. apk

Dependencies come along, signatures checked:

apk add exo
apk add exo=4.20.0-r0   # this version

apk del exo   # also drops dependencies nothing else needs

Package: exo-4.20.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install exo
oss-get install exo=4.20.0-r0   # this version

oss-get remove exo   # its files only

Its dependencies stay installed: at-spi2-core, cairo, gdk-pixbuf, gettext, glib, gtk3, harfbuzz, libxfce4ui, libxfce4util, pango, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/exo-4.20.0-r0.tar.gz
[ "$(openssl dgst -sha256 exo-4.20.0-r0.tar.gz | sed 's/.*= *//')" = a2eda77183e925dc22ddd3898c265fcff7f704f1d10269cfb2dc0323ee0829a8 ] && echo OK || echo BAD
gzip -dc exo-4.20.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/exo.list
gzip -dc exo-4.20.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm exo-4.20.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/exo.list
rm var/lib/manual/exo.list
