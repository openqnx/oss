Install and remove

A. apk

Dependencies come along, signatures checked:

apk add fastdds-dev
apk add fastdds-dev=2.14.4-r0   # this version

apk del fastdds-dev   # also drops dependencies nothing else needs

Package: fastdds-dev-2.14.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install fastdds-dev
oss-get install fastdds-dev=2.14.4-r0   # this version

oss-get remove fastdds-dev   # its files only

Its dependencies stay installed: fastdds. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/fastdds-dev-2.14.4-r0.tar.gz (371.0 KiB)
SHA-256
e28f9a89658a6c2c84d673ca24d8445059433dd34de03932fbde193c7fcea64a
Install first
fastcdr, foonathan_memory, openssl, tinyxml2, fastdds (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/fastdds-dev-2.14.4-r0.tar.gz
[ "$(openssl dgst -sha256 fastdds-dev-2.14.4-r0.tar.gz | sed 's/.*= *//')" = e28f9a89658a6c2c84d673ca24d8445059433dd34de03932fbde193c7fcea64a ] && echo OK || echo BAD
gzip -dc fastdds-dev-2.14.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/fastdds-dev.list
gzip -dc fastdds-dev-2.14.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm fastdds-dev-2.14.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/fastdds-dev.list
rm var/lib/manual/fastdds-dev.list

Its dependencies stay installed: fastcdr, foonathan_memory, openssl, tinyxml2, fastdds. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is fastdds). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
