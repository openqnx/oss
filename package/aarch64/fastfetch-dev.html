Install and remove

A. apk

Dependencies come along, signatures checked:

apk add fastfetch-dev
apk add fastfetch-dev=2.66.1-r0   # this version

apk del fastfetch-dev   # also drops dependencies nothing else needs

Package: fastfetch-dev-2.66.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install fastfetch-dev
oss-get install fastfetch-dev=2.66.1-r0   # this version

oss-get remove fastfetch-dev   # its files only

Its dependencies stay installed: fastfetch. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256

Install first

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/fastfetch-dev-2.66.1-r0.tar.gz
[ "$(openssl dgst -sha256 fastfetch-dev-2.66.1-r0.tar.gz | sed 's/.*= *//')" = 7f5724ed6fe0af6a1d84084dda8bd5358b06542fc4d812c5e8d9f4c40fd60420 ] && echo OK || echo BAD
gzip -dc fastfetch-dev-2.66.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/fastfetch-dev.list
gzip -dc fastfetch-dev-2.66.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm fastfetch-dev-2.66.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/fastfetch-dev.list
rm var/lib/manual/fastfetch-dev.list

Its dependencies stay installed: fastfetch. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is fastfetch). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
