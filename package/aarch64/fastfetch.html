Install and remove

A. apk

Dependencies come along, signatures checked:

apk add fastfetch
apk add fastfetch=2.66.1-r0   # this version

apk del fastfetch   # also drops dependencies nothing else needs

Package: fastfetch-2.66.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install fastfetch
oss-get install fastfetch=2.66.1-r0   # this version

oss-get remove fastfetch   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/fastfetch-2.66.1-r0.tar.gz
[ "$(openssl dgst -sha256 fastfetch-2.66.1-r0.tar.gz | sed 's/.*= *//')" = a2eafed91a2c9232d00f68b2394c90a0cc6e4d394605897d902c300a14817410 ] && echo OK || echo BAD
gzip -dc fastfetch-2.66.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/fastfetch.list
gzip -dc fastfetch-2.66.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm fastfetch-2.66.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/fastfetch.list
rm var/lib/manual/fastfetch.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
