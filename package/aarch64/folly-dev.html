Install and remove

A. apk

apk add folly-dev

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install folly-dev
oss-get install folly-dev=2026.10.26.00-r1   # this version

oss-get remove folly-dev   # its files only

Its dependencies stay installed: folly. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Remove: delete exactly the files it installed, then the list:

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, fmt, gflags, glog, openssl, libevent, libsodium, lz4, zstd, folly. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is folly).
