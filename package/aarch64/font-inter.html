Install and remove

A. apk

Dependencies come along, signatures checked:

apk add font-inter
apk add font-inter=4.1-r0   # this version

apk del font-inter   # also drops dependencies nothing else needs

Package: font-inter-4.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install font-inter
oss-get install font-inter=4.1-r0   # this version

oss-get remove font-inter   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/font-inter-4.1-r0.tar.gz (8.4 MiB)
SHA-256
fc766fa030dd46bad19a7e3ab8936306fbb0d52701fdb778aeb1cd880e473122
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/font-inter-4.1-r0.tar.gz
[ "$(openssl dgst -sha256 font-inter-4.1-r0.tar.gz | sed 's/.*= *//')" = fc766fa030dd46bad19a7e3ab8936306fbb0d52701fdb778aeb1cd880e473122 ] && echo OK || echo BAD
gzip -dc font-inter-4.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/font-inter.list
gzip -dc font-inter-4.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm font-inter-4.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/font-inter.list
rm var/lib/manual/font-inter.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
