Install and remove

A. apk

Dependencies come along, signatures checked:

apk add g3log
apk add g3log=2.4-r1   # this version

apk del g3log   # also drops dependencies nothing else needs

Package: g3log-2.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install g3log
oss-get install g3log=2.4-r1   # this version

oss-get remove g3log   # its files only

B-2. By hand

Archive

SHA-256
ec60c5bfb7dd5760905631ddaf9de3aebde5f3d389d823b25ac52981521e3e92
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/g3log-2.4-r1.tar.gz
[ "$(openssl dgst -sha256 g3log-2.4-r1.tar.gz | sed 's/.*= *//')" = ec60c5bfb7dd5760905631ddaf9de3aebde5f3d389d823b25ac52981521e3e92 ] && echo OK || echo BAD
gzip -dc g3log-2.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/g3log.list
gzip -dc g3log-2.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm g3log-2.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/g3log.list
rm var/lib/manual/g3log.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
