Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gawk-dev
apk add gawk-dev=5.3.2-r0   # this version

apk del gawk-dev   # also drops dependencies nothing else needs

Package: gawk-dev-5.3.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gawk-dev
oss-get install gawk-dev=5.3.2-r0   # this version

oss-get remove gawk-dev   # its files only

Its dependencies stay installed: gawk. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gawk-dev-5.3.2-r0.tar.gz (758.4 KiB)
SHA-256
e3b34a0b26dc66fdde294b7b89af8e3f2ba35173f509628f54cf406f4913fc39
Install first
ncurses, readline, gawk (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gawk-dev-5.3.2-r0.tar.gz
[ "$(openssl dgst -sha256 gawk-dev-5.3.2-r0.tar.gz | sed 's/.*= *//')" = e3b34a0b26dc66fdde294b7b89af8e3f2ba35173f509628f54cf406f4913fc39 ] && echo OK || echo BAD
gzip -dc gawk-dev-5.3.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gawk-dev.list
gzip -dc gawk-dev-5.3.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gawk-dev-5.3.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gawk-dev.list
rm var/lib/manual/gawk-dev.list

Its dependencies stay installed: ncurses, readline, gawk. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gawk). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
