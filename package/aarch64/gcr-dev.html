Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gcr-dev
apk add gcr-dev=3.41.2-r0   # this version

apk del gcr-dev   # also drops dependencies nothing else needs

Package: gcr-dev-3.41.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gcr-dev
oss-get install gcr-dev=3.41.2-r0   # this version

oss-get remove gcr-dev   # its files only

Its dependencies stay installed: gcr. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

gzip -dc gcr-dev-3.41.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gcr-dev.list
gzip -dc gcr-dev-3.41.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gcr-dev-3.41.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gcr-dev.list
rm var/lib/manual/gcr-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gcr). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
