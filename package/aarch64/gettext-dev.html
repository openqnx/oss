B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gettext-dev
oss-get install gettext-dev=0.22.5-r0   # this version

oss-get remove gettext-dev   # its files only

Its dependencies stay installed: gettext. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gettext-dev-0.22.5-r0.tar.gz
[ "$(openssl dgst -sha256 gettext-dev-0.22.5-r0.tar.gz | sed 's/.*= *//')" = d99d7b77b9f33bb2c555d8117decc4e6f04b72f4b33e0d931d0153f6df0805ea ] && echo OK || echo BAD
gzip -dc gettext-dev-0.22.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gettext-dev.list
gzip -dc gettext-dev-0.22.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gettext-dev-0.22.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gettext-dev.list
rm var/lib/manual/gettext-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gettext). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
