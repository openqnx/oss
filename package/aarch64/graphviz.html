Install and remove

A. apk

Dependencies come along, signatures checked:

apk add graphviz
apk add graphviz=13.1.2-r0   # this version

apk del graphviz   # also drops dependencies nothing else needs

Package: graphviz-13.1.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install graphviz
oss-get install graphviz=13.1.2-r0   # this version

oss-get remove graphviz   # its files only

Its dependencies stay installed: cairo, expat, gd, gettext, glib, harfbuzz, libtool, libwebp, libx11, libxrender, pango, poppler, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/graphviz-13.1.2-r0.tar.gz
[ "$(openssl dgst -sha256 graphviz-13.1.2-r0.tar.gz | sed 's/.*= *//')" = 6f0751dfaed885754b283b9bd4d553179169d753ee53e8676546b23b2bfd60d1 ] && echo OK || echo BAD
gzip -dc graphviz-13.1.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/graphviz.list
gzip -dc graphviz-13.1.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm graphviz-13.1.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/graphviz.list
rm var/lib/manual/graphviz.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, aom, dav1d, libavif, libde265, libjpeg-turbo, libwebp, xz, zstd, libtiff, openh264, openjpeg, openjph, x265, libheif, gd, graphite2, icu, harfbuzz, libtool, fribidi, libxft, pango, lcms2, poppler. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
