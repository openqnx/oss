Install and remove

A. apk

Dependencies come along, signatures checked:

apk add groff-dev
apk add groff-dev=1.23.0-r0   # this version

apk del groff-dev   # also drops dependencies nothing else needs

Package: groff-dev-1.23.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install groff-dev
oss-get install groff-dev=1.23.0-r0   # this version

oss-get remove groff-dev   # its files only

Its dependencies stay installed: groff. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/groff-dev-1.23.0-r0.tar.gz (9.3 MiB)
SHA-256
8e7d02eb07ee78a693214bf7bbbce0e5b93f223d43ce32f4ab205fd5bab8405d
Install first
libiconv, groff (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/groff-dev-1.23.0-r0.tar.gz
[ "$(openssl dgst -sha256 groff-dev-1.23.0-r0.tar.gz | sed 's/.*= *//')" = 8e7d02eb07ee78a693214bf7bbbce0e5b93f223d43ce32f4ab205fd5bab8405d ] && echo OK || echo BAD
gzip -dc groff-dev-1.23.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/groff-dev.list
gzip -dc groff-dev-1.23.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm groff-dev-1.23.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/groff-dev.list
rm var/lib/manual/groff-dev.list

Its dependencies stay installed: libiconv, groff. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is groff). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
