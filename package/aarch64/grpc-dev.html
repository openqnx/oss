Install and remove

A. apk

Dependencies come along, signatures checked:

apk add grpc-dev
apk add grpc-dev=1.69.0-r1   # this version

apk del grpc-dev   # also drops dependencies nothing else needs

Package: grpc-dev-1.69.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install grpc-dev
oss-get install grpc-dev=1.69.0-r1   # this version

oss-get remove grpc-dev   # its files only

Its dependencies stay installed: grpc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/grpc-dev-1.69.0-r1.tar.gz (216.6 KiB)
SHA-256
6a6b0e81d0e9302c20a0ca5da97e86a1c992c60e38b724971c68a3cd41627d8e
Install first
abseil, c-ares, openssl, zlib, protobuf, re2, grpc (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/grpc-dev-1.69.0-r1.tar.gz
[ "$(openssl dgst -sha256 grpc-dev-1.69.0-r1.tar.gz | sed 's/.*= *//')" = 6a6b0e81d0e9302c20a0ca5da97e86a1c992c60e38b724971c68a3cd41627d8e ] && echo OK || echo BAD
gzip -dc grpc-dev-1.69.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/grpc-dev.list
gzip -dc grpc-dev-1.69.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm grpc-dev-1.69.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/grpc-dev.list
rm var/lib/manual/grpc-dev.list

Its dependencies stay installed: abseil, c-ares, openssl, zlib, protobuf, re2, grpc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is grpc). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
