Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gsettings-desktop-schemas-49.0-r0.tar.gz
[ "$(openssl dgst -sha256 gsettings-desktop-schemas-49.0-r0.tar.gz | sed 's/.*= *//')" = 58f2e07f8a02797419fa3cfba1fa1f543a855eee49cd394ab5efdc4a95f2ef1e ] && echo OK || echo BAD
gzip -dc gsettings-desktop-schemas-49.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gsettings-desktop-schemas.list
gzip -dc gsettings-desktop-schemas-49.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gsettings-desktop-schemas-49.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gsettings-desktop-schemas.list
rm var/lib/manual/gsettings-desktop-schemas.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
