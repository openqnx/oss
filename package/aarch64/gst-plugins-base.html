Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gst-plugins-base
apk add gst-plugins-base=1.24.10-r1   # this version

apk del gst-plugins-base   # also drops dependencies nothing else needs

Package: gst-plugins-base-1.24.10-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gst-plugins-base
oss-get install gst-plugins-base=1.24.10-r1   # this version

oss-get remove gst-plugins-base   # its files only

Its dependencies stay installed: gettext, glib, gstreamer, libogg, libtheora, libvorbis, opus, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gst-plugins-base-1.24.10-r1.tar.gz (2.4 MiB)
SHA-256
f4ef703c76d747bac30ae1935f9698e70c1a95470ebe3adc1c2ffa9c060a130b
Install first
libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, gstreamer, libogg, libtheora, libvorbis, opus (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gst-plugins-base-1.24.10-r1.tar.gz
[ "$(openssl dgst -sha256 gst-plugins-base-1.24.10-r1.tar.gz | sed 's/.*= *//')" = f4ef703c76d747bac30ae1935f9698e70c1a95470ebe3adc1c2ffa9c060a130b ] && echo OK || echo BAD
gzip -dc gst-plugins-base-1.24.10-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gst-plugins-base.list
gzip -dc gst-plugins-base-1.24.10-r1.tar.gz | (cd /data/oss && tar -xf -) && rm gst-plugins-base-1.24.10-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gst-plugins-base.list
rm var/lib/manual/gst-plugins-base.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, gstreamer, libogg, libtheora, libvorbis, opus. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
