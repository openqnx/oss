B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gst-plugins-good-dev
oss-get install gst-plugins-good-dev=1.24.10-r0   # this version

oss-get remove gst-plugins-good-dev   # its files only

Its dependencies stay installed: gst-plugins-good. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

gzip -dc gst-plugins-good-dev-1.24.10-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gst-plugins-good-dev.list
gzip -dc gst-plugins-good-dev-1.24.10-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gst-plugins-good-dev-1.24.10-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gst-plugins-good-dev.list
rm var/lib/manual/gst-plugins-good-dev.list

Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gst-plugins-good). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
