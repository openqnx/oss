Package: gtk-layer-shell-dev-0.9.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gtk-layer-shell-dev
oss-get install gtk-layer-shell-dev=0.9.0-r0   # this version

oss-get remove gtk-layer-shell-dev   # its files only

Its dependencies stay installed: gtk-layer-shell. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gtk-layer-shell-dev-0.9.0-r0.tar.gz
[ "$(openssl dgst -sha256 gtk-layer-shell-dev-0.9.0-r0.tar.gz | sed 's/.*= *//')" = c5a95f630befe21488bb0cc12eb1022f53398241170b7a58eb6abcf6d477a983 ] && echo OK || echo BAD
gzip -dc gtk-layer-shell-dev-0.9.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gtk-layer-shell-dev.list
gzip -dc gtk-layer-shell-dev-0.9.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gtk-layer-shell-dev-0.9.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gtk-layer-shell-dev.list
rm var/lib/manual/gtk-layer-shell-dev.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, dbus, libxi, libxtst, at-spi2-core, fribidi, libjpeg-turbo, gdk-pixbuf, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, gtk-layer-shell. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gtk-layer-shell). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
