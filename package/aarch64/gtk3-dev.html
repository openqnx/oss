Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gtk3-dev
apk add gtk3-dev=3.24.43-r1   # this version

apk del gtk3-dev   # also drops dependencies nothing else needs

Package: gtk3-dev-3.24.43-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gtk3-dev
oss-get install gtk3-dev=3.24.43-r1   # this version

oss-get remove gtk3-dev   # its files only

Its dependencies stay installed: gtk3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/gtk3-dev-3.24.43-r1.tar.gz
[ "$(openssl dgst -sha256 gtk3-dev-3.24.43-r1.tar.gz | sed 's/.*= *//')" = b9992e77638b6254149ecb9fb1989a0cae81863e4b32edea9fbbf77b43e1bb2f ] && echo OK || echo BAD
gzip -dc gtk3-dev-3.24.43-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gtk3-dev.list
gzip -dc gtk3-dev-3.24.43-r1.tar.gz | (cd /data/oss && tar -xf -) && rm gtk3-dev-3.24.43-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gtk3-dev.list
rm var/lib/manual/gtk3-dev.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, fribidi, libjpeg-turbo, gdk-pixbuf, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gtk3). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
