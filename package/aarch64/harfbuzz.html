Install and remove

A. apk

Dependencies come along, signatures checked:

apk add harfbuzz
apk add harfbuzz=10.1.0-r0   # this version

apk del harfbuzz   # also drops dependencies nothing else needs

Package: harfbuzz-10.1.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install harfbuzz
oss-get install harfbuzz=10.1.0-r0   # this version

oss-get remove harfbuzz   # its files only

Its dependencies stay installed: freetype, glib, graphite2, icu. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256
1ee8c318050594c780d3f563dd31c5539ec2f2da60d15c83df8e94c08cafdad9
Install first
brotli, bzip2, zlib, libpng, freetype, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, graphite2, icu (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/harfbuzz-10.1.0-r0.tar.gz
[ "$(openssl dgst -sha256 harfbuzz-10.1.0-r0.tar.gz | sed 's/.*= *//')" = 1ee8c318050594c780d3f563dd31c5539ec2f2da60d15c83df8e94c08cafdad9 ] && echo OK || echo BAD
gzip -dc harfbuzz-10.1.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/harfbuzz.list
gzip -dc harfbuzz-10.1.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm harfbuzz-10.1.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/harfbuzz.list
rm var/lib/manual/harfbuzz.list

Its dependencies stay installed: brotli, bzip2, zlib, libpng, freetype, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, graphite2, icu. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
