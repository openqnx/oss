Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/highwayhash-dev-0_git20240418-r0.tar.gz
[ "$(openssl dgst -sha256 highwayhash-dev-0_git20240418-r0.tar.gz | sed 's/.*= *//')" = c1b4995c423b0d7ab7f2ac7c17fa7f47781283b943b4ba8619c7f19f4382697d ] && echo OK || echo BAD
gzip -dc highwayhash-dev-0_git20240418-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/highwayhash-dev.list
gzip -dc highwayhash-dev-0_git20240418-r0.tar.gz | (cd /data/oss && tar -xf -) && rm highwayhash-dev-0_git20240418-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/highwayhash-dev.list
rm var/lib/manual/highwayhash-dev.list

Its dependencies stay installed: highwayhash. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is highwayhash). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
