Install and remove

A. apk

Dependencies come along, signatures checked:

apk add icu-dev
apk add icu-dev=76.1-r0   # this version

apk del icu-dev   # also drops dependencies nothing else needs

Package: icu-dev-76.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install icu-dev
oss-get install icu-dev=76.1-r0   # this version

oss-get remove icu-dev   # its files only

Its dependencies stay installed: icu. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/icu-dev-76.1-r0.tar.gz
[ "$(openssl dgst -sha256 icu-dev-76.1-r0.tar.gz | sed 's/.*= *//')" = aaab0a960550e044faece65d1ecab7bdb65af0bea861c4d460f3c3f742d3eb36 ] && echo OK || echo BAD
gzip -dc icu-dev-76.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/icu-dev.list
gzip -dc icu-dev-76.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm icu-dev-76.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/icu-dev.list
rm var/lib/manual/icu-dev.list

Its dependencies stay installed: icu. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is icu). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
