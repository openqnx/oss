Install and remove

A. apk

Dependencies come along, signatures checked:

apk add iso-codes
apk add iso-codes=4.17.0-r0   # this version

apk del iso-codes   # also drops dependencies nothing else needs

Package: iso-codes-4.17.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install iso-codes
oss-get install iso-codes=4.17.0-r0   # this version

oss-get remove iso-codes   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/iso-codes-4.17.0-r0.tar.gz
[ "$(openssl dgst -sha256 iso-codes-4.17.0-r0.tar.gz | sed 's/.*= *//')" = 82657a909af57d69f9e65f160f89f3d2da5303642cf6563a85b05bce7a73ec41 ] && echo OK || echo BAD
gzip -dc iso-codes-4.17.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/iso-codes.list
gzip -dc iso-codes-4.17.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm iso-codes-4.17.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/iso-codes.list
rm var/lib/manual/iso-codes.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
