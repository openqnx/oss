Install and remove

A. apk

Dependencies come along, signatures checked:

apk add labwc
apk add labwc=0.20.2-r1   # this version

apk del labwc   # also drops dependencies nothing else needs

Package: labwc-0.20.2-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install labwc
oss-get install labwc=0.20.2-r1   # this version

oss-get remove labwc   # its files only

Its dependencies stay installed: cairo, font-dejavu, glib, libpng, libsfdo, libxkbcommon, libxml2, pango, pixman, wayland, wlroots, xkeyboard-config. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/labwc-0.20.2-r1.tar.gz
[ "$(openssl dgst -sha256 labwc-0.20.2-r1.tar.gz | sed 's/.*= *//')" = 873403d24faaa1d189205776bd9ec024ab1af6c38802b6bab7f1f0b32f771af4 ] && echo OK || echo BAD
gzip -dc labwc-0.20.2-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/labwc.list
gzip -dc labwc-0.20.2-r1.tar.gz | (cd /data/oss && tar -xf -) && rm labwc-0.20.2-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/labwc.list
rm var/lib/manual/labwc.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, font-dejavu, libsfdo, xz, libxml2, libxkbcommon, fribidi, graphite2, icu, harfbuzz, libxft, pango, wayland, lcms2, wlroots, xkeyboard-config. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
