Install and remove

A. apk

Dependencies come along, signatures checked:

apk add lanelet2
apk add lanelet2=1.2.3-r2   # this version

apk del lanelet2   # also drops dependencies nothing else needs

Package: lanelet2-1.2.3-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install lanelet2
oss-get install lanelet2=1.2.3-r2   # this version

oss-get remove lanelet2   # its files only

Its dependencies stay installed: boost, geographiclib, pugixml, ros2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/lanelet2-1.2.3-r2.tar.gz
[ "$(openssl dgst -sha256 lanelet2-1.2.3-r2.tar.gz | sed 's/.*= *//')" = 3b02cf0e39e4b9708c02f978eaf1861a43621cf651d0d5f34a9ab53111246afe ] && echo OK || echo BAD
gzip -dc lanelet2-1.2.3-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/lanelet2.list
gzip -dc lanelet2-1.2.3-r2.tar.gz | (cd /data/oss && tar -xf -) && rm lanelet2-1.2.3-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/lanelet2.list
rm var/lib/manual/lanelet2.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, geographiclib, pugixml, benchmark, console_bridge, brotli, c-ares, nghttp2, openssl, zstd, curl, cyclonedds, fastcdr, foonathan_memory, tinyxml2, fastdds, libyaml, lz4, openblas, expat, gdbm, libffi, readline, sqlite, python3, numpy, opencv, orocos-kdl, python3-pyyaml, urdfdom, yaml-cpp, ros2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
