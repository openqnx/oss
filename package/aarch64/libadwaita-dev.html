Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libadwaita-dev
apk add libadwaita-dev=1.6.10-r0   # this version

apk del libadwaita-dev   # also drops dependencies nothing else needs

Package: libadwaita-dev-1.6.10-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libadwaita-dev
oss-get install libadwaita-dev=1.6.10-r0   # this version

oss-get remove libadwaita-dev   # its files only

Its dependencies stay installed: libadwaita. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libadwaita-dev-1.6.10-r0.tar.gz
[ "$(openssl dgst -sha256 libadwaita-dev-1.6.10-r0.tar.gz | sed 's/.*= *//')" = dc2b941f84fe9e226a3d46b924602f2bb4bba3a6d44ff5467cd937fcdc627a28 ] && echo OK || echo BAD
gzip -dc libadwaita-dev-1.6.10-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libadwaita-dev.list
gzip -dc libadwaita-dev-1.6.10-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libadwaita-dev-1.6.10-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libadwaita-dev.list
rm var/lib/manual/libadwaita-dev.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, xz, libxml2, libxmlb, libyaml, appstream, fribidi, graphene, expat, bzip2, libpng, freetype, fontconfig, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, graphite2, icu, harfbuzz, libepoxy, libwebp, libtiff, libxkbcommon, libxft, pango, wayland, gtk4, libadwaita. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is libadwaita). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
