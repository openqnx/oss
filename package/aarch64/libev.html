B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libev-4.33-r0.tar.gz (24.7 KiB)
SHA-256
fedbf286d7e70f0786e9e31a133d4a1b177b14a704d95f0921f8278871654a21
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libev-4.33-r0.tar.gz
[ "$(openssl dgst -sha256 libev-4.33-r0.tar.gz | sed 's/.*= *//')" = fedbf286d7e70f0786e9e31a133d4a1b177b14a704d95f0921f8278871654a21 ] && echo OK || echo BAD
gzip -dc libev-4.33-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libev.list
gzip -dc libev-4.33-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libev-4.33-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libev.list
rm var/lib/manual/libev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
