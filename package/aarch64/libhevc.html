Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libhevc
apk add libhevc=1.8.5-r0   # this version

apk del libhevc   # also drops dependencies nothing else needs

Package: libhevc-1.8.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libhevc
oss-get install libhevc=1.8.5-r0   # this version

oss-get remove libhevc   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libhevc-1.8.5-r0.tar.gz (1.3 MiB)
SHA-256
f397a1aca16630cdb81a288241b97fc3e15369295b257dfaf3a21cd1091858b9
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libhevc-1.8.5-r0.tar.gz
[ "$(openssl dgst -sha256 libhevc-1.8.5-r0.tar.gz | sed 's/.*= *//')" = f397a1aca16630cdb81a288241b97fc3e15369295b257dfaf3a21cd1091858b9 ] && echo OK || echo BAD
gzip -dc libhevc-1.8.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libhevc.list
gzip -dc libhevc-1.8.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libhevc-1.8.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libhevc.list
rm var/lib/manual/libhevc.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
