B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libjson-dev
oss-get install libjson-dev=0.8_git20260512-r0   # this version

oss-get remove libjson-dev   # its files only

Its dependencies stay installed: libjson. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libjson-dev-0.8_git20260512-r0.tar.gz
[ "$(openssl dgst -sha256 libjson-dev-0.8_git20260512-r0.tar.gz | sed 's/.*= *//')" = 42a21fabb2fc9d1341884d62c663af877db78aace25a51cff32ff45256b43150 ] && echo OK || echo BAD
gzip -dc libjson-dev-0.8_git20260512-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libjson-dev.list
gzip -dc libjson-dev-0.8_git20260512-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libjson-dev-0.8_git20260512-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libjson-dev.list
rm var/lib/manual/libjson-dev.list

Its dependencies stay installed: libjson. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is libjson). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
