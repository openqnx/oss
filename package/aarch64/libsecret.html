Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libsecret
apk add libsecret=0.21.4-r0   # this version

apk del libsecret   # also drops dependencies nothing else needs

Package: libsecret-0.21.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libsecret
oss-get install libsecret=0.21.4-r0   # this version

oss-get remove libsecret   # its files only

Its dependencies stay installed: glib, libgcrypt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libsecret-0.21.4-r0.tar.gz (224.5 KiB)
SHA-256
54d61771587ff51802b35d0dbcdeb25fed35e7e4342a03ae9ab336a1b3abe17e
Install first
libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libgpg-error, libgcrypt (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libsecret-0.21.4-r0.tar.gz
[ "$(openssl dgst -sha256 libsecret-0.21.4-r0.tar.gz | sed 's/.*= *//')" = 54d61771587ff51802b35d0dbcdeb25fed35e7e4342a03ae9ab336a1b3abe17e ] && echo OK || echo BAD
gzip -dc libsecret-0.21.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libsecret.list
gzip -dc libsecret-0.21.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libsecret-0.21.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libsecret.list
rm var/lib/manual/libsecret.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libgpg-error, libgcrypt. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
