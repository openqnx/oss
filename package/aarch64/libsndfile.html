Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libsndfile
apk add libsndfile=1.2.2-r0   # this version

apk del libsndfile   # also drops dependencies nothing else needs

Package: libsndfile-1.2.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libsndfile
oss-get install libsndfile=1.2.2-r0   # this version

oss-get remove libsndfile   # its files only

Its dependencies stay installed: flac, libogg, libvorbis, opus. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libsndfile-1.2.2-r0.tar.gz (277.5 KiB)
SHA-256
ae2dbe169060a1b188fc0bac845c3d064b7ab5582221f5f5c845db5fd308e986
Install first
libogg, flac, libvorbis, opus (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libsndfile-1.2.2-r0.tar.gz
[ "$(openssl dgst -sha256 libsndfile-1.2.2-r0.tar.gz | sed 's/.*= *//')" = ae2dbe169060a1b188fc0bac845c3d064b7ab5582221f5f5c845db5fd308e986 ] && echo OK || echo BAD
gzip -dc libsndfile-1.2.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libsndfile.list
gzip -dc libsndfile-1.2.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libsndfile-1.2.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libsndfile.list
rm var/lib/manual/libsndfile.list

Its dependencies stay installed: libogg, flac, libvorbis, opus. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
