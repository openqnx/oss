B-2. By hand

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libunibreak-6.1-r0.tar.gz
[ "$(openssl dgst -sha256 libunibreak-6.1-r0.tar.gz | sed 's/.*= *//')" = 6aa5e6f7c5c97d35f8e0840c881685b18ed8b58d047cd0d0da5ed9e50d6ce8be ] && echo OK || echo BAD
gzip -dc libunibreak-6.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libunibreak.list
gzip -dc libunibreak-6.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libunibreak-6.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libunibreak.list
rm var/lib/manual/libunibreak.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
