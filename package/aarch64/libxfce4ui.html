Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libxfce4ui
apk add libxfce4ui=4.20.0-r1   # this version

apk del libxfce4ui   # also drops dependencies nothing else needs

Package: libxfce4ui-4.20.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libxfce4ui
oss-get install libxfce4ui=4.20.0-r1   # this version

oss-get remove libxfce4ui   # its files only

Its dependencies stay installed: at-spi2-core, cairo, gdk-pixbuf, gettext, glib, gtk3, harfbuzz, hicolor-icon-theme, libxfce4util, pango, xfconf, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libxfce4ui-4.20.0-r1.tar.gz
[ "$(openssl dgst -sha256 libxfce4ui-4.20.0-r1.tar.gz | sed 's/.*= *//')" = 8a7e0915045c65b0be751b45adb5b919c3ab578cc159c1f64dfcf3c5d71a9129 ] && echo OK || echo BAD
gzip -dc libxfce4ui-4.20.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libxfce4ui.list
gzip -dc libxfce4ui-4.20.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm libxfce4ui-4.20.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libxfce4ui.list
rm var/lib/manual/libxfce4ui.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, fribidi, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, hicolor-icon-theme, libxfce4util, xfconf. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
