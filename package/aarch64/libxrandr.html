Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libxrandr
apk add libxrandr=1.5.4-r0   # this version

apk del libxrandr   # also drops dependencies nothing else needs

Package: libxrandr-1.5.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libxrandr
oss-get install libxrandr=1.5.4-r0   # this version

oss-get remove libxrandr   # its files only

Its dependencies stay installed: libx11, libxext, libxrender. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libxrandr-1.5.4-r0.tar.gz (17.5 KiB)
SHA-256
a22c4d9953cf1acd3300cddf65851947d1d0fe5efd3831e24ee578375050cbeb
Install first
libxau, libxdmcp, libxcb, libx11, libxext, libxrender (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libxrandr-1.5.4-r0.tar.gz
[ "$(openssl dgst -sha256 libxrandr-1.5.4-r0.tar.gz | sed 's/.*= *//')" = a22c4d9953cf1acd3300cddf65851947d1d0fe5efd3831e24ee578375050cbeb ] && echo OK || echo BAD
gzip -dc libxrandr-1.5.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libxrandr.list
gzip -dc libxrandr-1.5.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libxrandr-1.5.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libxrandr.list
rm var/lib/manual/libxrandr.list

Its dependencies stay installed: libxau, libxdmcp, libxcb, libx11, libxext, libxrender. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
