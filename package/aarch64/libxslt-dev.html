Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libxslt-dev
apk add libxslt-dev=1.1.42-r0   # this version

apk del libxslt-dev   # also drops dependencies nothing else needs

Package: libxslt-dev-1.1.42-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libxslt-dev
oss-get install libxslt-dev=1.1.42-r0   # this version

oss-get remove libxslt-dev   # its files only

Its dependencies stay installed: libxslt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libxslt-dev-1.1.42-r0.tar.gz (174.4 KiB)
SHA-256
a84e9939bd4a6bfba73804cddebf92738e62566536be5254cb6ecfaa97778abb
Install first
libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64/libxslt-dev-1.1.42-r0.tar.gz
[ "$(openssl dgst -sha256 libxslt-dev-1.1.42-r0.tar.gz | sed 's/.*= *//')" = a84e9939bd4a6bfba73804cddebf92738e62566536be5254cb6ecfaa97778abb ] && echo OK || echo BAD
gzip -dc libxslt-dev-1.1.42-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libxslt-dev.list
gzip -dc libxslt-dev-1.1.42-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libxslt-dev-1.1.42-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libxslt-dev.list
rm var/lib/manual/libxslt-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is libxslt). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
