Install and remove

A. apk

Dependencies come along, signatures checked:

apk add meson
apk add meson=1.10.0-r0   # this version

apk del meson   # also drops dependencies nothing else needs

Package: meson-1.10.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install meson
oss-get install meson=1.10.0-r0   # this version

oss-get remove meson   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/meson-1.10.0-r0.tar.gz (884.1 KiB)
SHA-256
23ec6d8862646573e2a659acbe6e1e69690793e67b0a5fd60a72879dfc53e309
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/meson-1.10.0-r0.tar.gz
[ "$(openssl dgst -sha256 meson-1.10.0-r0.tar.gz | sed 's/.*= *//')" = 23ec6d8862646573e2a659acbe6e1e69690793e67b0a5fd60a72879dfc53e309 ] && echo OK || echo BAD
gzip -dc meson-1.10.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/meson.list
gzip -dc meson-1.10.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm meson-1.10.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/meson.list
rm var/lib/manual/meson.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
