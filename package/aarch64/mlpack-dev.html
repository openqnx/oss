Install and remove

A. apk

Dependencies come along, signatures checked:

apk add mlpack-dev
apk add mlpack-dev=4.8.0-r0   # this version

apk del mlpack-dev   # also drops dependencies nothing else needs

Package: mlpack-dev-4.8.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install mlpack-dev
oss-get install mlpack-dev=4.8.0-r0   # this version

oss-get remove mlpack-dev   # its files only

Its dependencies stay installed: mlpack. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/mlpack-dev-4.8.0-r0.tar.gz
[ "$(openssl dgst -sha256 mlpack-dev-4.8.0-r0.tar.gz | sed 's/.*= *//')" = 6bc422b1f3452a0e95b90f001754f56e9bef5ff8db8656ac0e960bbc69460355 ] && echo OK || echo BAD
gzip -dc mlpack-dev-4.8.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/mlpack-dev.list
gzip -dc mlpack-dev-4.8.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm mlpack-dev-4.8.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/mlpack-dev.list
rm var/lib/manual/mlpack-dev.list

Its dependencies stay installed: openblas, armadillo, mlpack. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is mlpack). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
