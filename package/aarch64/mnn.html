Install and remove

A. apk

Dependencies come along, signatures checked:

apk add mnn

Package: mnn-3.6.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install mnn
oss-get install mnn=3.6.2-r0   # this version

oss-get remove mnn   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/mnn-3.6.2-r0.tar.gz (1.6 MiB)
SHA-256
cb6712ec28f3bd3197779e1a5f9cf9087be50413a8f0e107f62acfa15c417e55
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/mnn-3.6.2-r0.tar.gz
[ "$(openssl dgst -sha256 mnn-3.6.2-r0.tar.gz | sed 's/.*= *//')" = cb6712ec28f3bd3197779e1a5f9cf9087be50413a8f0e107f62acfa15c417e55 ] && echo OK || echo BAD
gzip -dc mnn-3.6.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/mnn.list
gzip -dc mnn-3.6.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm mnn-3.6.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/mnn.list
rm var/lib/manual/mnn.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
