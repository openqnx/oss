Install and remove

A. apk

Dependencies come along, signatures checked:

apk add nano-dev
apk add nano-dev=8.2-r0   # this version

apk del nano-dev   # also drops dependencies nothing else needs

Package: nano-dev-8.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install nano-dev
oss-get install nano-dev=8.2-r0   # this version

oss-get remove nano-dev   # its files only

Its dependencies stay installed: nano. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/nano-dev-8.2-r0.tar.gz (73.0 KiB)
SHA-256
04322f190c451234b9ecdafaba642ab6ea0a8e1a7c853d4e1be89c7431c11a67
Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd, file, nano (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/nano-dev-8.2-r0.tar.gz
[ "$(openssl dgst -sha256 nano-dev-8.2-r0.tar.gz | sed 's/.*= *//')" = 04322f190c451234b9ecdafaba642ab6ea0a8e1a7c853d4e1be89c7431c11a67 ] && echo OK || echo BAD
gzip -dc nano-dev-8.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/nano-dev.list
gzip -dc nano-dev-8.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm nano-dev-8.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/nano-dev.list
rm var/lib/manual/nano-dev.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd, file, nano. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is nano). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
