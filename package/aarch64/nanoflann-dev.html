Install and remove

A. apk

Dependencies come along, signatures checked:

apk add nanoflann-dev
apk add nanoflann-dev=1.10.0-r0   # this version

apk del nanoflann-dev   # also drops dependencies nothing else needs

Package: nanoflann-dev-1.10.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install nanoflann-dev
oss-get install nanoflann-dev=1.10.0-r0   # this version

oss-get remove nanoflann-dev   # its files only

B-2. By hand

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/nanoflann-dev-1.10.0-r0.tar.gz
[ "$(openssl dgst -sha256 nanoflann-dev-1.10.0-r0.tar.gz | sed 's/.*= *//')" = deb2dcbd9365b9a496b31fded63944ca32b821ef9689a5d065bfcc10c7436334 ] && echo OK || echo BAD
gzip -dc nanoflann-dev-1.10.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/nanoflann-dev.list
gzip -dc nanoflann-dev-1.10.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm nanoflann-dev-1.10.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/nanoflann-dev.list
rm var/lib/manual/nanoflann-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
