Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ncurses
apk add ncurses=6.5-r2   # this version

apk del ncurses   # also drops dependencies nothing else needs

Package: ncurses-6.5-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ncurses
oss-get install ncurses=6.5-r2   # this version

oss-get remove ncurses   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/ncurses-6.5-r2.tar.gz
[ "$(openssl dgst -sha256 ncurses-6.5-r2.tar.gz | sed 's/.*= *//')" = 719c8f2f80e612265a1888ddcff06b8715e549adabba8d0408b82f82311b79ad ] && echo OK || echo BAD
gzip -dc ncurses-6.5-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ncurses.list
gzip -dc ncurses-6.5-r2.tar.gz | (cd /data/oss && tar -xf -) && rm ncurses-6.5-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ncurses.list
rm var/lib/manual/ncurses.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
