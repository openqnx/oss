Install and remove

A. apk

Dependencies come along, signatures checked:

apk add numpy
apk add numpy=2.3.4-r1   # this version

apk del numpy   # also drops dependencies nothing else needs

Package: numpy-2.3.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install numpy
oss-get install numpy=2.3.4-r1   # this version

oss-get remove numpy   # its files only

Its dependencies stay installed: openblas, python3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256
01385216380f2c387dc32eaa5c6f2deb356547b4c62be0ea7f17bd4b340ed56b

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/numpy-2.3.4-r1.tar.gz
[ "$(openssl dgst -sha256 numpy-2.3.4-r1.tar.gz | sed 's/.*= *//')" = 01385216380f2c387dc32eaa5c6f2deb356547b4c62be0ea7f17bd4b340ed56b ] && echo OK || echo BAD
gzip -dc numpy-2.3.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/numpy.list
gzip -dc numpy-2.3.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm numpy-2.3.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/numpy.list
rm var/lib/manual/numpy.list

Its dependencies stay installed: openblas, bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
