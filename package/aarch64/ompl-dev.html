Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ompl-dev
apk add ompl-dev=1.7.0-r0   # this version

apk del ompl-dev   # also drops dependencies nothing else needs

Package: ompl-dev-1.7.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ompl-dev
oss-get install ompl-dev=1.7.0-r0   # this version

oss-get remove ompl-dev   # its files only

Its dependencies stay installed: ompl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/ompl-dev-1.7.0-r0.tar.gz (359.7 KiB)
SHA-256
e0ab1c7abfbd969b6bef53854326f33ab96c4a1d5b73ff1cda3aee6215b026b5
Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, ompl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/ompl-dev-1.7.0-r0.tar.gz
[ "$(openssl dgst -sha256 ompl-dev-1.7.0-r0.tar.gz | sed 's/.*= *//')" = e0ab1c7abfbd969b6bef53854326f33ab96c4a1d5b73ff1cda3aee6215b026b5 ] && echo OK || echo BAD
gzip -dc ompl-dev-1.7.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ompl-dev.list
gzip -dc ompl-dev-1.7.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm ompl-dev-1.7.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ompl-dev.list
rm var/lib/manual/ompl-dev.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, ompl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is ompl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
