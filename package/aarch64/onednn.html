Install and remove

A. apk

Dependencies come along, signatures checked:

apk add onednn
apk add onednn=3.14.1-r0   # this version

apk del onednn   # also drops dependencies nothing else needs

Package: onednn-3.14.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install onednn
oss-get install onednn=3.14.1-r0   # this version

oss-get remove onednn   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/onednn-3.14.1-r0.tar.gz (10.0 MiB)
SHA-256
8798ba440162b249ef85e1e925b917fc88448239833bbfb53b3a0239ea9cf240
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/onednn-3.14.1-r0.tar.gz
[ "$(openssl dgst -sha256 onednn-3.14.1-r0.tar.gz | sed 's/.*= *//')" = 8798ba440162b249ef85e1e925b917fc88448239833bbfb53b3a0239ea9cf240 ] && echo OK || echo BAD
gzip -dc onednn-3.14.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/onednn.list
gzip -dc onednn-3.14.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm onednn-3.14.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/onednn.list
rm var/lib/manual/onednn.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
