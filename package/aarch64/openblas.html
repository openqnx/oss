A. apk

Dependencies come along, signatures checked:

apk add openblas

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install openblas
oss-get install openblas=0.3.28-r0   # this version

oss-get remove openblas   # its files only

B-2. By hand

nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/openblas-0.3.28-r0.tar.gz
[ "$(openssl dgst -sha256 openblas-0.3.28-r0.tar.gz | sed 's/.*= *//')" = af8bda268d369563ed1a24a3164b75d4defe0b65435f987d216b0eb26b74c14d ] && echo OK || echo BAD
gzip -dc openblas-0.3.28-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/openblas.list
gzip -dc openblas-0.3.28-r0.tar.gz | (cd /data/oss && tar -xf -) && rm openblas-0.3.28-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/openblas.list
rm var/lib/manual/openblas.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
