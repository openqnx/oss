Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/openpam-20250531-r0.tar.gz
[ "$(openssl dgst -sha256 openpam-20250531-r0.tar.gz | sed 's/.*= *//')" = 0ee54ba363d2afd5e17887cfac817f0fff6c478a9f4e0090fa2bc43b4a88c385 ] && echo OK || echo BAD
gzip -dc openpam-20250531-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/openpam.list
gzip -dc openpam-20250531-r0.tar.gz | (cd /data/oss && tar -xf -) && rm openpam-20250531-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/openpam.list
rm var/lib/manual/openpam.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
