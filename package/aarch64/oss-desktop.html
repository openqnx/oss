Install and remove

A. apk

Dependencies come along, signatures checked:

apk add oss-desktop
apk add oss-desktop=1.0-r0   # this version

apk del oss-desktop   # also drops dependencies nothing else needs

Package: oss-desktop-1.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install oss-desktop
oss-get install oss-desktop=1.0-r0   # this version

oss-get remove oss-desktop   # its files only

Its dependencies stay installed: dbus, font-dejavu, hicolor-icon-theme, labwc, lxde-icon-theme, swaybg, thunar, xfce4-appfinder, xfce4-panel, xfce4-terminal. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/oss-desktop-1.0-r0.tar.gz
[ "$(openssl dgst -sha256 oss-desktop-1.0-r0.tar.gz | sed 's/.*= *//')" = bf305b2031175011e9da6cf5af975d8ca33b4cc695fd150dcff32bc433d6090a ] && echo OK || echo BAD
gzip -dc oss-desktop-1.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/oss-desktop.list
gzip -dc oss-desktop-1.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm oss-desktop-1.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/oss-desktop.list
rm var/lib/manual/oss-desktop.list

Its dependencies stay installed: expat, dbus, font-dejavu, hicolor-icon-theme, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, libsfdo, xz, libxml2, libxkbcommon, fribidi, graphite2, icu, harfbuzz, libxft, pango, wayland, lcms2, wlroots, xkeyboard-config, labwc, lxde-icon-theme, libjpeg-turbo, gdk-pixbuf, swaybg, libxi, libxtst, at-spi2-core, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, libxrandr, gtk3, libxfce4util, xfconf, libxfce4ui, exo, libexif, libnotify, garcon, gtk-layer-shell, libxfce4windowing, xfce4-panel, thunar, xfce4-appfinder, gmp, libidn2, libtasn1, nettle, zstd, gnutls, graphene, libwebp, libtiff, gtk4, lz4, vte, xfce4-terminal. For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay.
