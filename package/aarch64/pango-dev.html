Install and remove

A. apk

Dependencies come along, signatures checked:

apk add pango-dev
apk add pango-dev=1.54.0-r0   # this version

apk del pango-dev   # also drops dependencies nothing else needs

Package: pango-dev-1.54.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pango-dev
oss-get install pango-dev=1.54.0-r0   # this version

oss-get remove pango-dev   # its files only

Its dependencies stay installed: pango. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pango-dev-1.54.0-r0.tar.gz
[ "$(openssl dgst -sha256 pango-dev-1.54.0-r0.tar.gz | sed 's/.*= *//')" = e40be2511c5f41b60de029232b1a54132be54adf902ee464fc7a119b6e63646c ] && echo OK || echo BAD
gzip -dc pango-dev-1.54.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pango-dev.list
gzip -dc pango-dev-1.54.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm pango-dev-1.54.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pango-dev.list
rm var/lib/manual/pango-dev.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, fribidi, graphite2, icu, harfbuzz, libxft, pango. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is pango). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
