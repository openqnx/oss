Install and remove

A. apk

Dependencies come along, signatures checked:

apk add pcl-dev
apk add pcl-dev=1.14.1-r0   # this version

apk del pcl-dev   # also drops dependencies nothing else needs

Package: pcl-dev-1.14.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pcl-dev
oss-get install pcl-dev=1.14.1-r0   # this version

oss-get remove pcl-dev   # its files only

Its dependencies stay installed: pcl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pcl-dev-1.14.1-r0.tar.gz
[ "$(openssl dgst -sha256 pcl-dev-1.14.1-r0.tar.gz | sed 's/.*= *//')" = f9fb1aa9d43ad01dc4622bdf99b5223dcaf18ea67ebd2c0fc39d369aa3f00759 ] && echo OK || echo BAD
gzip -dc pcl-dev-1.14.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pcl-dev.list
gzip -dc pcl-dev-1.14.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm pcl-dev-1.14.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pcl-dev.list
rm var/lib/manual/pcl-dev.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, lz4, flann, pcl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is pcl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
