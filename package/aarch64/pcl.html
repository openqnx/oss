Install and remove

A. apk

Dependencies come along, signatures checked:

apk add pcl
apk add pcl=1.14.1-r1   # this version

apk del pcl   # also drops dependencies nothing else needs

Package: pcl-1.14.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pcl
oss-get install pcl=1.14.1-r1   # this version

oss-get remove pcl   # its files only

Its dependencies stay installed: boost, flann, lz4. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pcl-1.14.1-r1.tar.gz (19.8 MiB)
SHA-256
92d4e657b7252b4e37db776f117e3748a1a00b3f278a41836197950fc71fcc83
Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, lz4, flann (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pcl-1.14.1-r1.tar.gz
[ "$(openssl dgst -sha256 pcl-1.14.1-r1.tar.gz | sed 's/.*= *//')" = 92d4e657b7252b4e37db776f117e3748a1a00b3f278a41836197950fc71fcc83 ] && echo OK || echo BAD
gzip -dc pcl-1.14.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pcl.list
gzip -dc pcl-1.14.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm pcl-1.14.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pcl.list
rm var/lib/manual/pcl.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, lz4, flann. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
