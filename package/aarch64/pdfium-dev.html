Install and remove

A. apk

Dependencies come along, signatures checked:

apk add pdfium-dev
apk add pdfium-dev=0_git-r0   # this version

apk del pdfium-dev   # also drops dependencies nothing else needs

Package: pdfium-dev-0_git-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pdfium-dev
oss-get install pdfium-dev=0_git-r0   # this version

oss-get remove pdfium-dev   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pdfium-dev-0_git-r0.tar.gz (25.3 MiB)
SHA-256

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pdfium-dev-0_git-r0.tar.gz
[ "$(openssl dgst -sha256 pdfium-dev-0_git-r0.tar.gz | sed 's/.*= *//')" = 64eace7eff575acafae5327ff6009b9c108fe3fad4fd74ce8652d65721247024 ] && echo OK || echo BAD
gzip -dc pdfium-dev-0_git-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pdfium-dev.list
gzip -dc pdfium-dev-0_git-r0.tar.gz | (cd /data/oss && tar -xf -) && rm pdfium-dev-0_git-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pdfium-dev.list
rm var/lib/manual/pdfium-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
