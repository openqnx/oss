Install and remove

A. apk

Dependencies come along, signatures checked:

apk add perl-encode-locale
apk add perl-encode-locale=1.05-r0   # this version

apk del perl-encode-locale   # also drops dependencies nothing else needs

Package: perl-encode-locale-1.05-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install perl-encode-locale
oss-get install perl-encode-locale=1.05-r0   # this version

oss-get remove perl-encode-locale   # its files only

Its dependencies stay installed: perl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/perl-encode-locale-1.05-r0.tar.gz
[ "$(openssl dgst -sha256 perl-encode-locale-1.05-r0.tar.gz | sed 's/.*= *//')" = 0596b0ead671bc0aa3bda055676ddb165c71a0dca887ef4091f3767784bcbb84 ] && echo OK || echo BAD
gzip -dc perl-encode-locale-1.05-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/perl-encode-locale.list
gzip -dc perl-encode-locale-1.05-r0.tar.gz | (cd /data/oss && tar -xf -) && rm perl-encode-locale-1.05-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/perl-encode-locale.list
rm var/lib/manual/perl-encode-locale.list

Its dependencies stay installed: libxcrypt, perl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
