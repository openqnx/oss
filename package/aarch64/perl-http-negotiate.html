Install and remove

A. apk

Dependencies come along, signatures checked:

apk add perl-http-negotiate

apk del perl-http-negotiate   # also drops dependencies nothing else needs

Package: perl-http-negotiate-6.01-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install perl-http-negotiate
oss-get install perl-http-negotiate=6.01-r0   # this version

oss-get remove perl-http-negotiate   # its files only

Its dependencies stay installed: perl, perl-http-message. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/perl-http-negotiate-6.01-r0.tar.gz
[ "$(openssl dgst -sha256 perl-http-negotiate-6.01-r0.tar.gz | sed 's/.*= *//')" = 508c7dedd0d240c65f3185ad8f26ed28584f8e9bc5c87ebccbabb90477992398 ] && echo OK || echo BAD
gzip -dc perl-http-negotiate-6.01-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/perl-http-negotiate.list
gzip -dc perl-http-negotiate-6.01-r0.tar.gz | (cd /data/oss && tar -xf -) && rm perl-http-negotiate-6.01-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/perl-http-negotiate.list
rm var/lib/manual/perl-http-negotiate.list

Its dependencies stay installed: libxcrypt, perl, perl-clone, perl-encode-locale, perl-http-date, perl-io-html, perl-lwp-mediatypes, perl-mime-base32, perl-uri, perl-http-message. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
