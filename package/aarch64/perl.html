Install and remove

A. apk

Dependencies come along, signatures checked:

apk add perl
apk add perl=5.40.2-r2   # this version

apk del perl   # also drops dependencies nothing else needs

Package: perl-5.40.2-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install perl
oss-get install perl=5.40.2-r2   # this version

oss-get remove perl   # its files only

Its dependencies stay installed: libxcrypt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/perl-5.40.2-r2.tar.gz
[ "$(openssl dgst -sha256 perl-5.40.2-r2.tar.gz | sed 's/.*= *//')" = b5a332b68e71cf623677a77594188d0797eff75b6980a421a51cc02cf789f62a ] && echo OK || echo BAD
gzip -dc perl-5.40.2-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/perl.list
gzip -dc perl-5.40.2-r2.tar.gz | (cd /data/oss && tar -xf -) && rm perl-5.40.2-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/perl.list
rm var/lib/manual/perl.list

Its dependencies stay installed: libxcrypt. Remove each the same way, from its own page, if nothing else needs it.
