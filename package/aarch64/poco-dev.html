Install and remove

A. apk

Dependencies come along, signatures checked:

apk add poco-dev
apk add poco-dev=1.15.4-r0   # this version

apk del poco-dev   # also drops dependencies nothing else needs

Package: poco-dev-1.15.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install poco-dev
oss-get install poco-dev=1.15.4-r0   # this version

oss-get remove poco-dev   # its files only

Its dependencies stay installed: poco. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/poco-dev-1.15.4-r0.tar.gz (562.5 KiB)
SHA-256
2ae76080176371b83043ec8a4016369c6c2bd7c1cb9807a8d6d1f1c3ff38f339
Install first
expat, openssl, pcre2, utf8proc, zlib, poco (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/poco-dev-1.15.4-r0.tar.gz
[ "$(openssl dgst -sha256 poco-dev-1.15.4-r0.tar.gz | sed 's/.*= *//')" = 2ae76080176371b83043ec8a4016369c6c2bd7c1cb9807a8d6d1f1c3ff38f339 ] && echo OK || echo BAD
gzip -dc poco-dev-1.15.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/poco-dev.list
gzip -dc poco-dev-1.15.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm poco-dev-1.15.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/poco-dev.list
rm var/lib/manual/poco-dev.list

Its dependencies stay installed: expat, openssl, pcre2, utf8proc, zlib, poco. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is poco). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
