B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pygame-dev
oss-get install pygame-dev=2.6.1_git20251005-r0   # this version

oss-get remove pygame-dev   # its files only

Its dependencies stay installed: pygame. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/pygame-dev-2.6.1_git20251005-r0.tar.gz
[ "$(openssl dgst -sha256 pygame-dev-2.6.1_git20251005-r0.tar.gz | sed 's/.*= *//')" = 4133c17f0417eab0684a78d97c97147f214552778ffe7e6289f15e8e3b72bdde ] && echo OK || echo BAD
gzip -dc pygame-dev-2.6.1_git20251005-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pygame-dev.list
gzip -dc pygame-dev-2.6.1_git20251005-r0.tar.gz | (cd /data/oss && tar -xf -) && rm pygame-dev-2.6.1_git20251005-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pygame-dev.list
rm var/lib/manual/pygame-dev.list

Its dependencies stay installed: brotli, bzip2, zlib, libpng, freetype, libjpeg-turbo, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, sqlite, xz, zstd, python3, sdl2, aom, dav1d, libavif, libwebp, libtiff, sdl2-image, libogg, opus, opusfile, sdl2-mixer, pcre2, glib, graphite2, icu, harfbuzz, sdl2-ttf, pygame. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is pygame). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
