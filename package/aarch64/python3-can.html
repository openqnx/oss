Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-can
apk add python3-can=4.6.1-r0   # this version

apk del python3-can   # also drops dependencies nothing else needs

Package: python3-can-4.6.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-can
oss-get install python3-can=4.6.1-r0   # this version

oss-get remove python3-can   # its files only

Its dependencies stay installed: python3, python3-packaging, python3-typing-extensions, python3-wrapt, qnx-socketcan. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/python3-can-4.6.1-r0.tar.gz
[ "$(openssl dgst -sha256 python3-can-4.6.1-r0.tar.gz | sed 's/.*= *//')" = 45caef8dab2359c84dc989776ea491c62a35c60dd1aecc9433ad9e939c224468 ] && echo OK || echo BAD
gzip -dc python3-can-4.6.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-can.list
gzip -dc python3-can-4.6.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-can-4.6.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-can.list
rm var/lib/manual/python3-can.list

Its dependencies stay installed: bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3, python3-packaging, python3-typing-extensions, python3-wrapt, qnx-socketcan. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
