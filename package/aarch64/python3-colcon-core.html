Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-colcon-core
apk add python3-colcon-core=0.21.3-r0   # this version

apk del python3-colcon-core   # also drops dependencies nothing else needs

Package: python3-colcon-core-0.21.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-colcon-core
oss-get install python3-colcon-core=0.21.3-r0   # this version

oss-get remove python3-colcon-core   # its files only

Its dependencies stay installed: python3, python3-distlib, python3-empy, python3-packaging, python3-pytest, python3-pytest-cov, python3-pytest-repeat, python3-pytest-rerunfailures, python3-setuptools. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/python3-colcon-core-0.21.3-r0.tar.gz
[ "$(openssl dgst -sha256 python3-colcon-core-0.21.3-r0.tar.gz | sed 's/.*= *//')" = 08fd04dd2fd516392b88097a8899f8bb38fad1a5c8066abc9113032ce7a60a3e ] && echo OK || echo BAD
gzip -dc python3-colcon-core-0.21.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-colcon-core.list
gzip -dc python3-colcon-core-0.21.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-colcon-core-0.21.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-colcon-core.list
rm var/lib/manual/python3-colcon-core.list

Its dependencies stay installed: bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3, python3-distlib, python3-empy, python3-packaging, python3-iniconfig, python3-pluggy, python3-pygments, python3-pytest, python3-coverage, python3-pytest-cov, python3-pytest-repeat, python3-pytest-rerunfailures, python3-setuptools. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
