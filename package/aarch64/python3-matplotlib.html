Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-matplotlib
apk add python3-matplotlib=3.11.2-r1   # this version

apk del python3-matplotlib   # also drops dependencies nothing else needs

Package: python3-matplotlib-3.11.2-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-matplotlib
oss-get install python3-matplotlib=3.11.2-r1   # this version

oss-get remove python3-matplotlib   # its files only

Its dependencies stay installed: freetype, libraqm, numpy, python3, python3-contourpy, python3-cycler, python3-dateutil, python3-fonttools, python3-kiwisolver, python3-packaging, python3-pillow, python3-pyparsing, qhull. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

[ "$(openssl dgst -sha256 python3-matplotlib-3.11.2-r1.tar.gz | sed 's/.*= *//')" = 6bc633f2623b9f2e6253996735a5e42aabf396e33f3b168aa63bc984dd18449b ] && echo OK || echo BAD
gzip -dc python3-matplotlib-3.11.2-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-matplotlib.list
gzip -dc python3-matplotlib-3.11.2-r1.tar.gz | (cd /data/oss && tar -xf -) && rm python3-matplotlib-3.11.2-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-matplotlib.list
rm var/lib/manual/python3-matplotlib.list
