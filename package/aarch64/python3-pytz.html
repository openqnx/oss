Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-pytz
apk add python3-pytz=2025.2-r0   # this version

apk del python3-pytz   # also drops dependencies nothing else needs

Package: python3-pytz-2025.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-pytz
oss-get install python3-pytz=2025.2-r0   # this version

oss-get remove python3-pytz   # its files only

B-2. By hand

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/python3-pytz-2025.2-r0.tar.gz
[ "$(openssl dgst -sha256 python3-pytz-2025.2-r0.tar.gz | sed 's/.*= *//')" = f016ab7fc1dd30eb5fe4725ca1ab187b1483e38e87f8604e54411f926acc0fb9 ] && echo OK || echo BAD
gzip -dc python3-pytz-2025.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-pytz.list
gzip -dc python3-pytz-2025.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-pytz-2025.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-pytz.list
rm var/lib/manual/python3-pytz.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
