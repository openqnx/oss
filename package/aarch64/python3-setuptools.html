B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-setuptools
oss-get install python3-setuptools=80.8.0-r0   # this version

oss-get remove python3-setuptools   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/python3-setuptools-80.8.0-r0.tar.gz (991.2 KiB)
SHA-256
a23b747d9a671dcd57957dd70d350e190b98a8a31ecd3a4abba6c6d9cac0d647
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/python3-setuptools-80.8.0-r0.tar.gz
[ "$(openssl dgst -sha256 python3-setuptools-80.8.0-r0.tar.gz | sed 's/.*= *//')" = a23b747d9a671dcd57957dd70d350e190b98a8a31ecd3a4abba6c6d9cac0d647 ] && echo OK || echo BAD
gzip -dc python3-setuptools-80.8.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-setuptools.list
gzip -dc python3-setuptools-80.8.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-setuptools-80.8.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-setuptools.list
rm var/lib/manual/python3-setuptools.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
