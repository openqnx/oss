Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qt6-3d-dev
apk add qt6-3d-dev=6.8.1-r0   # this version

apk del qt6-3d-dev   # also drops dependencies nothing else needs

Package: qt6-3d-dev-6.8.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qt6-3d-dev
oss-get install qt6-3d-dev=6.8.1-r0   # this version

oss-get remove qt6-3d-dev   # its files only

Its dependencies stay installed: qt6-3d. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.
