Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qt6-httpserver-dev
apk add qt6-httpserver-dev=6.8.1-r0   # this version

apk del qt6-httpserver-dev   # also drops dependencies nothing else needs

Package: qt6-httpserver-dev-6.8.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qt6-httpserver-dev
oss-get install qt6-httpserver-dev=6.8.1-r0   # this version

oss-get remove qt6-httpserver-dev   # its files only

Its dependencies stay installed: qt6-httpserver. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/qt6-httpserver-dev-6.8.1-r0.tar.gz
[ "$(openssl dgst -sha256 qt6-httpserver-dev-6.8.1-r0.tar.gz | sed 's/.*= *//')" = e5cff0fa82df6152f750efb75c3ab9268ec705ddd56e90d586d1ca424e477a0d ] && echo OK || echo BAD
gzip -dc qt6-httpserver-dev-6.8.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/qt6-httpserver-dev.list
gzip -dc qt6-httpserver-dev-6.8.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm qt6-httpserver-dev-6.8.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/qt6-httpserver-dev.list
rm var/lib/manual/qt6-httpserver-dev.list

Its dependencies stay installed: brotli, double-conversion, bzip2, dav1d, lame, libogg, libtheora, libvorbis, libvpx, openh264, opus, x264, x265, libiconv, libunistring, ncurses, gettext, xz, zlib, ffmpeg, expat, libpng, freetype, fontconfig, libffi, pcre2, glib, aom, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, fdk-aac, gstreamer, gst-plugins-base, libwebp, fribidi, graphite2, icu, harfbuzz, libxft, pango, svt-av1, gst-plugins-bad, libjpeg-turbo, zstd, libtiff, libxml2, libxkbcommon, openssl, qt6, qt6-httpserver. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is qt6-httpserver). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
