Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qt6-wayland-dev
apk add qt6-wayland-dev=6.8.1-r0   # this version

apk del qt6-wayland-dev   # also drops dependencies nothing else needs

Package: qt6-wayland-dev-6.8.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qt6-wayland-dev
oss-get install qt6-wayland-dev=6.8.1-r0   # this version

oss-get remove qt6-wayland-dev   # its files only

Its dependencies stay installed: qt6-wayland. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

gzip -dc qt6-wayland-dev-6.8.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/qt6-wayland-dev.list
gzip -dc qt6-wayland-dev-6.8.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm qt6-wayland-dev-6.8.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/qt6-wayland-dev.list
rm var/lib/manual/qt6-wayland-dev.list

Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is qt6-wayland). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
