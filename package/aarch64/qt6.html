Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qt6
apk add qt6=6.8.1-r1   # this version

apk del qt6   # also drops dependencies nothing else needs

Package: qt6-6.8.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qt6
oss-get install qt6=6.8.1-r1   # this version

oss-get remove qt6   # its files only

Its dependencies stay installed: brotli, double-conversion, ffmpeg, fontconfig, freetype, glib, gst-plugins-bad, gst-plugins-base, gstreamer, harfbuzz, icu, libjpeg-turbo, libpng, libtiff, libwebp, openssl, pcre2, zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.
