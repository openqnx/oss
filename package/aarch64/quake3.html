B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install quake3
oss-get install quake3=1.36_git20261012-r1   # this version

oss-get remove quake3   # its files only

Its dependencies stay installed: sdl2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/quake3-1.36_git20261012-r1.tar.gz
[ "$(openssl dgst -sha256 quake3-1.36_git20261012-r1.tar.gz | sed 's/.*= *//')" = 5c46ce5aa0c5b8d1d58d9c03b1bcc1627ebe97d4615e6b772ebf4186ea812977 ] && echo OK || echo BAD
gzip -dc quake3-1.36_git20261012-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/quake3.list
gzip -dc quake3-1.36_git20261012-r1.tar.gz | (cd /data/oss && tar -xf -) && rm quake3-1.36_git20261012-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/quake3.list
rm var/lib/manual/quake3.list

Its dependencies stay installed: sdl2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
