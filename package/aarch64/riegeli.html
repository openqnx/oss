Package: riegeli-0_git20231212-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install riegeli
oss-get install riegeli=0_git20231212-r1   # this version

oss-get remove riegeli   # its files only

Its dependencies stay installed: abseil, brotli, bzip2, highwayhash, lz4, protobuf, snappy, xz, zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/riegeli-0_git20231212-r1.tar.gz
[ "$(openssl dgst -sha256 riegeli-0_git20231212-r1.tar.gz | sed 's/.*= *//')" = 2a8129f05a62cae871a8a77e3126749854c28963b79879e9726ed971edf0a1bd ] && echo OK || echo BAD
gzip -dc riegeli-0_git20231212-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/riegeli.list
gzip -dc riegeli-0_git20231212-r1.tar.gz | (cd /data/oss && tar -xf -) && rm riegeli-0_git20231212-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/riegeli.list
rm var/lib/manual/riegeli.list

Its dependencies stay installed: abseil, brotli, bzip2, highwayhash, lz4, zlib, protobuf, snappy, libiconv, libunistring, ncurses, gettext, xz, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
