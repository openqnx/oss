Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ros2-dev
apk add ros2-dev=0_git-r1   # this version

apk del ros2-dev   # also drops dependencies nothing else needs

Package: ros2-dev-0_git-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ros2-dev
oss-get install ros2-dev=0_git-r1   # this version

oss-get remove ros2-dev   # its files only

Its dependencies stay installed: ros2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/ros2-dev-0_git-r1.tar.gz
[ "$(openssl dgst -sha256 ros2-dev-0_git-r1.tar.gz | sed 's/.*= *//')" = 74a0a1bb70ec1d6bc5ca12d1ad3ba9c23fc5ccd4cb3cccbc6c11092733556b37 ] && echo OK || echo BAD
gzip -dc ros2-dev-0_git-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ros2-dev.list
gzip -dc ros2-dev-0_git-r1.tar.gz | (cd /data/oss && tar -xf -) && rm ros2-dev-0_git-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ros2-dev.list
rm var/lib/manual/ros2-dev.list

Its dependencies stay installed: benchmark, console_bridge, brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, cyclonedds, fastcdr, foonathan_memory, tinyxml2, fastdds, libyaml, lz4, opencv, orocos-kdl, bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, readline, sqlite, xz, python3, urdfdom, yaml-cpp, ros2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is ros2). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
