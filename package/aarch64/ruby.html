Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ruby
apk add ruby=3.4.12-r1   # this version

apk del ruby   # also drops dependencies nothing else needs

Package: ruby-3.4.12-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ruby
oss-get install ruby=3.4.12-r1   # this version

oss-get remove ruby   # its files only

Its dependencies stay installed: gmp, libffi, libxcrypt, libyaml, openssl, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/ruby-3.4.12-r1.tar.gz
[ "$(openssl dgst -sha256 ruby-3.4.12-r1.tar.gz | sed 's/.*= *//')" = 9f5f0792e526a6af8757cb2b8171be1e669f569af61ea657cfe272b9e370c679 ] && echo OK || echo BAD
gzip -dc ruby-3.4.12-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ruby.list
gzip -dc ruby-3.4.12-r1.tar.gz | (cd /data/oss && tar -xf -) && rm ruby-3.4.12-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ruby.list
rm var/lib/manual/ruby.list

Its dependencies stay installed: gmp, libffi, libxcrypt, libyaml, openssl, zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
