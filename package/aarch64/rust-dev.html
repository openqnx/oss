Install and remove

A. apk

Dependencies come along, signatures checked:

apk add rust-dev
apk add rust-dev=1.90.0-r0   # this version

apk del rust-dev   # also drops dependencies nothing else needs

Package: rust-dev-1.90.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install rust-dev
oss-get install rust-dev=1.90.0-r0   # this version

oss-get remove rust-dev   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/rust-dev-1.90.0-r0.tar.gz
[ "$(openssl dgst -sha256 rust-dev-1.90.0-r0.tar.gz | sed 's/.*= *//')" = 1003e7996d630adde90ddbf945f7591058b2a4a923b7c4e96daebed20568f1e5 ] && echo OK || echo BAD
gzip -dc rust-dev-1.90.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/rust-dev.list
gzip -dc rust-dev-1.90.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm rust-dev-1.90.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/rust-dev.list
rm var/lib/manual/rust-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
