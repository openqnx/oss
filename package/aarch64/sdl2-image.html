Install and remove

A. apk

Dependencies come along, signatures checked:

apk add sdl2-image
apk add sdl2-image=2.8.8-r0   # this version

apk del sdl2-image   # also drops dependencies nothing else needs

Package: sdl2-image-2.8.8-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sdl2-image
oss-get install sdl2-image=2.8.8-r0   # this version

oss-get remove sdl2-image   # its files only

Its dependencies stay installed: libavif, libtiff, libwebp, sdl2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sdl2-image-2.8.8-r0.tar.gz (134.4 KiB)
SHA-256
f32a6c4907a2a3698d34419c854382f451873a579c6d29eb5c7a49c5dcecf6d7
Install first
aom, dav1d, libavif, libjpeg-turbo, libwebp, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd, libtiff, sdl2 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sdl2-image-2.8.8-r0.tar.gz
[ "$(openssl dgst -sha256 sdl2-image-2.8.8-r0.tar.gz | sed 's/.*= *//')" = f32a6c4907a2a3698d34419c854382f451873a579c6d29eb5c7a49c5dcecf6d7 ] && echo OK || echo BAD
gzip -dc sdl2-image-2.8.8-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sdl2-image.list
gzip -dc sdl2-image-2.8.8-r0.tar.gz | (cd /data/oss && tar -xf -) && rm sdl2-image-2.8.8-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sdl2-image.list
rm var/lib/manual/sdl2-image.list

Its dependencies stay installed: aom, dav1d, libavif, libjpeg-turbo, libwebp, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd, libtiff, sdl2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
