Install and remove

A. apk

Dependencies come along, signatures checked:

apk add sdl3-dev
apk add sdl3-dev=3.4.18-r0   # this version

apk del sdl3-dev   # also drops dependencies nothing else needs

Package: sdl3-dev-3.4.18-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sdl3-dev
oss-get install sdl3-dev=3.4.18-r0   # this version

oss-get remove sdl3-dev   # its files only

Its dependencies stay installed: sdl3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sdl3-dev-3.4.18-r0.tar.gz (590.7 KiB)
SHA-256
8a92c18493f3e9f8768c102a00ef6ee6597072ab42c8767321068cf3d4fd32f8
Install first
libiconv, libxau, libxdmcp, libxcb, libx11, libxfixes, libxrender, libxcursor, libxext, libxi, libxrandr, libxscrnsaver, libxtst, sdl3 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sdl3-dev-3.4.18-r0.tar.gz
[ "$(openssl dgst -sha256 sdl3-dev-3.4.18-r0.tar.gz | sed 's/.*= *//')" = 8a92c18493f3e9f8768c102a00ef6ee6597072ab42c8767321068cf3d4fd32f8 ] && echo OK || echo BAD
gzip -dc sdl3-dev-3.4.18-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sdl3-dev.list
gzip -dc sdl3-dev-3.4.18-r0.tar.gz | (cd /data/oss && tar -xf -) && rm sdl3-dev-3.4.18-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sdl3-dev.list
rm var/lib/manual/sdl3-dev.list

Its dependencies stay installed: libiconv, libxau, libxdmcp, libxcb, libx11, libxfixes, libxrender, libxcursor, libxext, libxi, libxrandr, libxscrnsaver, libxtst, sdl3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is sdl3). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
