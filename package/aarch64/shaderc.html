Install and remove

A. apk

Dependencies come along, signatures checked:

apk add shaderc
apk add shaderc=2026.2-r0   # this version

apk del shaderc   # also drops dependencies nothing else needs

Package: shaderc-2026.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install shaderc
oss-get install shaderc=2026.2-r0   # this version

oss-get remove shaderc   # its files only

Its dependencies stay installed: glslang, spirv-tools. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/shaderc-2026.2-r0.tar.gz (156.2 KiB)
SHA-256
1548ecd9a6c97ba096d9b46e86f209428fbcd558d9e1152ecf5dd6cc2945fd69
Install first
spirv-tools, glslang (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/shaderc-2026.2-r0.tar.gz
[ "$(openssl dgst -sha256 shaderc-2026.2-r0.tar.gz | sed 's/.*= *//')" = 1548ecd9a6c97ba096d9b46e86f209428fbcd558d9e1152ecf5dd6cc2945fd69 ] && echo OK || echo BAD
gzip -dc shaderc-2026.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/shaderc.list
gzip -dc shaderc-2026.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm shaderc-2026.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/shaderc.list
rm var/lib/manual/shaderc.list

Its dependencies stay installed: spirv-tools, glslang. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
