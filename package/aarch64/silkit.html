Install and remove

A. apk

Dependencies come along, signatures checked:

apk add silkit
apk add silkit=5.0.8-r1   # this version

apk del silkit   # also drops dependencies nothing else needs

Package: silkit-5.0.8-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install silkit
oss-get install silkit=5.0.8-r1   # this version

oss-get remove silkit   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/silkit-5.0.8-r1.tar.gz (3.5 MiB)
SHA-256
f1caf9055bf904d406b5ef2fdd172843013075a03fbb8a29f8bb23de608b2dfd
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/silkit-5.0.8-r1.tar.gz
[ "$(openssl dgst -sha256 silkit-5.0.8-r1.tar.gz | sed 's/.*= *//')" = f1caf9055bf904d406b5ef2fdd172843013075a03fbb8a29f8bb23de608b2dfd ] && echo OK || echo BAD
gzip -dc silkit-5.0.8-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/silkit.list
gzip -dc silkit-5.0.8-r1.tar.gz | (cd /data/oss && tar -xf -) && rm silkit-5.0.8-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/silkit.list
rm var/lib/manual/silkit.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
