Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/spirv-headers-dev-1.4.321.0-r0.tar.gz
[ "$(openssl dgst -sha256 spirv-headers-dev-1.4.321.0-r0.tar.gz | sed 's/.*= *//')" = 254a6fb8ad8467b82be3befdcf0fb0f796d77ca3a8c3e3e537081862c1d4fbc1 ] && echo OK || echo BAD
gzip -dc spirv-headers-dev-1.4.321.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/spirv-headers-dev.list
gzip -dc spirv-headers-dev-1.4.321.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm spirv-headers-dev-1.4.321.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/spirv-headers-dev.list
rm var/lib/manual/spirv-headers-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
