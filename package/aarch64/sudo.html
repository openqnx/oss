Install and remove

A. apk

Dependencies come along, signatures checked:

apk add sudo
apk add sudo=1.9.17_p2-r1   # this version

apk del sudo   # also drops dependencies nothing else needs

Package: sudo-1.9.17_p2-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sudo
oss-get install sudo=1.9.17_p2-r1   # this version

oss-get remove sudo   # its files only

Its dependencies stay installed: libxcrypt, openssl, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sudo-1.9.17_p2-r1.tar.gz (962.9 KiB)
SHA-256
d81025976b438099ac75708dd1556d0fd429c16aba29c7e73497a5284388308b
Install first
libxcrypt, openssl, zlib (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sudo-1.9.17_p2-r1.tar.gz
[ "$(openssl dgst -sha256 sudo-1.9.17_p2-r1.tar.gz | sed 's/.*= *//')" = d81025976b438099ac75708dd1556d0fd429c16aba29c7e73497a5284388308b ] && echo OK || echo BAD
gzip -dc sudo-1.9.17_p2-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sudo.list
gzip -dc sudo-1.9.17_p2-r1.tar.gz | (cd /data/oss && tar -xf -) && rm sudo-1.9.17_p2-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sudo.list
rm var/lib/manual/sudo.list

Its dependencies stay installed: libxcrypt, openssl, zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
