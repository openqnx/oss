Install and remove

A. apk

Dependencies come along, signatures checked:

apk add suitesparse-dev
apk add suitesparse-dev=7.11.0-r0   # this version

apk del suitesparse-dev   # also drops dependencies nothing else needs

Package: suitesparse-dev-7.11.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install suitesparse-dev
oss-get install suitesparse-dev=7.11.0-r0   # this version

oss-get remove suitesparse-dev   # its files only

Its dependencies stay installed: suitesparse. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/suitesparse-dev-7.11.0-r0.tar.gz (2.1 MiB)
SHA-256
95c4a090ce2db0da611fb1b8462a72702ba705d61dad3540a6dacf8309e7b365
Install first
openblas, suitesparse (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/suitesparse-dev-7.11.0-r0.tar.gz
[ "$(openssl dgst -sha256 suitesparse-dev-7.11.0-r0.tar.gz | sed 's/.*= *//')" = 95c4a090ce2db0da611fb1b8462a72702ba705d61dad3540a6dacf8309e7b365 ] && echo OK || echo BAD
gzip -dc suitesparse-dev-7.11.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/suitesparse-dev.list
gzip -dc suitesparse-dev-7.11.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm suitesparse-dev-7.11.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/suitesparse-dev.list
rm var/lib/manual/suitesparse-dev.list

Its dependencies stay installed: openblas, suitesparse. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is suitesparse). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
