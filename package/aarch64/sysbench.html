Package: sysbench-1.0.20_git20250309-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sysbench
oss-get install sysbench=1.0.20_git20250309-r2   # this version

oss-get remove sysbench   # its files only

Its dependencies stay installed: luajit. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/sysbench-1.0.20_git20250309-r2.tar.gz
[ "$(openssl dgst -sha256 sysbench-1.0.20_git20250309-r2.tar.gz | sed 's/.*= *//')" = 3d730116ae8645e7ab41d786c7a354b42398d9beccc4fb8eb3ee32c7433c0db0 ] && echo OK || echo BAD
gzip -dc sysbench-1.0.20_git20250309-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sysbench.list
gzip -dc sysbench-1.0.20_git20250309-r2.tar.gz | (cd /data/oss && tar -xf -) && rm sysbench-1.0.20_git20250309-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sysbench.list
rm var/lib/manual/sysbench.list

Its dependencies stay installed: luajit. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
