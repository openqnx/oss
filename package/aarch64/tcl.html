Install and remove

A. apk

Dependencies come along, signatures checked:

apk add tcl
apk add tcl=8.6.17-r0   # this version

apk del tcl   # also drops dependencies nothing else needs

Package: tcl-8.6.17-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install tcl
oss-get install tcl=8.6.17-r0   # this version

oss-get remove tcl   # its files only

Its dependencies stay installed: zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/tcl-8.6.17-r0.tar.gz
[ "$(openssl dgst -sha256 tcl-8.6.17-r0.tar.gz | sed 's/.*= *//')" = d1c92ae0ebfd1af1de93d901a8b17e1c3a1134e12ee1edc6bf06e51cad2720b7 ] && echo OK || echo BAD
gzip -dc tcl-8.6.17-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tcl.list
gzip -dc tcl-8.6.17-r0.tar.gz | (cd /data/oss && tar -xf -) && rm tcl-8.6.17-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tcl.list
rm var/lib/manual/tcl.list

Its dependencies stay installed: zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
