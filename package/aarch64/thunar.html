Install and remove

A. apk

Dependencies come along, signatures checked:

apk add thunar
apk add thunar=4.20.0-r0   # this version

apk del thunar   # also drops dependencies nothing else needs

Package: thunar-4.20.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install thunar
oss-get install thunar=4.20.0-r0   # this version

oss-get remove thunar   # its files only

Its dependencies stay installed: at-spi2-core, cairo, exo, gdk-pixbuf, gettext, glib, gtk3, harfbuzz, libexif, libnotify, libx11, libxfce4ui, libxfce4util, pango, pcre2, xfce4-panel, xfconf, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/thunar-4.20.0-r0.tar.gz
[ "$(openssl dgst -sha256 thunar-4.20.0-r0.tar.gz | sed 's/.*= *//')" = 17356ddb98a4daf1796b8b5aa7d4bcf217e315172e69d6df325a8e4eaf69d6bf ] && echo OK || echo BAD
gzip -dc thunar-4.20.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/thunar.list
gzip -dc thunar-4.20.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm thunar-4.20.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/thunar.list
rm var/lib/manual/thunar.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, fribidi, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, hicolor-icon-theme, libxfce4util, xfconf, libxfce4ui, exo, libexif, libnotify, garcon, gtk-layer-shell, libxfce4windowing, xfce4-panel. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
