Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/tree-sitter-c-0.24.1-r0.tar.gz
[ "$(openssl dgst -sha256 tree-sitter-c-0.24.1-r0.tar.gz | sed 's/.*= *//')" = 017416d30e6ffc002b31a7a2c3273dc05fd2da9ea6f312aebf029df1d0c01cf9 ] && echo OK || echo BAD
gzip -dc tree-sitter-c-0.24.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tree-sitter-c.list
gzip -dc tree-sitter-c-0.24.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm tree-sitter-c-0.24.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tree-sitter-c.list
rm var/lib/manual/tree-sitter-c.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
