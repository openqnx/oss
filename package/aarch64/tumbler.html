B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install tumbler
oss-get install tumbler=4.20.0-r0   # this version

oss-get remove tumbler   # its files only

Its dependencies stay installed: curl, ffmpegthumbnailer, freetype, gdk-pixbuf, gettext, glib, gst-plugins-base, gstreamer, libgsf, libjpeg-turbo, libpng, libxfce4util, libxml2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/tumbler-4.20.0-r0.tar.gz
[ "$(openssl dgst -sha256 tumbler-4.20.0-r0.tar.gz | sed 's/.*= *//')" = d8f06a5b001ad417d23a2d93ce6b833b22f18d46bf10935f81417cdec1c9d0d8 ] && echo OK || echo BAD
gzip -dc tumbler-4.20.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tumbler.list
gzip -dc tumbler-4.20.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm tumbler-4.20.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tumbler.list
rm var/lib/manual/tumbler.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, bzip2, dav1d, lame, libogg, libtheora, libvorbis, libvpx, openh264, opus, x264, x265, libiconv, libunistring, ncurses, gettext, xz, ffmpeg, libjpeg-turbo, libpng, ffmpegthumbnailer, freetype, libffi, pcre2, glib, gdk-pixbuf, gstreamer, gst-plugins-base, libxml2, libgsf, libxfce4util. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
