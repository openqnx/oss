Install and remove

A. apk

Dependencies come along, signatures checked:

apk add up-cpp
apk add up-cpp=1.0.1-r1   # this version

apk del up-cpp   # also drops dependencies nothing else needs

Package: up-cpp-1.0.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install up-cpp
oss-get install up-cpp=1.0.1-r1   # this version

oss-get remove up-cpp   # its files only

Its dependencies stay installed: abseil, protobuf, up-core-api. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/up-cpp-1.0.1-r1.tar.gz (76.2 KiB)
SHA-256
88af7b38f88a6d89227fd00eaae4af5cf0c3472b9388f6a697f2cf43a6c9b0c7
Install first
abseil, zlib, protobuf, up-core-api (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/up-cpp-1.0.1-r1.tar.gz
[ "$(openssl dgst -sha256 up-cpp-1.0.1-r1.tar.gz | sed 's/.*= *//')" = 88af7b38f88a6d89227fd00eaae4af5cf0c3472b9388f6a697f2cf43a6c9b0c7 ] && echo OK || echo BAD
gzip -dc up-cpp-1.0.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/up-cpp.list
gzip -dc up-cpp-1.0.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm up-cpp-1.0.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/up-cpp.list
rm var/lib/manual/up-cpp.list

Its dependencies stay installed: abseil, zlib, protobuf, up-core-api. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
