Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vala-dev
apk add vala-dev=0.56.18-r0   # this version

apk del vala-dev   # also drops dependencies nothing else needs

Package: vala-dev-0.56.18-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vala-dev
oss-get install vala-dev=0.56.18-r0   # this version

oss-get remove vala-dev   # its files only

Its dependencies stay installed: vala. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/vala-dev-0.56.18-r0.tar.gz
[ "$(openssl dgst -sha256 vala-dev-0.56.18-r0.tar.gz | sed 's/.*= *//')" = 5c66681eee41d8b3328c30b1f1e71fdc7feb9141db12325900206e690ce5ccb5 ] && echo OK || echo BAD
gzip -dc vala-dev-0.56.18-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vala-dev.list
gzip -dc vala-dev-0.56.18-r0.tar.gz | (cd /data/oss && tar -xf -) && rm vala-dev-0.56.18-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vala-dev.list
rm var/lib/manual/vala-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, vala. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is vala). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
