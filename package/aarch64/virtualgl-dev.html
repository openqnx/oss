Install and remove

A. apk

Dependencies come along, signatures checked:

apk add virtualgl-dev
apk add virtualgl-dev=3.1.5-r0   # this version

apk del virtualgl-dev   # also drops dependencies nothing else needs

Package: virtualgl-dev-3.1.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install virtualgl-dev
oss-get install virtualgl-dev=3.1.5-r0   # this version

oss-get remove virtualgl-dev   # its files only

Its dependencies stay installed: virtualgl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/virtualgl-dev-3.1.5-r0.tar.gz (312.8 KiB)
SHA-256
ec6a39bd0172db58cc07dc74f9890159aef91a35f6d7d5934f1dbfa0e923b174
Install first
libjpeg-turbo, libxau, libxdmcp, libxcb, libx11, libxext, virtualgl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/virtualgl-dev-3.1.5-r0.tar.gz
[ "$(openssl dgst -sha256 virtualgl-dev-3.1.5-r0.tar.gz | sed 's/.*= *//')" = ec6a39bd0172db58cc07dc74f9890159aef91a35f6d7d5934f1dbfa0e923b174 ] && echo OK || echo BAD
gzip -dc virtualgl-dev-3.1.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/virtualgl-dev.list
gzip -dc virtualgl-dev-3.1.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm virtualgl-dev-3.1.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/virtualgl-dev.list
rm var/lib/manual/virtualgl-dev.list

Its dependencies stay installed: libjpeg-turbo, libxau, libxdmcp, libxcb, libx11, libxext, virtualgl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is virtualgl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
