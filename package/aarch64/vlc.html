Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vlc
apk add vlc=3.0.21-r0   # this version

apk del vlc   # also drops dependencies nothing else needs

Package: vlc-3.0.21-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vlc
oss-get install vlc=3.0.21-r0   # this version

oss-get remove vlc   # its files only

Its dependencies stay installed: bzip2, libiconv, lz4, openssl, xz, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/vlc-3.0.21-r0.tar.gz (220.5 MiB)
SHA-256
b26df6301b57dd20395f00c5ef9fb37d0a5edbceb09db0822526bf8b16c5651b
Install first
bzip2, libiconv, lz4, openssl, libunistring, ncurses, gettext, xz, zstd (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/vlc-3.0.21-r0.tar.gz
[ "$(openssl dgst -sha256 vlc-3.0.21-r0.tar.gz | sed 's/.*= *//')" = b26df6301b57dd20395f00c5ef9fb37d0a5edbceb09db0822526bf8b16c5651b ] && echo OK || echo BAD
gzip -dc vlc-3.0.21-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vlc.list
gzip -dc vlc-3.0.21-r0.tar.gz | (cd /data/oss && tar -xf -) && rm vlc-3.0.21-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vlc.list
rm var/lib/manual/vlc.list

Its dependencies stay installed: bzip2, libiconv, lz4, openssl, libunistring, ncurses, gettext, xz, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
