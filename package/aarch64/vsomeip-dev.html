Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vsomeip-dev
apk add vsomeip-dev=3.5.6-r1   # this version

apk del vsomeip-dev   # also drops dependencies nothing else needs

Package: vsomeip-dev-3.5.6-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vsomeip-dev
oss-get install vsomeip-dev=3.5.6-r1   # this version

oss-get remove vsomeip-dev   # its files only

Its dependencies stay installed: vsomeip. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256

Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, vsomeip (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/vsomeip-dev-3.5.6-r1.tar.gz
[ "$(openssl dgst -sha256 vsomeip-dev-3.5.6-r1.tar.gz | sed 's/.*= *//')" = 7414fbcac2629c5cf67c2858ed513be3783854fe26361bc4d19dfe2dbed958ed ] && echo OK || echo BAD
gzip -dc vsomeip-dev-3.5.6-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vsomeip-dev.list
gzip -dc vsomeip-dev-3.5.6-r1.tar.gz | (cd /data/oss && tar -xf -) && rm vsomeip-dev-3.5.6-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vsomeip-dev.list
rm var/lib/manual/vsomeip-dev.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, vsomeip. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is vsomeip). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
