Install and remove

A. apk

Dependencies come along, signatures checked:

apk add webkitgtk-dev
apk add webkitgtk-dev=2.44.4-r0   # this version

apk del webkitgtk-dev   # also drops dependencies nothing else needs

Package: webkitgtk-dev-2.44.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install webkitgtk-dev
oss-get install webkitgtk-dev=2.44.4-r0   # this version

oss-get remove webkitgtk-dev   # its files only

Its dependencies stay installed: webkitgtk. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/webkitgtk-dev-2.44.4-r0.tar.gz
[ "$(openssl dgst -sha256 webkitgtk-dev-2.44.4-r0.tar.gz | sed 's/.*= *//')" = 0bef93d7b4d20c688b4d9e5ae9f9e1956e176c3dc7ded1e48f2bb35aeb22ce70 ] && echo OK || echo BAD
gzip -dc webkitgtk-dev-2.44.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/webkitgtk-dev.list
gzip -dc webkitgtk-dev-2.44.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm webkitgtk-dev-2.44.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/webkitgtk-dev.list
rm var/lib/manual/webkitgtk-dev.list

Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is webkitgtk). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
