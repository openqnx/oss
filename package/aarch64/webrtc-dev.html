B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install webrtc-dev
oss-get install webrtc-dev=0_git-r0   # this version

oss-get remove webrtc-dev   # its files only

Its dependencies stay installed: webrtc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

[ "$(openssl dgst -sha256 webrtc-dev-0_git-r0.tar.gz | sed 's/.*= *//')" = 8ebbebf2cd6e21b146b66e65c2a189d59812506359951ca96b6d5ad39b9651c6 ] && echo OK || echo BAD

gzip -dc webrtc-dev-0_git-r0.tar.gz | (cd /data/oss && tar -xf -) && rm webrtc-dev-0_git-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/webrtc-dev.list
rm var/lib/manual/webrtc-dev.list

Its dependencies stay installed: webrtc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is webrtc). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
