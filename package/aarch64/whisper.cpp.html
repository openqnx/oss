Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/whisper.cpp-0_git20260728-r2.tar.gz
[ "$(openssl dgst -sha256 whisper.cpp-0_git20260728-r2.tar.gz | sed 's/.*= *//')" = 355a2adbe123747cf4cae9b03d2d7b438cfff6f5ea363cb9d838d070e13f9bfa ] && echo OK || echo BAD
gzip -dc whisper.cpp-0_git20260728-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/whisper.cpp.list
gzip -dc whisper.cpp-0_git20260728-r2.tar.gz | (cd /data/oss && tar -xf -) && rm whisper.cpp-0_git20260728-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/whisper.cpp.list
rm var/lib/manual/whisper.cpp.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
