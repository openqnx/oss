Install and remove

A. apk

Dependencies come along, signatures checked:

apk add x265
apk add x265=3.6-r0   # this version

apk del x265   # also drops dependencies nothing else needs

Package: x265-3.6-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install x265
oss-get install x265=3.6-r0   # this version

oss-get remove x265   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/x265-3.6-r0.tar.gz
[ "$(openssl dgst -sha256 x265-3.6-r0.tar.gz | sed 's/.*= *//')" = 444d1e1f489fe7ff629223a5252812b0e6d3394d424177424839d7fa7d80f8ec ] && echo OK || echo BAD
gzip -dc x265-3.6-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/x265.list
gzip -dc x265-3.6-r0.tar.gz | (cd /data/oss && tar -xf -) && rm x265-3.6-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/x265.list
rm var/lib/manual/x265.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
