Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xfce4-dev-tools
apk add xfce4-dev-tools=4.21.0-r1   # this version

apk del xfce4-dev-tools   # also drops dependencies nothing else needs

Package: xfce4-dev-tools-4.21.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xfce4-dev-tools
oss-get install xfce4-dev-tools=4.21.0-r1   # this version

oss-get remove xfce4-dev-tools   # its files only

Its dependencies stay installed: autoconf, automake, gettext, glib, make, python3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install first
libiconv, m4, libxcrypt, perl, autoconf, automake, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, make, bzip2, expat, gdbm, openssl, readline, sqlite, xz, zstd, python3 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/xfce4-dev-tools-4.21.0-r1.tar.gz
[ "$(openssl dgst -sha256 xfce4-dev-tools-4.21.0-r1.tar.gz | sed 's/.*= *//')" = 59cb962f283e257cf574bd4f7be8f2c4df293384f3021ae5834a25a62f927ffa ] && echo OK || echo BAD
gzip -dc xfce4-dev-tools-4.21.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xfce4-dev-tools.list
gzip -dc xfce4-dev-tools-4.21.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm xfce4-dev-tools-4.21.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xfce4-dev-tools.list
rm var/lib/manual/xfce4-dev-tools.list

Its dependencies stay installed: libiconv, m4, libxcrypt, perl, autoconf, automake, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, make, bzip2, expat, gdbm, openssl, readline, sqlite, xz, zstd, python3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
