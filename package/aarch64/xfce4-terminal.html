Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xfce4-terminal
apk add xfce4-terminal=1.1.5-r0   # this version

apk del xfce4-terminal   # also drops dependencies nothing else needs

Package: xfce4-terminal-1.1.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xfce4-terminal
oss-get install xfce4-terminal=1.1.5-r0   # this version

oss-get remove xfce4-terminal   # its files only

Its dependencies stay installed: at-spi2-core, cairo, gdk-pixbuf, glib, gtk-layer-shell, gtk3, libxfce4ui, libxfce4util, pango, pcre2, vte, xfconf. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/xfce4-terminal-1.1.5-r0.tar.gz
[ "$(openssl dgst -sha256 xfce4-terminal-1.1.5-r0.tar.gz | sed 's/.*= *//')" = 4ed613eea9e1a9ef9d2bb04586f68aeba21e8d3d1247d3b87adc68c8ad96d0c2 ] && echo OK || echo BAD
gzip -dc xfce4-terminal-1.1.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xfce4-terminal.list
gzip -dc xfce4-terminal-1.1.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xfce4-terminal-1.1.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xfce4-terminal.list
rm var/lib/manual/xfce4-terminal.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, fribidi, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, gtk-layer-shell, hicolor-icon-theme, libxfce4util, xfconf, libxfce4ui, gmp, libidn2, libtasn1, nettle, zstd, gnutls, graphene, libwebp, libtiff, gtk4, lz4, vte. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
