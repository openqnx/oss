Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xfconf
apk add xfconf=4.20.0-r1   # this version

apk del xfconf   # also drops dependencies nothing else needs

Package: xfconf-4.20.0-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xfconf
oss-get install xfconf=4.20.0-r1   # this version

oss-get remove xfconf   # its files only

Its dependencies stay installed: gettext, glib, libxfce4util. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/xfconf-4.20.0-r1.tar.gz (206.5 KiB)
SHA-256
1565358b741417fcc8b9d248513c792c14ecf6ce7905c2a53b96900ce74b7ae1
Install first
libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxfce4util (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/xfconf-4.20.0-r1.tar.gz
[ "$(openssl dgst -sha256 xfconf-4.20.0-r1.tar.gz | sed 's/.*= *//')" = 1565358b741417fcc8b9d248513c792c14ecf6ce7905c2a53b96900ce74b7ae1 ] && echo OK || echo BAD
gzip -dc xfconf-4.20.0-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xfconf.list
gzip -dc xfconf-4.20.0-r1.tar.gz | (cd /data/oss && tar -xf -) && rm xfconf-4.20.0-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xfconf.list
rm var/lib/manual/xfconf.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxfce4util. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
