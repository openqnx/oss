B-2. By hand

SHA-256

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/xvidcore-1.3.7-r0.tar.gz
[ "$(openssl dgst -sha256 xvidcore-1.3.7-r0.tar.gz | sed 's/.*= *//')" = 9b208843e84a704f4b5c6292f0fc078347b7ce67cca68cd80b5c3499c97f2cf4 ] && echo OK || echo BAD
gzip -dc xvidcore-1.3.7-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xvidcore.list
gzip -dc xvidcore-1.3.7-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xvidcore-1.3.7-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xvidcore.list
rm var/lib/manual/xvidcore.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
