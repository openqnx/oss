Install and remove

A. apk

Dependencies come along, signatures checked:

apk add zenoh-c-dev
apk add zenoh-c-dev=1.2.1-r0   # this version

apk del zenoh-c-dev   # also drops dependencies nothing else needs

Package: zenoh-c-dev-1.2.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install zenoh-c-dev
oss-get install zenoh-c-dev=1.2.1-r0   # this version

oss-get remove zenoh-c-dev   # its files only

Its dependencies stay installed: zenoh-c. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Install first
zenoh-c (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/zenoh-c-dev-1.2.1-r0.tar.gz
[ "$(openssl dgst -sha256 zenoh-c-dev-1.2.1-r0.tar.gz | sed 's/.*= *//')" = c51c1569646399ce33c3618f8fe3360a0eaae147afde70a3b26a10426efed4dd ] && echo OK || echo BAD
gzip -dc zenoh-c-dev-1.2.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/zenoh-c-dev.list
gzip -dc zenoh-c-dev-1.2.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm zenoh-c-dev-1.2.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/zenoh-c-dev.list
rm var/lib/manual/zenoh-c-dev.list

Its dependencies stay installed: zenoh-c. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is zenoh-c). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
