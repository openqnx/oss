Install and remove

A. apk

Dependencies come along, signatures checked:

apk add zlib
apk add zlib=1.3.1-r0   # this version

apk del zlib   # also drops dependencies nothing else needs

Package: zlib-1.3.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install zlib
oss-get install zlib=1.3.1-r0   # this version

oss-get remove zlib   # its files only

B-2. By hand

Archive

SHA-256
47c13ccaa6bc3f214d2e97ed2f1dd7bdd65ba6a2cb244914b11d99696abd174b
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-aarch64-m-z/zlib-1.3.1-r0.tar.gz
[ "$(openssl dgst -sha256 zlib-1.3.1-r0.tar.gz | sed 's/.*= *//')" = 47c13ccaa6bc3f214d2e97ed2f1dd7bdd65ba6a2cb244914b11d99696abd174b ] && echo OK || echo BAD
gzip -dc zlib-1.3.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/zlib.list
gzip -dc zlib-1.3.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm zlib-1.3.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/zlib.list
rm var/lib/manual/zlib.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
