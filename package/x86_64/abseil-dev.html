Package: abseil-dev-20240722.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install abseil-dev
oss-get install abseil-dev=20240722.0-r0   # this version

oss-get remove abseil-dev   # its files only

Its dependencies stay installed: abseil. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Remove: delete exactly the files it installed, then the list:

rm var/lib/manual/abseil-dev.list

Its dependencies stay installed: abseil. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is abseil).
