mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/abseil-20240722.0-r0.tar.gz
[ "$(openssl dgst -sha256 abseil-20240722.0-r0.tar.gz | sed 's/.*= *//')" = 98ce978aff94c972c98a05aa17cf4e00fa07b9c0deeb343fe3bac87a103795e7 ] && echo OK || echo BAD
gzip -dc abseil-20240722.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/abseil.list
gzip -dc abseil-20240722.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm abseil-20240722.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/abseil.list
rm var/lib/manual/abseil.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
