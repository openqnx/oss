Install and remove

A. apk

Dependencies come along, signatures checked:

apk add acado-dev
apk add acado-dev=1.2.2_beta-r0   # this version

apk del acado-dev   # also drops dependencies nothing else needs

Package: acado-dev-1.2.2_beta-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install acado-dev
oss-get install acado-dev=1.2.2_beta-r0   # this version

oss-get remove acado-dev   # its files only

Its dependencies stay installed: acado. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/acado-dev-1.2.2_beta-r0.tar.gz
[ "$(openssl dgst -sha256 acado-dev-1.2.2_beta-r0.tar.gz | sed 's/.*= *//')" = 6acbdc7e4775f0e7303c2cf2e8821f513f4a611d4001896be462e18620b2a3f5 ] && echo OK || echo BAD
gzip -dc acado-dev-1.2.2_beta-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/acado-dev.list
gzip -dc acado-dev-1.2.2_beta-r0.tar.gz | (cd /data/oss && tar -xf -) && rm acado-dev-1.2.2_beta-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/acado-dev.list
rm var/lib/manual/acado-dev.list

Its dependencies stay installed: acado. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is acado). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
