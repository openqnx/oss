Install and remove

A. apk

Dependencies come along, signatures checked:

apk add acado
apk add acado=1.2.2_beta-r0   # this version

apk del acado   # also drops dependencies nothing else needs

Package: acado-1.2.2_beta-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install acado
oss-get install acado=1.2.2_beta-r0   # this version

oss-get remove acado   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/acado-1.2.2_beta-r0.tar.gz (3.6 MiB)
SHA-256
88b68080582630d8ad7eca4cfc3b66d16e29d9e22c873c4afd41ad0b0089baca
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/acado-1.2.2_beta-r0.tar.gz
[ "$(openssl dgst -sha256 acado-1.2.2_beta-r0.tar.gz | sed 's/.*= *//')" = 88b68080582630d8ad7eca4cfc3b66d16e29d9e22c873c4afd41ad0b0089baca ] && echo OK || echo BAD
gzip -dc acado-1.2.2_beta-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/acado.list
gzip -dc acado-1.2.2_beta-r0.tar.gz | (cd /data/oss && tar -xf -) && rm acado-1.2.2_beta-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/acado.list
rm var/lib/manual/acado.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
