Install and remove

A. apk

apk add adwaita-icon-theme

Package: adwaita-icon-theme-51.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install adwaita-icon-theme
oss-get install adwaita-icon-theme=51.0-r0   # this version

oss-get remove adwaita-icon-theme   # its files only

Its dependencies stay installed: hicolor-icon-theme. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/adwaita-icon-theme-51.0-r0.tar.gz
[ "$(openssl dgst -sha256 adwaita-icon-theme-51.0-r0.tar.gz | sed 's/.*= *//')" = ae0862ac885d2e5e0e399a32c688f04ac0007eb4d4b39f7549797bc0bd22480a ] && echo OK || echo BAD
gzip -dc adwaita-icon-theme-51.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/adwaita-icon-theme.list
gzip -dc adwaita-icon-theme-51.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm adwaita-icon-theme-51.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/adwaita-icon-theme.list
rm var/lib/manual/adwaita-icon-theme.list

Its dependencies stay installed: hicolor-icon-theme. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
