A. apk

apk add apr-util

apk del apr-util   # also drops dependencies nothing else needs

Package: apr-util-1.6.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install apr-util
oss-get install apr-util=1.6.5-r0   # this version

oss-get remove apr-util   # its files only

Its dependencies stay installed: apr, expat, libiconv, libxcrypt, openssl, sqlite. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/apr-util-1.6.5-r0.tar.gz (101.3 KiB)
SHA-256
be8ea30857051fa9b744e442bfbb0517ec2bace55551c5084d72938e27742b7e
Install first
apr, expat, libiconv, libxcrypt, openssl, zlib, sqlite (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/apr-util-1.6.5-r0.tar.gz
[ "$(openssl dgst -sha256 apr-util-1.6.5-r0.tar.gz | sed 's/.*= *//')" = be8ea30857051fa9b744e442bfbb0517ec2bace55551c5084d72938e27742b7e ] && echo OK || echo BAD
gzip -dc apr-util-1.6.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/apr-util.list
gzip -dc apr-util-1.6.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm apr-util-1.6.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/apr-util.list
rm var/lib/manual/apr-util.list

Its dependencies stay installed: apr, expat, libiconv, libxcrypt, openssl, zlib, sqlite. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
