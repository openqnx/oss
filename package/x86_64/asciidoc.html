Install and remove

A. apk

Dependencies come along, signatures checked:

apk add asciidoc
apk add asciidoc=10.2.1-r0   # this version

apk del asciidoc   # also drops dependencies nothing else needs

Package: asciidoc-10.2.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install asciidoc
oss-get install asciidoc=10.2.1-r0   # this version

oss-get remove asciidoc   # its files only

Its dependencies stay installed: docbook-xsl, python3, xsltproc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

SHA-256

Install first

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/asciidoc-10.2.1-r0.tar.gz
[ "$(openssl dgst -sha256 asciidoc-10.2.1-r0.tar.gz | sed 's/.*= *//')" = ae49df5b2856710c06f11bc48ccbeb6ae83c7541e6e6a3a4c43409fad07710a5 ] && echo OK || echo BAD
gzip -dc asciidoc-10.2.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/asciidoc.list
gzip -dc asciidoc-10.2.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm asciidoc-10.2.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/asciidoc.list
rm var/lib/manual/asciidoc.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt, docbook-xsl, bzip2, expat, gdbm, libffi, openssl, readline, sqlite, zstd, python3, xsltproc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
