Install and remove

A. apk

Dependencies come along, signatures checked:

apk add autoconf
apk add autoconf=2.72-r1   # this version

apk del autoconf   # also drops dependencies nothing else needs

Package: autoconf-2.72-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install autoconf
oss-get install autoconf=2.72-r1   # this version

oss-get remove autoconf   # its files only

Its dependencies stay installed: m4, perl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/autoconf-2.72-r1.tar.gz (572.3 KiB)
SHA-256
da75a03dd74668df81e6527bcf9e9f09a550dd91c6ac01abfca4e03a34139a32
Install first
libiconv, m4, libxcrypt, perl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/autoconf-2.72-r1.tar.gz
[ "$(openssl dgst -sha256 autoconf-2.72-r1.tar.gz | sed 's/.*= *//')" = da75a03dd74668df81e6527bcf9e9f09a550dd91c6ac01abfca4e03a34139a32 ] && echo OK || echo BAD
gzip -dc autoconf-2.72-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/autoconf.list
gzip -dc autoconf-2.72-r1.tar.gz | (cd /data/oss && tar -xf -) && rm autoconf-2.72-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/autoconf.list
rm var/lib/manual/autoconf.list

Its dependencies stay installed: libiconv, m4, libxcrypt, perl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
