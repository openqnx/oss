A. apk

Dependencies come along, signatures checked:

apk add aws-crt-cpp-dev
apk add aws-crt-cpp-dev=0.38.5-r0   # this version

apk del aws-crt-cpp-dev   # also drops dependencies nothing else needs

Package: aws-crt-cpp-dev-0.38.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install aws-crt-cpp-dev
oss-get install aws-crt-cpp-dev=0.38.5-r0   # this version

oss-get remove aws-crt-cpp-dev   # its files only

Its dependencies stay installed: aws-crt-cpp. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/aws-crt-cpp-dev-0.38.5-r0.tar.gz
[ "$(openssl dgst -sha256 aws-crt-cpp-dev-0.38.5-r0.tar.gz | sed 's/.*= *//')" = 9c1baf1a8747e5927b54a20911e8b15861cebb0481de8484cf47f1a63801313e ] && echo OK || echo BAD
gzip -dc aws-crt-cpp-dev-0.38.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/aws-crt-cpp-dev.list
gzip -dc aws-crt-cpp-dev-0.38.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm aws-crt-cpp-dev-0.38.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/aws-crt-cpp-dev.list
rm var/lib/manual/aws-crt-cpp-dev.list

Its dependencies stay installed: aws-c-common, openssl, aws-c-cal, aws-c-compression, s2n-tls, aws-c-io, aws-c-http, aws-c-sdkutils, aws-c-auth, aws-checksums, aws-c-event-stream, aws-c-mqtt, aws-c-s3, aws-crt-cpp. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is aws-crt-cpp). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
