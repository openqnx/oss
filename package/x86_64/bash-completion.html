B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install bash-completion
oss-get install bash-completion=2.18.0-r0   # this version

oss-get remove bash-completion   # its files only

Its dependencies stay installed: bash. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.
