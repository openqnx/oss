Install and remove

A. apk

Dependencies come along, signatures checked:

apk add binutils
apk add binutils=2.43-r0   # this version

apk del binutils   # also drops dependencies nothing else needs

Package: binutils-2.43-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install binutils
oss-get install binutils=2.43-r0   # this version

oss-get remove binutils   # its files only

Its dependencies stay installed: zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/binutils-2.43-r0.tar.gz (15.9 MiB)
SHA-256
c7a5c0ac14124acb0598fb8dd3402d4cf299bf82bee9044600761b3adff1e70c
Install first
zlib, zstd (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/binutils-2.43-r0.tar.gz
[ "$(openssl dgst -sha256 binutils-2.43-r0.tar.gz | sed 's/.*= *//')" = c7a5c0ac14124acb0598fb8dd3402d4cf299bf82bee9044600761b3adff1e70c ] && echo OK || echo BAD
gzip -dc binutils-2.43-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/binutils.list
gzip -dc binutils-2.43-r0.tar.gz | (cd /data/oss && tar -xf -) && rm binutils-2.43-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/binutils.list
rm var/lib/manual/binutils.list

Its dependencies stay installed: zlib, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
