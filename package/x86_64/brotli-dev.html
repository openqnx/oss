Install and remove

A. apk

Dependencies come along, signatures checked:

apk add brotli-dev
apk add brotli-dev=1.1.0-r0   # this version

apk del brotli-dev   # also drops dependencies nothing else needs

Package: brotli-dev-1.1.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install brotli-dev
oss-get install brotli-dev=1.1.0-r0   # this version

oss-get remove brotli-dev   # its files only

Its dependencies stay installed: brotli. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/brotli-dev-1.1.0-r0.tar.gz
[ "$(openssl dgst -sha256 brotli-dev-1.1.0-r0.tar.gz | sed 's/.*= *//')" = 618ce8c59d55f1c6b5aef7a52f04786134be2d59c02b1479cccfda2a2546fd43 ] && echo OK || echo BAD
gzip -dc brotli-dev-1.1.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/brotli-dev.list
gzip -dc brotli-dev-1.1.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm brotli-dev-1.1.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/brotli-dev.list
rm var/lib/manual/brotli-dev.list

Its dependencies stay installed: brotli. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is brotli). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
