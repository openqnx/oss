Install and remove

A. apk

Dependencies come along, signatures checked:

apk add bullet3-dev
apk add bullet3-dev=3.25-r0   # this version

apk del bullet3-dev   # also drops dependencies nothing else needs

Package: bullet3-dev-3.25-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install bullet3-dev
oss-get install bullet3-dev=3.25-r0   # this version

oss-get remove bullet3-dev   # its files only

Its dependencies stay installed: bullet3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/bullet3-dev-3.25-r0.tar.gz (615.8 KiB)
SHA-256
1a868f411452f0bda9a68f47c9a5bed9d76c937b63a8913ed4bc052eb4178e99

bullet3 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/bullet3-dev-3.25-r0.tar.gz
[ "$(openssl dgst -sha256 bullet3-dev-3.25-r0.tar.gz | sed 's/.*= *//')" = 1a868f411452f0bda9a68f47c9a5bed9d76c937b63a8913ed4bc052eb4178e99 ] && echo OK || echo BAD
gzip -dc bullet3-dev-3.25-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/bullet3-dev.list
gzip -dc bullet3-dev-3.25-r0.tar.gz | (cd /data/oss && tar -xf -) && rm bullet3-dev-3.25-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/bullet3-dev.list
rm var/lib/manual/bullet3-dev.list

Its dependencies stay installed: bullet3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is bullet3). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
