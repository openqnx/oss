Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/bullet3-3.25-r0.tar.gz
[ "$(openssl dgst -sha256 bullet3-3.25-r0.tar.gz | sed 's/.*= *//')" = 55e38610543863271cc4cc8a937004d543a8175fbcb39ef4a9274894d4dbdee7 ] && echo OK || echo BAD
gzip -dc bullet3-3.25-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/bullet3.list
gzip -dc bullet3-3.25-r0.tar.gz | (cd /data/oss && tar -xf -) && rm bullet3-3.25-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/bullet3.list
rm var/lib/manual/bullet3.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
