Install and remove

A. apk

Dependencies come along, signatures checked:

apk add c-ares-dev
apk add c-ares-dev=1.34.3-r0   # this version

apk del c-ares-dev   # also drops dependencies nothing else needs

Package: c-ares-dev-1.34.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install c-ares-dev
oss-get install c-ares-dev=1.34.3-r0   # this version

oss-get remove c-ares-dev   # its files only

Its dependencies stay installed: c-ares. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/c-ares-dev-1.34.3-r0.tar.gz
[ "$(openssl dgst -sha256 c-ares-dev-1.34.3-r0.tar.gz | sed 's/.*= *//')" = ccc43507d45c4823062432149753aa0d94231587904c94f19e2c50b85c571d7a ] && echo OK || echo BAD
gzip -dc c-ares-dev-1.34.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/c-ares-dev.list
gzip -dc c-ares-dev-1.34.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm c-ares-dev-1.34.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/c-ares-dev.list
rm var/lib/manual/c-ares-dev.list

Its dependencies stay installed: c-ares. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is c-ares). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
