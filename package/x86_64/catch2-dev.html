Install and remove

A. apk

Dependencies come along, signatures checked:

apk add catch2-dev
apk add catch2-dev=3.7.1-r0   # this version

apk del catch2-dev   # also drops dependencies nothing else needs

Package: catch2-dev-3.7.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install catch2-dev
oss-get install catch2-dev=3.7.1-r0   # this version

oss-get remove catch2-dev   # its files only

Its dependencies stay installed: catch2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/catch2-dev-3.7.1-r0.tar.gz
[ "$(openssl dgst -sha256 catch2-dev-3.7.1-r0.tar.gz | sed 's/.*= *//')" = 23d6ccf1eb6ef7084e34b19684885ce28c98d48010a7e56bd3f78159606b76c4 ] && echo OK || echo BAD
gzip -dc catch2-dev-3.7.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/catch2-dev.list
gzip -dc catch2-dev-3.7.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm catch2-dev-3.7.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/catch2-dev.list
rm var/lib/manual/catch2-dev.list

Its dependencies stay installed: catch2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is catch2). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
