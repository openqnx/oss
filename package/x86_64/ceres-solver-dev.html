B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ceres-solver-dev
oss-get install ceres-solver-dev=2.2.0-r0   # this version

oss-get remove ceres-solver-dev   # its files only

Its dependencies stay installed: ceres-solver. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/ceres-solver-dev-2.2.0-r0.tar.gz
[ "$(openssl dgst -sha256 ceres-solver-dev-2.2.0-r0.tar.gz | sed 's/.*= *//')" = 92316f3523483bf3c60baaaab02c6063bed9f28ab4f18e98796943104899efb4 ] && echo OK || echo BAD
gzip -dc ceres-solver-dev-2.2.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ceres-solver-dev.list
gzip -dc ceres-solver-dev-2.2.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm ceres-solver-dev-2.2.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ceres-solver-dev.list
rm var/lib/manual/ceres-solver-dev.list

Its dependencies stay installed: gflags, glog, ceres-solver. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is ceres-solver). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
