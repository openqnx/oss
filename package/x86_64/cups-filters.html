Install and remove

A. apk

Dependencies come along, signatures checked:

apk add cups-filters
apk add cups-filters=1.28.17-r0   # this version

apk del cups-filters   # also drops dependencies nothing else needs

Package: cups-filters-1.28.17-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install cups-filters
oss-get install cups-filters=1.28.17-r0   # this version

oss-get remove cups-filters   # its files only

Its dependencies stay installed: avahi, cups, fontconfig, freetype, gettext, glib, lcms2, libexif, libiconv, libjpeg-turbo, libpng, libtiff, libxcrypt, openssl, poppler, qpdf, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/cups-filters-1.28.17-r0.tar.gz
[ "$(openssl dgst -sha256 cups-filters-1.28.17-r0.tar.gz | sed 's/.*= *//')" = 39dfecd5cf3523006d499a370e80075d5de80d975bc3374a36a49674b0732a1a ] && echo OK || echo BAD
gzip -dc cups-filters-1.28.17-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/cups-filters.list
gzip -dc cups-filters-1.28.17-r0.tar.gz | (cd /data/oss && tar -xf -) && rm cups-filters-1.28.17-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/cups-filters.list
rm var/lib/manual/cups-filters.list

Its dependencies stay installed: expat, dbus, libdaemon, avahi, libiconv, libxcrypt, openssl, zlib, cups, brotli, bzip2, libpng, freetype, fontconfig, libunistring, ncurses, gettext, libffi, pcre2, glib, lcms2, libexif, libjpeg-turbo, libwebp, xz, zstd, libtiff, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, openjpeg, poppler, qpdf. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
