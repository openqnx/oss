Install and remove

A. apk

Dependencies come along, signatures checked:

apk add curl-dev
apk add curl-dev=8.11.1-r1   # this version

apk del curl-dev   # also drops dependencies nothing else needs

Package: curl-dev-8.11.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install curl-dev
oss-get install curl-dev=8.11.1-r1   # this version

oss-get remove curl-dev   # its files only

Its dependencies stay installed: curl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/curl-dev-8.11.1-r1.tar.gz (414.7 KiB)
SHA-256
7d047f76e08cfcec68a5adf670981f79e419389ba1d16ec7fd70094afb7e7424
Install first
brotli, c-ares, nghttp2, openssl, zlib, zstd, curl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/curl-dev-8.11.1-r1.tar.gz
[ "$(openssl dgst -sha256 curl-dev-8.11.1-r1.tar.gz | sed 's/.*= *//')" = 7d047f76e08cfcec68a5adf670981f79e419389ba1d16ec7fd70094afb7e7424 ] && echo OK || echo BAD
gzip -dc curl-dev-8.11.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/curl-dev.list
gzip -dc curl-dev-8.11.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm curl-dev-8.11.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/curl-dev.list
rm var/lib/manual/curl-dev.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is curl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
