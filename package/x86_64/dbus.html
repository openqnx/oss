Install and remove

A. apk

Dependencies come along, signatures checked:

apk add dbus
apk add dbus=1.16.0-r3   # this version

apk del dbus   # also drops dependencies nothing else needs

Package: dbus-1.16.0-r3.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install dbus
oss-get install dbus=1.16.0-r3   # this version

oss-get remove dbus   # its files only

Its dependencies stay installed: expat. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/dbus-1.16.0-r3.tar.gz (305.7 KiB)
SHA-256
d1f07ca91339d73f005aa7071311686c6acfc425b80717ecbdc14d31a858c3a1
Install first
expat (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/dbus-1.16.0-r3.tar.gz
[ "$(openssl dgst -sha256 dbus-1.16.0-r3.tar.gz | sed 's/.*= *//')" = d1f07ca91339d73f005aa7071311686c6acfc425b80717ecbdc14d31a858c3a1 ] && echo OK || echo BAD
gzip -dc dbus-1.16.0-r3.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/dbus.list
gzip -dc dbus-1.16.0-r3.tar.gz | (cd /data/oss && tar -xf -) && rm dbus-1.16.0-r3.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/dbus.list
rm var/lib/manual/dbus.list

Its dependencies stay installed: expat. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
