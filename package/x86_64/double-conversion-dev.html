Package: double-conversion-dev-3.3.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install double-conversion-dev
oss-get install double-conversion-dev=3.3.0-r0   # this version

oss-get remove double-conversion-dev   # its files only

Its dependencies stay installed: double-conversion. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/double-conversion-dev-3.3.0-r0.tar.gz
[ "$(openssl dgst -sha256 double-conversion-dev-3.3.0-r0.tar.gz | sed 's/.*= *//')" = fb34fb59fbbb487568bf4430104414cdd2abec150e37d29056edea4017543a72 ] && echo OK || echo BAD
gzip -dc double-conversion-dev-3.3.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/double-conversion-dev.list
gzip -dc double-conversion-dev-3.3.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm double-conversion-dev-3.3.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/double-conversion-dev.list
rm var/lib/manual/double-conversion-dev.list

Its dependencies stay installed: double-conversion. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is double-conversion). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
