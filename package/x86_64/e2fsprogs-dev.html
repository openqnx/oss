Install and remove

A. apk

Dependencies come along, signatures checked:

apk add e2fsprogs-dev
apk add e2fsprogs-dev=1.47.4-r1   # this version

apk del e2fsprogs-dev   # also drops dependencies nothing else needs

Package: e2fsprogs-dev-1.47.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install e2fsprogs-dev
oss-get install e2fsprogs-dev=1.47.4-r1   # this version

oss-get remove e2fsprogs-dev   # its files only

Its dependencies stay installed: e2fsprogs. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/e2fsprogs-dev-1.47.4-r1.tar.gz
[ "$(openssl dgst -sha256 e2fsprogs-dev-1.47.4-r1.tar.gz | sed 's/.*= *//')" = 9f887b75515ff2ac7c8fb64f99c5ff3d7a6a8927b2a7b85ae4d423a3f37596ab ] && echo OK || echo BAD
gzip -dc e2fsprogs-dev-1.47.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/e2fsprogs-dev.list
gzip -dc e2fsprogs-dev-1.47.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm e2fsprogs-dev-1.47.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/e2fsprogs-dev.list
rm var/lib/manual/e2fsprogs-dev.list

Its dependencies stay installed: libuuid, e2fsprogs. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is e2fsprogs). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
