Install and remove

A. apk

Dependencies come along, signatures checked:

apk add epiphany
apk add epiphany=43.1-r2   # this version

apk del epiphany   # also drops dependencies nothing else needs

Package: epiphany-43.1-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install epiphany
oss-get install epiphany=43.1-r2   # this version

oss-get remove epiphany   # its files only

Its dependencies stay installed: at-spi2-core, cairo, gcr, gdk-pixbuf, gettext, glib, gmp, gtk3, json-glib, libarchive, libdazzle, libhandy, libportal, libsecret, libsoup, libxml2, nettle, pango, sqlite, webkitgtk. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.
