Install and remove

A. apk

Dependencies come along, signatures checked:

apk add fcl-dev
apk add fcl-dev=0.7.0-r0   # this version

apk del fcl-dev   # also drops dependencies nothing else needs

Package: fcl-dev-0.7.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install fcl-dev
oss-get install fcl-dev=0.7.0-r0   # this version

oss-get remove fcl-dev   # its files only

Its dependencies stay installed: fcl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/fcl-dev-0.7.0-r0.tar.gz (304.4 KiB)
SHA-256
a4e850bed3be38b515b2b5c3228f6e0d473fa3b9a9c11cdd5c049315f2cc47eb
Install first
libccd, octomap, fcl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/fcl-dev-0.7.0-r0.tar.gz
[ "$(openssl dgst -sha256 fcl-dev-0.7.0-r0.tar.gz | sed 's/.*= *//')" = a4e850bed3be38b515b2b5c3228f6e0d473fa3b9a9c11cdd5c049315f2cc47eb ] && echo OK || echo BAD
gzip -dc fcl-dev-0.7.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/fcl-dev.list
gzip -dc fcl-dev-0.7.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm fcl-dev-0.7.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/fcl-dev.list
rm var/lib/manual/fcl-dev.list

Its dependencies stay installed: libccd, octomap, fcl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is fcl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
