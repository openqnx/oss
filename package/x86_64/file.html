B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install file
oss-get install file=5.46-r0   # this version

oss-get remove file   # its files only

Its dependencies stay installed: bzip2, xz, zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

SHA-256
3b646195051b7b34c01cab3687ea7df9616b46953d15149b89250cac2d5ca6d2
Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/file-5.46-r0.tar.gz
[ "$(openssl dgst -sha256 file-5.46-r0.tar.gz | sed 's/.*= *//')" = 3b646195051b7b34c01cab3687ea7df9616b46953d15149b89250cac2d5ca6d2 ] && echo OK || echo BAD
gzip -dc file-5.46-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/file.list
gzip -dc file-5.46-r0.tar.gz | (cd /data/oss && tar -xf -) && rm file-5.46-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/file.list
rm var/lib/manual/file.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
