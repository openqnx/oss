Install and remove

A. apk

Dependencies come along, signatures checked:

apk add flatbuffers-dev
apk add flatbuffers-dev=24.3.25-r0   # this version

apk del flatbuffers-dev   # also drops dependencies nothing else needs

Package: flatbuffers-dev-24.3.25-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install flatbuffers-dev
oss-get install flatbuffers-dev=24.3.25-r0   # this version

oss-get remove flatbuffers-dev   # its files only

Its dependencies stay installed: flatbuffers. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/flatbuffers-dev-24.3.25-r0.tar.gz
[ "$(openssl dgst -sha256 flatbuffers-dev-24.3.25-r0.tar.gz | sed 's/.*= *//')" = 4f00a625461c8e8be0297cf27ff38442361b6f3b0bd070c068948467881eda66 ] && echo OK || echo BAD
gzip -dc flatbuffers-dev-24.3.25-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/flatbuffers-dev.list
gzip -dc flatbuffers-dev-24.3.25-r0.tar.gz | (cd /data/oss && tar -xf -) && rm flatbuffers-dev-24.3.25-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/flatbuffers-dev.list
rm var/lib/manual/flatbuffers-dev.list

Its dependencies stay installed: flatbuffers. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is flatbuffers). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
