Install and remove

A. apk

Dependencies come along, signatures checked:

apk add folly
apk add folly=2026.10.26.00-r1   # this version

apk del folly   # also drops dependencies nothing else needs

Package: folly-2026.10.26.00-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install folly
oss-get install folly=2026.10.26.00-r1   # this version

oss-get remove folly   # its files only

Its dependencies stay installed: boost, bzip2, fmt, gflags, glog, libevent, libsodium, lz4, openssl, xz, zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/folly-2026.10.26.00-r1.tar.gz
[ "$(openssl dgst -sha256 folly-2026.10.26.00-r1.tar.gz | sed 's/.*= *//')" = 08ef130139776d65c2fbd35210b35e2eb49890623e1ed183d066ce51b288fbd8 ] && echo OK || echo BAD
gzip -dc folly-2026.10.26.00-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/folly.list
gzip -dc folly-2026.10.26.00-r1.tar.gz | (cd /data/oss && tar -xf -) && rm folly-2026.10.26.00-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/folly.list
rm var/lib/manual/folly.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost, fmt, gflags, glog, openssl, libevent, libsodium, lz4, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
