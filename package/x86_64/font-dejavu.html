Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/font-dejavu-2.37-r0.tar.gz
[ "$(openssl dgst -sha256 font-dejavu-2.37-r0.tar.gz | sed 's/.*= *//')" = 4b81645919ae2eec8c633e2c05df07371285a5f8ea31894ac51b8e5705c9b394 ] && echo OK || echo BAD
gzip -dc font-dejavu-2.37-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/font-dejavu.list
gzip -dc font-dejavu-2.37-r0.tar.gz | (cd /data/oss && tar -xf -) && rm font-dejavu-2.37-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/font-dejavu.list
rm var/lib/manual/font-dejavu.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
