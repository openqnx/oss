Install and remove

A. apk

Dependencies come along, signatures checked:

apk add font-inconsolata
apk add font-inconsolata=3.000-r0   # this version

apk del font-inconsolata   # also drops dependencies nothing else needs

Package: font-inconsolata-3.000-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install font-inconsolata
oss-get install font-inconsolata=3.000-r0   # this version

oss-get remove font-inconsolata   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/font-inconsolata-3.000-r0.tar.gz (2.8 MiB)
SHA-256

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/font-inconsolata-3.000-r0.tar.gz
[ "$(openssl dgst -sha256 font-inconsolata-3.000-r0.tar.gz | sed 's/.*= *//')" = f1237ce4c9844f8afedb053d64670590ad349d0651828583583bf32bfe50517d ] && echo OK || echo BAD
gzip -dc font-inconsolata-3.000-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/font-inconsolata.list
gzip -dc font-inconsolata-3.000-r0.tar.gz | (cd /data/oss && tar -xf -) && rm font-inconsolata-3.000-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/font-inconsolata.list
rm var/lib/manual/font-inconsolata.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
