Install and remove

A. apk

Dependencies come along, signatures checked:

apk add foot
apk add foot=1.23.1-r3   # this version

apk del foot   # also drops dependencies nothing else needs

Package: foot-1.23.1-r3.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install foot
oss-get install foot=1.23.1-r3   # this version

oss-get remove foot   # its files only

Its dependencies stay installed: fcft, fontconfig, libxkbcommon, ncurses, pixman, utf8proc, wayland. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

SHA-256
f6794ee490a6591d69ef4c4611c2820a281e6068e18b7b7e4c94ab02ff1ab238
Install first
expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, graphite2, icu, harfbuzz, pixman, utf8proc, fcft, xz, libxml2, libxkbcommon, wayland (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/foot-1.23.1-r3.tar.gz
[ "$(openssl dgst -sha256 foot-1.23.1-r3.tar.gz | sed 's/.*= *//')" = f6794ee490a6591d69ef4c4611c2820a281e6068e18b7b7e4c94ab02ff1ab238 ] && echo OK || echo BAD
gzip -dc foot-1.23.1-r3.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/foot.list
gzip -dc foot-1.23.1-r3.tar.gz | (cd /data/oss && tar -xf -) && rm foot-1.23.1-r3.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/foot.list
rm var/lib/manual/foot.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, graphite2, icu, harfbuzz, pixman, utf8proc, fcft, xz, libxml2, libxkbcommon, wayland. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
