Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gcr
apk add gcr=3.41.2-r0   # this version

apk del gcr   # also drops dependencies nothing else needs

Package: gcr-3.41.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gcr
oss-get install gcr=3.41.2-r0   # this version

oss-get remove gcr   # its files only

Its dependencies stay installed: cairo, gdk-pixbuf, gettext, glib, gtk3, libgcrypt, p11-kit, pango. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gcr-3.41.2-r0.tar.gz
[ "$(openssl dgst -sha256 gcr-3.41.2-r0.tar.gz | sed 's/.*= *//')" = 4a3836195099d68471efbe92c5dea8ef737e197df86fb58a16c1620397655630 ] && echo OK || echo BAD
gzip -dc gcr-3.41.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gcr.list
gzip -dc gcr-3.41.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gcr-3.41.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gcr.list
rm var/lib/manual/gcr.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, dbus, libxi, libxtst, at-spi2-core, fribidi, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, libgpg-error, libgcrypt, p11-kit. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
