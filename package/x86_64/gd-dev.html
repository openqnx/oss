Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gd-dev
apk add gd-dev=2.3.3-r0   # this version

apk del gd-dev   # also drops dependencies nothing else needs

Package: gd-dev-2.3.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gd-dev
oss-get install gd-dev=2.3.3-r0   # this version

oss-get remove gd-dev   # its files only

Its dependencies stay installed: gd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, aom, dav1d, libavif, libde265, libjpeg-turbo, libwebp, libiconv, libunistring, ncurses, gettext, xz, zstd, libtiff, openh264, openjpeg, openjph, x265, libheif, gd (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gd-dev-2.3.3-r0.tar.gz
[ "$(openssl dgst -sha256 gd-dev-2.3.3-r0.tar.gz | sed 's/.*= *//')" = 5d7699a45a0a67f9af7cb9c13ecddece869a3c758bd035ca06cd838b209bcf9c ] && echo OK || echo BAD
gzip -dc gd-dev-2.3.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gd-dev.list
gzip -dc gd-dev-2.3.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gd-dev-2.3.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gd-dev.list
rm var/lib/manual/gd-dev.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, aom, dav1d, libavif, libde265, libjpeg-turbo, libwebp, libiconv, libunistring, ncurses, gettext, xz, zstd, libtiff, openh264, openjpeg, openjph, x265, libheif, gd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gd). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
