Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gd
apk add gd=2.3.3-r0   # this version

apk del gd   # also drops dependencies nothing else needs

Package: gd-2.3.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gd
oss-get install gd=2.3.3-r0   # this version

oss-get remove gd   # its files only

Its dependencies stay installed: fontconfig, freetype, libavif, libheif, libjpeg-turbo, libpng, libtiff, libwebp, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install first

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gd-2.3.3-r0.tar.gz
[ "$(openssl dgst -sha256 gd-2.3.3-r0.tar.gz | sed 's/.*= *//')" = 3b88d651b4ec094be4e8a4b2af0af87208576e71213ddf502262bcd0659cd6a8 ] && echo OK || echo BAD
gzip -dc gd-2.3.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gd.list
gzip -dc gd-2.3.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gd-2.3.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gd.list
rm var/lib/manual/gd.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, aom, dav1d, libavif, libde265, libjpeg-turbo, libwebp, libiconv, libunistring, ncurses, gettext, xz, zstd, libtiff, openh264, openjpeg, openjph, x265, libheif. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
