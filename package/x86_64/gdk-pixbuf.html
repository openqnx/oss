Package: gdk-pixbuf-2.42.12-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gdk-pixbuf
oss-get install gdk-pixbuf=2.42.12-r0   # this version

oss-get remove gdk-pixbuf   # its files only

Its dependencies stay installed: gettext, glib, libjpeg-turbo, libpng. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gdk-pixbuf-2.42.12-r0.tar.gz
[ "$(openssl dgst -sha256 gdk-pixbuf-2.42.12-r0.tar.gz | sed 's/.*= *//')" = 09d6f46e96d665c3044c0e60c662fbd8dcf2adb3ce03c1045e4ae34ffc572eef ] && echo OK || echo BAD
gzip -dc gdk-pixbuf-2.42.12-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gdk-pixbuf.list
gzip -dc gdk-pixbuf-2.42.12-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gdk-pixbuf-2.42.12-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gdk-pixbuf.list
rm var/lib/manual/gdk-pixbuf.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libjpeg-turbo, libpng. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
