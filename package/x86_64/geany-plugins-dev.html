Install and remove

A. apk

Dependencies come along, signatures checked:

apk add geany-plugins-dev
apk add geany-plugins-dev=2.1-r1   # this version

apk del geany-plugins-dev   # also drops dependencies nothing else needs

Package: geany-plugins-dev-2.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install geany-plugins-dev
oss-get install geany-plugins-dev=2.1-r1   # this version

oss-get remove geany-plugins-dev   # its files only

Its dependencies stay installed: geany-plugins. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/geany-plugins-dev-2.1-r1.tar.gz
[ "$(openssl dgst -sha256 geany-plugins-dev-2.1-r1.tar.gz | sed 's/.*= *//')" = 854294ca4a4344924357ae017ae82e06d2625d53c846ffd03d61ce7da2c7c8a1 ] && echo OK || echo BAD
gzip -dc geany-plugins-dev-2.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/geany-plugins-dev.list
gzip -dc geany-plugins-dev-2.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm geany-plugins-dev-2.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/geany-plugins-dev.list
rm var/lib/manual/geany-plugins-dev.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, fribidi, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, geany, geany-plugins. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is geany-plugins). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
