Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/geographiclib-2.7-r0.tar.gz
[ "$(openssl dgst -sha256 geographiclib-2.7-r0.tar.gz | sed 's/.*= *//')" = 78d5d505031ac7744b33a02ef23f03499dd0285a486c243db6a0b572dbbf415a ] && echo OK || echo BAD
gzip -dc geographiclib-2.7-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/geographiclib.list
gzip -dc geographiclib-2.7-r0.tar.gz | (cd /data/oss && tar -xf -) && rm geographiclib-2.7-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/geographiclib.list
rm var/lib/manual/geographiclib.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
