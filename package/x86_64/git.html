Install and remove

A. apk

Dependencies come along, signatures checked:

apk add git
apk add git=2.51.0-r0   # this version

apk del git   # also drops dependencies nothing else needs

Package: git-2.51.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install git
oss-get install git=2.51.0-r0   # this version

oss-get remove git   # its files only

Its dependencies stay installed: curl, expat, libiconv, openssl, pcre2, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive

SHA-256
c20ef9eb7c4539f3cef967ffaf5c2f651cdc45cd747e65af3b92ff4ab93771b4
Install first

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/git-2.51.0-r0.tar.gz
[ "$(openssl dgst -sha256 git-2.51.0-r0.tar.gz | sed 's/.*= *//')" = c20ef9eb7c4539f3cef967ffaf5c2f651cdc45cd747e65af3b92ff4ab93771b4 ] && echo OK || echo BAD
gzip -dc git-2.51.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/git.list
gzip -dc git-2.51.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm git-2.51.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/git.list
rm var/lib/manual/git.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, expat, libiconv, pcre2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
