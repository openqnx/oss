Install and remove

A. apk

Dependencies come along, signatures checked:

apk add glib-dev
apk add glib-dev=2.82.4-r1   # this version

apk del glib-dev   # also drops dependencies nothing else needs

Package: glib-dev-2.82.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install glib-dev
oss-get install glib-dev=2.82.4-r1   # this version

oss-get remove glib-dev   # its files only

Its dependencies stay installed: glib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/glib-dev-2.82.4-r1.tar.gz (2.7 MiB)
SHA-256
6024c076b283734ec9cbc9e9d405e01a979aee36c291535759015f72141ae91e
Install first

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/glib-dev-2.82.4-r1.tar.gz
[ "$(openssl dgst -sha256 glib-dev-2.82.4-r1.tar.gz | sed 's/.*= *//')" = 6024c076b283734ec9cbc9e9d405e01a979aee36c291535759015f72141ae91e ] && echo OK || echo BAD
gzip -dc glib-dev-2.82.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/glib-dev.list
gzip -dc glib-dev-2.82.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm glib-dev-2.82.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/glib-dev.list
rm var/lib/manual/glib-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is glib). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
