Install and remove

A. apk

Dependencies come along, signatures checked:

apk add glib
apk add glib=2.82.4-r1   # this version

apk del glib   # also drops dependencies nothing else needs

Package: glib-2.82.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install glib
oss-get install glib=2.82.4-r1   # this version

oss-get remove glib   # its files only

Its dependencies stay installed: gettext, libffi, libiconv, pcre2, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/glib-2.82.4-r1.tar.gz (5.1 MiB)
SHA-256
c2c8e2e0b9d98dbe68456ee4ebb5aab271f212863c8b09bbf01ab857a038da66
Install first
libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/glib-2.82.4-r1.tar.gz
[ "$(openssl dgst -sha256 glib-2.82.4-r1.tar.gz | sed 's/.*= *//')" = c2c8e2e0b9d98dbe68456ee4ebb5aab271f212863c8b09bbf01ab857a038da66 ] && echo OK || echo BAD
gzip -dc glib-2.82.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/glib.list
gzip -dc glib-2.82.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm glib-2.82.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/glib.list
rm var/lib/manual/glib.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
