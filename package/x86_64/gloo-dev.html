Package: gloo-dev-0_git20261104-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gloo-dev
oss-get install gloo-dev=0_git20261104-r0   # this version

oss-get remove gloo-dev   # its files only

Its dependencies stay installed: gloo. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gloo-dev-0_git20261104-r0.tar.gz
[ "$(openssl dgst -sha256 gloo-dev-0_git20261104-r0.tar.gz | sed 's/.*= *//')" = 35a91b0ea7617f1ec8eb1038c5a0bdb1672f18b31384b8303bc191f26ed09784 ] && echo OK || echo BAD
gzip -dc gloo-dev-0_git20261104-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gloo-dev.list
gzip -dc gloo-dev-0_git20261104-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gloo-dev-0_git20261104-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gloo-dev.list
rm var/lib/manual/gloo-dev.list

Its dependencies stay installed: gloo. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gloo). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
