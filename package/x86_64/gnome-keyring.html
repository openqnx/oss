Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gnome-keyring
apk add gnome-keyring=51.1-r1   # this version

apk del gnome-keyring   # also drops dependencies nothing else needs

Package: gnome-keyring-51.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gnome-keyring
oss-get install gnome-keyring=51.1-r1   # this version

oss-get remove gnome-keyring   # its files only

Its dependencies stay installed: gcr, gettext, glib, libgcrypt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gnome-keyring-51.1-r1.tar.gz
[ "$(openssl dgst -sha256 gnome-keyring-51.1-r1.tar.gz | sed 's/.*= *//')" = 5ac3adbe006d28978312ebf3835c5691b1f8b087e950882fb3d741565d55cb9a ] && echo OK || echo BAD
gzip -dc gnome-keyring-51.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gnome-keyring.list
gzip -dc gnome-keyring-51.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm gnome-keyring-51.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gnome-keyring.list
rm var/lib/manual/gnome-keyring.list

Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
