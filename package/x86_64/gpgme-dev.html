Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gpgme-dev
apk add gpgme-dev=2.2.0-r0   # this version

apk del gpgme-dev   # also drops dependencies nothing else needs

Package: gpgme-dev-2.2.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gpgme-dev
oss-get install gpgme-dev=2.2.0-r0   # this version

oss-get remove gpgme-dev   # its files only

Its dependencies stay installed: gpgme. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gpgme-dev-2.2.0-r0.tar.gz
[ "$(openssl dgst -sha256 gpgme-dev-2.2.0-r0.tar.gz | sed 's/.*= *//')" = 2136162fd761da5a0fbb9efa10e2a236749143f30b593d5870c293a28100a03d ] && echo OK || echo BAD
gzip -dc gpgme-dev-2.2.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gpgme-dev.list
gzip -dc gpgme-dev-2.2.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gpgme-dev-2.2.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gpgme-dev.list
rm var/lib/manual/gpgme-dev.list

Its dependencies stay installed: bzip2, brotli, gmp, libiconv, libunistring, ncurses, gettext, libidn2, libtasn1, nettle, zlib, zstd, gnutls, libgpg-error, libassuan, libgcrypt, libksba, npth, readline, sqlite, gnupg, gpgme. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is gpgme). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
