Install and remove

A. apk

Dependencies come along, signatures checked:

apk add graphicsmagick-dev
apk add graphicsmagick-dev=1.3.46-r1   # this version

apk del graphicsmagick-dev   # also drops dependencies nothing else needs

Package: graphicsmagick-dev-1.3.46-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install graphicsmagick-dev
oss-get install graphicsmagick-dev=1.3.46-r1   # this version

oss-get remove graphicsmagick-dev   # its files only

Its dependencies stay installed: graphicsmagick. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/graphicsmagick-dev-1.3.46-r1.tar.gz (1.8 MiB)
SHA-256
efd2d2079281f5ebdc092374904fd898ef7be68965353640df4ccd224b603efe
Install first
bzip2, brotli, zlib, libpng, freetype, lcms2, libjpeg-turbo, highway, libjxl, libwebp, libiconv, libunistring, ncurses, gettext, xz, zstd, libtiff, libxml2, openssl, libzip, graphicsmagick (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/graphicsmagick-dev-1.3.46-r1.tar.gz
[ "$(openssl dgst -sha256 graphicsmagick-dev-1.3.46-r1.tar.gz | sed 's/.*= *//')" = efd2d2079281f5ebdc092374904fd898ef7be68965353640df4ccd224b603efe ] && echo OK || echo BAD
gzip -dc graphicsmagick-dev-1.3.46-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/graphicsmagick-dev.list
gzip -dc graphicsmagick-dev-1.3.46-r1.tar.gz | (cd /data/oss && tar -xf -) && rm graphicsmagick-dev-1.3.46-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/graphicsmagick-dev.list
rm var/lib/manual/graphicsmagick-dev.list

Its dependencies stay installed: bzip2, brotli, zlib, libpng, freetype, lcms2, libjpeg-turbo, highway, libjxl, libwebp, libiconv, libunistring, ncurses, gettext, xz, zstd, libtiff, libxml2, openssl, libzip, graphicsmagick. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is graphicsmagick). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
