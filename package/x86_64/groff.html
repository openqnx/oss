Install and remove

A. apk

Dependencies come along, signatures checked:

apk add groff
apk add groff=1.23.0-r0   # this version

apk del groff   # also drops dependencies nothing else needs

Package: groff-1.23.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install groff
oss-get install groff=1.23.0-r0   # this version

oss-get remove groff   # its files only

Its dependencies stay installed: libiconv. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/groff-1.23.0-r0.tar.gz (3.8 MiB)
SHA-256
8ee896981da0ccb6343a4b2ff58fdaaf4fe92e70c71aee240b76f494108b596f
Install first
libiconv (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/groff-1.23.0-r0.tar.gz
[ "$(openssl dgst -sha256 groff-1.23.0-r0.tar.gz | sed 's/.*= *//')" = 8ee896981da0ccb6343a4b2ff58fdaaf4fe92e70c71aee240b76f494108b596f ] && echo OK || echo BAD
gzip -dc groff-1.23.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/groff.list
gzip -dc groff-1.23.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm groff-1.23.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/groff.list
rm var/lib/manual/groff.list

Its dependencies stay installed: libiconv. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
