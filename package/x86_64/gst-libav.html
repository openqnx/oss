B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gst-libav
oss-get install gst-libav=1.24.10-r0   # this version

oss-get remove gst-libav   # its files only

Its dependencies stay installed: ffmpeg, glib, gst-plugins-base, gstreamer. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gst-libav-1.24.10-r0.tar.gz
[ "$(openssl dgst -sha256 gst-libav-1.24.10-r0.tar.gz | sed 's/.*= *//')" = 1cd328eba53698f8325f4c6bd5fc211ac0e23c9e298413c2fb41a8060d5bcb20 ] && echo OK || echo BAD
gzip -dc gst-libav-1.24.10-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gst-libav.list
gzip -dc gst-libav-1.24.10-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gst-libav-1.24.10-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gst-libav.list
rm var/lib/manual/gst-libav.list

Its dependencies stay installed: bzip2, dav1d, lame, libogg, libtheora, libvorbis, libvpx, openh264, opus, x264, x265, libiconv, libunistring, ncurses, gettext, xz, zlib, ffmpeg, libffi, pcre2, glib, gstreamer, gst-plugins-base. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
