Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gst-plugins-bad-dev
apk add gst-plugins-bad-dev=1.24.10-r0   # this version

Package: gst-plugins-bad-dev-1.24.10-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gst-plugins-bad-dev
oss-get install gst-plugins-bad-dev=1.24.10-r0   # this version

oss-get remove gst-plugins-bad-dev   # its files only

Its dependencies stay installed: gst-plugins-bad. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.
