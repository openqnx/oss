Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gst-plugins-ugly-1.24.10-r0.tar.gz
[ "$(openssl dgst -sha256 gst-plugins-ugly-1.24.10-r0.tar.gz | sed 's/.*= *//')" = 3b562818de84ded070a05040b97b839b627d2c3b583e672db242294b031b3a8d ] && echo OK || echo BAD
gzip -dc gst-plugins-ugly-1.24.10-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gst-plugins-ugly.list
gzip -dc gst-plugins-ugly-1.24.10-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gst-plugins-ugly-1.24.10-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gst-plugins-ugly.list
rm var/lib/manual/gst-plugins-ugly.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, gstreamer, libogg, libtheora, libvorbis, opus, gst-plugins-base, x264. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
