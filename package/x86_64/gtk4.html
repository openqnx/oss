Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gtk4
apk add gtk4=4.16.7-r0   # this version

apk del gtk4   # also drops dependencies nothing else needs

Package: gtk4-4.16.7-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gtk4
oss-get install gtk4=4.16.7-r0   # this version

oss-get remove gtk4   # its files only

Its dependencies stay installed: cairo, fontconfig, fribidi, gdk-pixbuf, gettext, glib, graphene, harfbuzz, libepoxy, libjpeg-turbo, libpng, libtiff, libxkbcommon, pango, wayland. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gtk4-4.16.7-r0.tar.gz
[ "$(openssl dgst -sha256 gtk4-4.16.7-r0.tar.gz | sed 's/.*= *//')" = 67ae2048501c0f7e2c0673d34ee5e44874cf385d4a852d29b75194b8fbda16a9 ] && echo OK || echo BAD
gzip -dc gtk4-4.16.7-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gtk4.list
gzip -dc gtk4-4.16.7-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gtk4-4.16.7-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gtk4.list
rm var/lib/manual/gtk4.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, fribidi, libjpeg-turbo, gdk-pixbuf, graphene, graphite2, icu, harfbuzz, libepoxy, libwebp, xz, zstd, libtiff, libxml2, libxkbcommon, libxft, pango, wayland. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
