Install and remove

A. apk

Dependencies come along, signatures checked:

apk add gyp
apk add gyp=0.22.4-r0   # this version

apk del gyp   # also drops dependencies nothing else needs

Package: gyp-0.22.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install gyp
oss-get install gyp=0.22.4-r0   # this version

oss-get remove gyp   # its files only

Its dependencies stay installed: python3, python3-packaging, python3-setuptools. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/gyp-0.22.4-r0.tar.gz
[ "$(openssl dgst -sha256 gyp-0.22.4-r0.tar.gz | sed 's/.*= *//')" = 5ef6d3250b8f3fc4ef8d09420b8abe7e240712e73f4bd1bf73c26852f4fe9d71 ] && echo OK || echo BAD
gzip -dc gyp-0.22.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/gyp.list
gzip -dc gyp-0.22.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm gyp-0.22.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/gyp.list
rm var/lib/manual/gyp.list

Its dependencies stay installed: bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3, python3-packaging, python3-setuptools. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
