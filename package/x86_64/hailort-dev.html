Install and remove

A. apk

Dependencies come along, signatures checked:

apk add hailort-dev
apk add hailort-dev=4.14.0-r0   # this version

apk del hailort-dev   # also drops dependencies nothing else needs

Package: hailort-dev-4.14.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install hailort-dev
oss-get install hailort-dev=4.14.0-r0   # this version

oss-get remove hailort-dev   # its files only

Its dependencies stay installed: hailort. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/hailort-dev-4.14.0-r0.tar.gz (67.7 KiB)
SHA-256
0d49726cd2b676dfa2948f5e52baf9e47aea6fc68ee24ff4e1d114a33e2b84c0
Install first
hailort (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/hailort-dev-4.14.0-r0.tar.gz
[ "$(openssl dgst -sha256 hailort-dev-4.14.0-r0.tar.gz | sed 's/.*= *//')" = 0d49726cd2b676dfa2948f5e52baf9e47aea6fc68ee24ff4e1d114a33e2b84c0 ] && echo OK || echo BAD
gzip -dc hailort-dev-4.14.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/hailort-dev.list
gzip -dc hailort-dev-4.14.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm hailort-dev-4.14.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/hailort-dev.list
rm var/lib/manual/hailort-dev.list

Its dependencies stay installed: hailort. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is hailort). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
