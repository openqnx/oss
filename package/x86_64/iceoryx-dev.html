Install and remove

A. apk

Dependencies come along, signatures checked:

apk add iceoryx-dev
apk add iceoryx-dev=2.0.6-r0   # this version

apk del iceoryx-dev   # also drops dependencies nothing else needs

Package: iceoryx-dev-2.0.6-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install iceoryx-dev
oss-get install iceoryx-dev=2.0.6-r0   # this version

oss-get remove iceoryx-dev   # its files only

Its dependencies stay installed: iceoryx. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/iceoryx-dev-2.0.6-r0.tar.gz
[ "$(openssl dgst -sha256 iceoryx-dev-2.0.6-r0.tar.gz | sed 's/.*= *//')" = f383e2671127face486fb3b455c8e4b4fccc5da03049e4f2f662aa9e83c022d8 ] && echo OK || echo BAD
gzip -dc iceoryx-dev-2.0.6-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/iceoryx-dev.list
gzip -dc iceoryx-dev-2.0.6-r0.tar.gz | (cd /data/oss && tar -xf -) && rm iceoryx-dev-2.0.6-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/iceoryx-dev.list
rm var/lib/manual/iceoryx-dev.list

Its dependencies stay installed: iceoryx. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is iceoryx). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
