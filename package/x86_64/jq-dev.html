Install and remove

A. apk

Dependencies come along, signatures checked:

apk add jq-dev
apk add jq-dev=1.7.1-r0   # this version

apk del jq-dev   # also drops dependencies nothing else needs

Package: jq-dev-1.7.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install jq-dev
oss-get install jq-dev=1.7.1-r0   # this version

oss-get remove jq-dev   # its files only

Its dependencies stay installed: jq. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

SHA-256

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/jq-dev-1.7.1-r0.tar.gz
[ "$(openssl dgst -sha256 jq-dev-1.7.1-r0.tar.gz | sed 's/.*= *//')" = 9f82f6443bcd7ce9bb30b94f3622753a50657f195f2373bdf9fc41540f1e6dd9 ] && echo OK || echo BAD
gzip -dc jq-dev-1.7.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/jq-dev.list
gzip -dc jq-dev-1.7.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm jq-dev-1.7.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/jq-dev.list
rm var/lib/manual/jq-dev.list

Its dependencies stay installed: oniguruma, jq. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is jq). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
