B-1. oss-get

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libaec-1.1.7-r0.tar.gz
[ "$(openssl dgst -sha256 libaec-1.1.7-r0.tar.gz | sed 's/.*= *//')" = 9ba02416a78890e30f5a9e54c81b5fd63eaaeccc225ae728b08b5846cb806a9d ] && echo OK || echo BAD
gzip -dc libaec-1.1.7-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libaec.list
gzip -dc libaec-1.1.7-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libaec-1.1.7-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libaec.list
rm var/lib/manual/libaec.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
