Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libassuan
apk add libassuan=3.0.2-r0   # this version

apk del libassuan   # also drops dependencies nothing else needs

Package: libassuan-3.0.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libassuan
oss-get install libassuan=3.0.2-r0   # this version

oss-get remove libassuan   # its files only

Its dependencies stay installed: libgpg-error. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libassuan-3.0.2-r0.tar.gz (42.9 KiB)
SHA-256
3d941dd762ba27fbae7706a5da06e2bd6d1e7fd19326d45d7ab2b04154597906
Install first
libiconv, libunistring, ncurses, gettext, libgpg-error (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libassuan-3.0.2-r0.tar.gz
[ "$(openssl dgst -sha256 libassuan-3.0.2-r0.tar.gz | sed 's/.*= *//')" = 3d941dd762ba27fbae7706a5da06e2bd6d1e7fd19326d45d7ab2b04154597906 ] && echo OK || echo BAD
gzip -dc libassuan-3.0.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libassuan.list
gzip -dc libassuan-3.0.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libassuan-3.0.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libassuan.list
rm var/lib/manual/libassuan.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libgpg-error. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
