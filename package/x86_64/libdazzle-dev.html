Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libdazzle-dev
apk add libdazzle-dev=3.44.0-r0   # this version

apk del libdazzle-dev   # also drops dependencies nothing else needs

Package: libdazzle-dev-3.44.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libdazzle-dev
oss-get install libdazzle-dev=3.44.0-r0   # this version

oss-get remove libdazzle-dev   # its files only

Its dependencies stay installed: libdazzle. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libdazzle-dev-3.44.0-r0.tar.gz
[ "$(openssl dgst -sha256 libdazzle-dev-3.44.0-r0.tar.gz | sed 's/.*= *//')" = a3d9098026ac9d91c8a14b75d6fa8ecac9eea809438ef01bee24fb71ea468a73 ] && echo OK || echo BAD
gzip -dc libdazzle-dev-3.44.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libdazzle-dev.list
gzip -dc libdazzle-dev-3.44.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libdazzle-dev-3.44.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libdazzle-dev.list
rm var/lib/manual/libdazzle-dev.list

Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is libdazzle). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
