Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libretro-2048-0_git20241227-r0.tar.gz
[ "$(openssl dgst -sha256 libretro-2048-0_git20241227-r0.tar.gz | sed 's/.*= *//')" = 13e739c0bb9d03aa8d5a37a14136c494d890ea329103914a741c61f0c9ee2e04 ] && echo OK || echo BAD
gzip -dc libretro-2048-0_git20241227-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libretro-2048.list
gzip -dc libretro-2048-0_git20241227-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libretro-2048-0_git20241227-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libretro-2048.list
rm var/lib/manual/libretro-2048.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
