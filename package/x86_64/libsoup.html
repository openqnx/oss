Package: libsoup-3.6.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libsoup
oss-get install libsoup=3.6.1-r0   # this version

oss-get remove libsoup   # its files only

Its dependencies stay installed: brotli, gettext, glib, libpsl, nghttp2, sqlite, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libsoup-3.6.1-r0.tar.gz (354.6 KiB)
SHA-256
0b9493f6026bddc3405e4afce7d77356beb0acfd3eb25765df4ccdb9f1d25c4e
Install first
brotli, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libidn2, libpsl, nghttp2, sqlite (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libsoup-3.6.1-r0.tar.gz
[ "$(openssl dgst -sha256 libsoup-3.6.1-r0.tar.gz | sed 's/.*= *//')" = 0b9493f6026bddc3405e4afce7d77356beb0acfd3eb25765df4ccdb9f1d25c4e ] && echo OK || echo BAD
gzip -dc libsoup-3.6.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libsoup.list
gzip -dc libsoup-3.6.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libsoup-3.6.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libsoup.list
rm var/lib/manual/libsoup.list

Its dependencies stay installed: brotli, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libidn2, libpsl, nghttp2, sqlite. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
