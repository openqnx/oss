Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libx11
apk add libx11=1.8.10-r0   # this version

apk del libx11   # also drops dependencies nothing else needs

Package: libx11-1.8.10-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libx11
oss-get install libx11=1.8.10-r0   # this version

oss-get remove libx11   # its files only

Its dependencies stay installed: libxcb. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libx11-1.8.10-r0.tar.gz (912.3 KiB)
SHA-256
bba8aa003f2add51d707da10ee71ec9213b2dfcd97ace147cbc56fdbd43156f2
Install first
libxau, libxdmcp, libxcb (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libx11-1.8.10-r0.tar.gz
[ "$(openssl dgst -sha256 libx11-1.8.10-r0.tar.gz | sed 's/.*= *//')" = bba8aa003f2add51d707da10ee71ec9213b2dfcd97ace147cbc56fdbd43156f2 ] && echo OK || echo BAD
gzip -dc libx11-1.8.10-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libx11.list
gzip -dc libx11-1.8.10-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libx11-1.8.10-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libx11.list
rm var/lib/manual/libx11.list

Its dependencies stay installed: libxau, libxdmcp, libxcb. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
