Install and remove

A. apk

Dependencies come along, signatures checked:

apk add libxt-dev
apk add libxt-dev=1.3.1-r0   # this version

apk del libxt-dev   # also drops dependencies nothing else needs

Package: libxt-dev-1.3.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install libxt-dev
oss-get install libxt-dev=1.3.1-r0   # this version

oss-get remove libxt-dev   # its files only

Its dependencies stay installed: libxt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libxt-dev-1.3.1-r0.tar.gz (103.3 KiB)
SHA-256
da1123d4b9b73b65827c083dce75275d431d06e101a7679e11a82c1281c849c6
Install first
libice, libsm, libxau, libxdmcp, libxcb, libx11, libxt (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/libxt-dev-1.3.1-r0.tar.gz
[ "$(openssl dgst -sha256 libxt-dev-1.3.1-r0.tar.gz | sed 's/.*= *//')" = da1123d4b9b73b65827c083dce75275d431d06e101a7679e11a82c1281c849c6 ] && echo OK || echo BAD
gzip -dc libxt-dev-1.3.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/libxt-dev.list
gzip -dc libxt-dev-1.3.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm libxt-dev-1.3.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/libxt-dev.list
rm var/lib/manual/libxt-dev.list

Its dependencies stay installed: libice, libsm, libxau, libxdmcp, libxcb, libx11, libxt. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is libxt). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
