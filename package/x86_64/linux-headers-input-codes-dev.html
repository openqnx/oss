Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/linux-headers-input-codes-dev-6.12-r0.tar.gz
[ "$(openssl dgst -sha256 linux-headers-input-codes-dev-6.12-r0.tar.gz | sed 's/.*= *//')" = 2c87401dc5398b2bf1e4c4342cf478a30769c0806fab6b0043d56f0e9f8b6991 ] && echo OK || echo BAD
gzip -dc linux-headers-input-codes-dev-6.12-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/linux-headers-input-codes-dev.list
gzip -dc linux-headers-input-codes-dev-6.12-r0.tar.gz | (cd /data/oss && tar -xf -) && rm linux-headers-input-codes-dev-6.12-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/linux-headers-input-codes-dev.list
rm var/lib/manual/linux-headers-input-codes-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
