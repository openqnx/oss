Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/llama.cpp-0_git-r0.tar.gz
[ "$(openssl dgst -sha256 llama.cpp-0_git-r0.tar.gz | sed 's/.*= *//')" = 8902511a2885e9af1824ab680b2d108023651e341d127b5ddede364df8d245ac ] && echo OK || echo BAD
gzip -dc llama.cpp-0_git-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/llama.cpp.list
gzip -dc llama.cpp-0_git-r0.tar.gz | (cd /data/oss && tar -xf -) && rm llama.cpp-0_git-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/llama.cpp.list
rm var/lib/manual/llama.cpp.list

Its dependencies stay installed: openssl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
