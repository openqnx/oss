Install and remove

A. apk

Dependencies come along, signatures checked:

apk add llvm-dev
apk add llvm-dev=22.1.8-r0   # this version

apk del llvm-dev   # also drops dependencies nothing else needs

Package: llvm-dev-22.1.8-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install llvm-dev
oss-get install llvm-dev=22.1.8-r0   # this version

oss-get remove llvm-dev   # its files only

Its dependencies stay installed: llvm. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/llvm-dev-22.1.8-r0.tar.gz
[ "$(openssl dgst -sha256 llvm-dev-22.1.8-r0.tar.gz | sed 's/.*= *//')" = 76a4a79f3479ab7afe66810c35c0f99ee9ee14d97bea2ec0396ddd13b95c4576 ] && echo OK || echo BAD
gzip -dc llvm-dev-22.1.8-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/llvm-dev.list
gzip -dc llvm-dev-22.1.8-r0.tar.gz | (cd /data/oss && tar -xf -) && rm llvm-dev-22.1.8-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/llvm-dev.list
rm var/lib/manual/llvm-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, zstd, llvm. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is llvm). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
