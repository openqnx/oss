Install and remove

A. apk

Dependencies come along, signatures checked:

apk add llvm
apk add llvm=22.1.8-r0   # this version

apk del llvm   # also drops dependencies nothing else needs

Package: llvm-22.1.8-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install llvm
oss-get install llvm=22.1.8-r0   # this version

oss-get remove llvm   # its files only

Its dependencies stay installed: libxml2, zlib, zstd. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/llvm-22.1.8-r0.tar.gz (133.3 MiB)
SHA-256
08d28481581ed94fdedfeb0d6a72c59d3e15f2356dee906b89cf0059e3cc256b
Install first
libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, zstd (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/llvm-22.1.8-r0.tar.gz
[ "$(openssl dgst -sha256 llvm-22.1.8-r0.tar.gz | sed 's/.*= *//')" = 08d28481581ed94fdedfeb0d6a72c59d3e15f2356dee906b89cf0059e3cc256b ] && echo OK || echo BAD
gzip -dc llvm-22.1.8-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/llvm.list
gzip -dc llvm-22.1.8-r0.tar.gz | (cd /data/oss && tar -xf -) && rm llvm-22.1.8-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/llvm.list
rm var/lib/manual/llvm.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, zstd. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
