Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/lmbench-3.0_git20260929-r0.tar.gz
[ "$(openssl dgst -sha256 lmbench-3.0_git20260929-r0.tar.gz | sed 's/.*= *//')" = caa13f0ef7cf05a7af21ef5193f559c2ca451a97f6b0d09fd55d12871fa429c0 ] && echo OK || echo BAD
gzip -dc lmbench-3.0_git20260929-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/lmbench.list
gzip -dc lmbench-3.0_git20260929-r0.tar.gz | (cd /data/oss && tar -xf -) && rm lmbench-3.0_git20260929-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/lmbench.list
rm var/lib/manual/lmbench.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
