Install and remove

A. apk

Dependencies come along, signatures checked:

apk add log4cpp-dev
apk add log4cpp-dev=1.1.4-r1   # this version

apk del log4cpp-dev   # also drops dependencies nothing else needs

Package: log4cpp-dev-1.1.4-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install log4cpp-dev
oss-get install log4cpp-dev=1.1.4-r1   # this version

oss-get remove log4cpp-dev   # its files only

Its dependencies stay installed: log4cpp. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/log4cpp-dev-1.1.4-r1.tar.gz (30.1 KiB)
SHA-256
232c104618aac230ac0301f60206b9e7a6ec1ae44e94b9b1b5a753b49bafeabc
Install first
log4cpp (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/log4cpp-dev-1.1.4-r1.tar.gz
[ "$(openssl dgst -sha256 log4cpp-dev-1.1.4-r1.tar.gz | sed 's/.*= *//')" = 232c104618aac230ac0301f60206b9e7a6ec1ae44e94b9b1b5a753b49bafeabc ] && echo OK || echo BAD
gzip -dc log4cpp-dev-1.1.4-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/log4cpp-dev.list
gzip -dc log4cpp-dev-1.1.4-r1.tar.gz | (cd /data/oss && tar -xf -) && rm log4cpp-dev-1.1.4-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/log4cpp-dev.list
rm var/lib/manual/log4cpp-dev.list

Its dependencies stay installed: log4cpp. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is log4cpp). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
