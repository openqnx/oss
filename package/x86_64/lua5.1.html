A. apk

Dependencies come along, signatures checked:

apk add lua5.1
apk add lua5.1=5.1.5-r0   # this version

apk del lua5.1   # also drops dependencies nothing else needs

Package: lua5.1-5.1.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install lua5.1
oss-get install lua5.1=5.1.5-r0   # this version

oss-get remove lua5.1   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64/lua5.1-5.1.5-r0.tar.gz
[ "$(openssl dgst -sha256 lua5.1-5.1.5-r0.tar.gz | sed 's/.*= *//')" = 661ccbcb676cb4782145229bfe2e0f0d603eaa4bfe49b1a6553af143171b1e33 ] && echo OK || echo BAD
gzip -dc lua5.1-5.1.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/lua5.1.list
gzip -dc lua5.1-5.1.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm lua5.1-5.1.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/lua5.1.list
rm var/lib/manual/lua5.1.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
