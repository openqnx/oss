Install and remove

A. apk

Dependencies come along, signatures checked:

apk add mnn-dev
apk add mnn-dev=3.6.2-r0   # this version

apk del mnn-dev   # also drops dependencies nothing else needs

Package: mnn-dev-3.6.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install mnn-dev
oss-get install mnn-dev=3.6.2-r0   # this version

oss-get remove mnn-dev   # its files only

Its dependencies stay installed: mnn. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/mnn-dev-3.6.2-r0.tar.gz
[ "$(openssl dgst -sha256 mnn-dev-3.6.2-r0.tar.gz | sed 's/.*= *//')" = 55b50fbd6e7967a7aad3fa94de306a347ff5b9f44edbc964fc49e54da67fcfab ] && echo OK || echo BAD
gzip -dc mnn-dev-3.6.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/mnn-dev.list
gzip -dc mnn-dev-3.6.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm mnn-dev-3.6.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/mnn-dev.list
rm var/lib/manual/mnn-dev.list

Its dependencies stay installed: mnn. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is mnn). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
