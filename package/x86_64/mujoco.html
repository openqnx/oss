Install and remove

A. apk

Dependencies come along, signatures checked:

apk add mujoco
apk add mujoco=3.10.0-r0   # this version

apk del mujoco   # also drops dependencies nothing else needs

Package: mujoco-3.10.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install mujoco
oss-get install mujoco=3.10.0-r0   # this version

oss-get remove mujoco   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/mujoco-3.10.0-r0.tar.gz (11.4 MiB)
SHA-256
5ffba2b2f921e8a829bd22474791960ed093e1c8cba244a7ba79af88b120d1ac
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/mujoco-3.10.0-r0.tar.gz
[ "$(openssl dgst -sha256 mujoco-3.10.0-r0.tar.gz | sed 's/.*= *//')" = 5ffba2b2f921e8a829bd22474791960ed093e1c8cba244a7ba79af88b120d1ac ] && echo OK || echo BAD
gzip -dc mujoco-3.10.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/mujoco.list
gzip -dc mujoco-3.10.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm mujoco-3.10.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/mujoco.list
rm var/lib/manual/mujoco.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
