Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ncurses-dev
apk add ncurses-dev=6.5-r2   # this version

apk del ncurses-dev   # also drops dependencies nothing else needs

Package: ncurses-dev-6.5-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ncurses-dev
oss-get install ncurses-dev=6.5-r2   # this version

oss-get remove ncurses-dev   # its files only

Its dependencies stay installed: ncurses. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ncurses-dev-6.5-r2.tar.gz (371.8 KiB)
SHA-256
40c8aba0f249467f90d4bb6bc5644fcfacf10e7089970c8dc6679a0bd2cc24c4
Install first
ncurses (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ncurses-dev-6.5-r2.tar.gz
[ "$(openssl dgst -sha256 ncurses-dev-6.5-r2.tar.gz | sed 's/.*= *//')" = 40c8aba0f249467f90d4bb6bc5644fcfacf10e7089970c8dc6679a0bd2cc24c4 ] && echo OK || echo BAD
gzip -dc ncurses-dev-6.5-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ncurses-dev.list
gzip -dc ncurses-dev-6.5-r2.tar.gz | (cd /data/oss && tar -xf -) && rm ncurses-dev-6.5-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ncurses-dev.list
rm var/lib/manual/ncurses-dev.list

Its dependencies stay installed: ncurses. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is ncurses). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
