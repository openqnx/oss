Install and remove

A. apk

Dependencies come along, signatures checked:

apk add neovim-dev
apk add neovim-dev=0.12.3-r0   # this version

apk del neovim-dev   # also drops dependencies nothing else needs

Package: neovim-dev-0.12.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install neovim-dev
oss-get install neovim-dev=0.12.3-r0   # this version

oss-get remove neovim-dev   # its files only

Its dependencies stay installed: neovim. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/neovim-dev-0.12.3-r0.tar.gz (3.8 KiB)
SHA-256
cf97b094a01861ecf13b6eba9f9d5f23cadac8dc8fff03970928c114e6124ba4
Install first
libiconv, libunistring, ncurses, gettext, libuv, luv, tree-sitter, unibilium, utf8proc, neovim (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/neovim-dev-0.12.3-r0.tar.gz
[ "$(openssl dgst -sha256 neovim-dev-0.12.3-r0.tar.gz | sed 's/.*= *//')" = cf97b094a01861ecf13b6eba9f9d5f23cadac8dc8fff03970928c114e6124ba4 ] && echo OK || echo BAD
gzip -dc neovim-dev-0.12.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/neovim-dev.list
gzip -dc neovim-dev-0.12.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm neovim-dev-0.12.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/neovim-dev.list
rm var/lib/manual/neovim-dev.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libuv, luv, tree-sitter, unibilium, utf8proc, neovim. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is neovim). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
