Install and remove

A. apk

Dependencies come along, signatures checked:

apk add nodejs-dev
apk add nodejs-dev=24.14.1-r0   # this version

apk del nodejs-dev   # also drops dependencies nothing else needs

Package: nodejs-dev-24.14.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install nodejs-dev
oss-get install nodejs-dev=24.14.1-r0   # this version

oss-get remove nodejs-dev   # its files only

Its dependencies stay installed: nodejs. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/nodejs-dev-24.14.1-r0.tar.gz
[ "$(openssl dgst -sha256 nodejs-dev-24.14.1-r0.tar.gz | sed 's/.*= *//')" = 459d4bc9c6c69f7bf472a494503ca7194ebebb95969ff2a054eac042056a85c8 ] && echo OK || echo BAD
gzip -dc nodejs-dev-24.14.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/nodejs-dev.list
gzip -dc nodejs-dev-24.14.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm nodejs-dev-24.14.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/nodejs-dev.list
rm var/lib/manual/nodejs-dev.list

Its dependencies stay installed: ada, brotli, c-ares, icu, libuv, nghttp2, openssl, simdjson, simdutf, zlib, sqlite, zstd, nodejs. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is nodejs). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
