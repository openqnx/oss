Install and remove

A. apk

Dependencies come along, signatures checked:

apk add npm
apk add npm=11.11.0-r0   # this version

apk del npm   # also drops dependencies nothing else needs

Package: npm-11.11.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install npm
oss-get install npm=11.11.0-r0   # this version

oss-get remove npm   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/npm-11.11.0-r0.tar.gz
[ "$(openssl dgst -sha256 npm-11.11.0-r0.tar.gz | sed 's/.*= *//')" = cf155a2f979ae56dd58b6aff3f3dbbe1d391fde08f2fa079a09dff37daf0f1a3 ] && echo OK || echo BAD
gzip -dc npm-11.11.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/npm.list
gzip -dc npm-11.11.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm npm-11.11.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/npm.list
rm var/lib/manual/npm.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
