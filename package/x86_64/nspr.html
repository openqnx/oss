B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install nspr
oss-get install nspr=4.39-r0   # this version

oss-get remove nspr   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/nspr-4.39-r0.tar.gz
[ "$(openssl dgst -sha256 nspr-4.39-r0.tar.gz | sed 's/.*= *//')" = 60e18b205f0668308bebd2528624d86a3008ec9c806e9eb83f0501df27b8af62 ] && echo OK || echo BAD
gzip -dc nspr-4.39-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/nspr.list
gzip -dc nspr-4.39-r0.tar.gz | (cd /data/oss && tar -xf -) && rm nspr-4.39-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/nspr.list
rm var/lib/manual/nspr.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
