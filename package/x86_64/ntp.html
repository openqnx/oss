Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ntp
apk add ntp=4.2.8_p18-r2   # this version

apk del ntp   # also drops dependencies nothing else needs

Package: ntp-4.2.8_p18-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ntp
oss-get install ntp=4.2.8_p18-r2   # this version

oss-get remove ntp   # its files only

Its dependencies stay installed: libedit, libevent, perl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ntp-4.2.8_p18-r2.tar.gz (2.2 MiB)
SHA-256
02c94c6c05b4b4db0fb9afc2181b440aeaf8c97bbebe7fc40cce0d23d586ca02
Install first
ncurses, libedit, openssl, libevent, libxcrypt, perl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ntp-4.2.8_p18-r2.tar.gz
[ "$(openssl dgst -sha256 ntp-4.2.8_p18-r2.tar.gz | sed 's/.*= *//')" = 02c94c6c05b4b4db0fb9afc2181b440aeaf8c97bbebe7fc40cce0d23d586ca02 ] && echo OK || echo BAD
gzip -dc ntp-4.2.8_p18-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ntp.list
gzip -dc ntp-4.2.8_p18-r2.tar.gz | (cd /data/oss && tar -xf -) && rm ntp-4.2.8_p18-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ntp.list
rm var/lib/manual/ntp.list

Its dependencies stay installed: ncurses, libedit, openssl, libevent, libxcrypt, perl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
