Install and remove

A. apk

Dependencies come along, signatures checked:

apk add openttd
apk add openttd=15.0_git20250501-r0   # this version

apk del openttd   # also drops dependencies nothing else needs

Package: openttd-15.0_git20250501-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install openttd
oss-get install openttd=15.0_git20250501-r0   # this version

oss-get remove openttd   # its files only

Its dependencies stay installed: curl, freetype, libpng, lzo, sdl2, xz, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/openttd-15.0_git20250501-r0.tar.gz
[ "$(openssl dgst -sha256 openttd-15.0_git20250501-r0.tar.gz | sed 's/.*= *//')" = 1dbe0096a6ceea77979d20d0de445aba6d9c703c0bf41f555ca87f829e6e55d9 ] && echo OK || echo BAD
gzip -dc openttd-15.0_git20250501-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/openttd.list
gzip -dc openttd-15.0_git20250501-r0.tar.gz | (cd /data/oss && tar -xf -) && rm openttd-15.0_git20250501-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/openttd.list
rm var/lib/manual/openttd.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, bzip2, libpng, freetype, lzo, sdl2, libiconv, libunistring, ncurses, gettext, xz. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
