Install and remove

A. apk

Dependencies come along, signatures checked:

apk add orocos-kdl-dev
apk add orocos-kdl-dev=1.5.1-r1   # this version

apk del orocos-kdl-dev   # also drops dependencies nothing else needs

Package: orocos-kdl-dev-1.5.1-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install orocos-kdl-dev
oss-get install orocos-kdl-dev=1.5.1-r1   # this version

oss-get remove orocos-kdl-dev   # its files only

Its dependencies stay installed: orocos-kdl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/orocos-kdl-dev-1.5.1-r1.tar.gz
[ "$(openssl dgst -sha256 orocos-kdl-dev-1.5.1-r1.tar.gz | sed 's/.*= *//')" = 74ff117bd04694acf5c1a5b16f1f8436c74d778c1b3e8527266b5f6afd070f34 ] && echo OK || echo BAD
gzip -dc orocos-kdl-dev-1.5.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/orocos-kdl-dev.list
gzip -dc orocos-kdl-dev-1.5.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm orocos-kdl-dev-1.5.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/orocos-kdl-dev.list
rm var/lib/manual/orocos-kdl-dev.list

Its dependencies stay installed: orocos-kdl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is orocos-kdl). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
