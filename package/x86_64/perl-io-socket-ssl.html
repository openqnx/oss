B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install perl-io-socket-ssl
oss-get install perl-io-socket-ssl=2.099-r0   # this version

oss-get remove perl-io-socket-ssl   # its files only

Its dependencies stay installed: perl, perl-mozilla-ca, perl-net-ssleay. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/perl-io-socket-ssl-2.099-r0.tar.gz
[ "$(openssl dgst -sha256 perl-io-socket-ssl-2.099-r0.tar.gz | sed 's/.*= *//')" = f115beb9755462cb1b5ca187e2e6cf1968238ebb76f11a5a96cd317ac13da523 ] && echo OK || echo BAD
gzip -dc perl-io-socket-ssl-2.099-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/perl-io-socket-ssl.list
gzip -dc perl-io-socket-ssl-2.099-r0.tar.gz | (cd /data/oss && tar -xf -) && rm perl-io-socket-ssl-2.099-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/perl-io-socket-ssl.list
rm var/lib/manual/perl-io-socket-ssl.list

Its dependencies stay installed: libxcrypt, perl, perl-mozilla-ca, openssl, zlib, perl-net-ssleay. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
