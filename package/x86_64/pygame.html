Install and remove

A. apk

Dependencies come along, signatures checked:

apk add pygame
apk add pygame=2.6.1_git20251005-r1   # this version

apk del pygame   # also drops dependencies nothing else needs

Package: pygame-2.6.1_git20251005-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install pygame
oss-get install pygame=2.6.1_git20251005-r1   # this version

oss-get remove pygame   # its files only

Its dependencies stay installed: freetype, libjpeg-turbo, libpng, python3, sdl2, sdl2-image, sdl2-mixer, sdl2-ttf. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/pygame-2.6.1_git20251005-r1.tar.gz
[ "$(openssl dgst -sha256 pygame-2.6.1_git20251005-r1.tar.gz | sed 's/.*= *//')" = 33558d453427f73c79a8705b832a6e42bbe4c6b6c0801ba6c6c590b6f5faf08b ] && echo OK || echo BAD
gzip -dc pygame-2.6.1_git20251005-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/pygame.list
gzip -dc pygame-2.6.1_git20251005-r1.tar.gz | (cd /data/oss && tar -xf -) && rm pygame-2.6.1_git20251005-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/pygame.list
rm var/lib/manual/pygame.list

Its dependencies stay installed: brotli, bzip2, zlib, libpng, freetype, libjpeg-turbo, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, sqlite, xz, zstd, python3, sdl2, aom, dav1d, libavif, libwebp, libtiff, sdl2-image, libogg, opus, opusfile, sdl2-mixer, pcre2, glib, graphite2, icu, harfbuzz, sdl2-ttf. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
