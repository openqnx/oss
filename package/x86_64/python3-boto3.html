Package: python3-boto3-1.43.123-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-boto3
oss-get install python3-boto3=1.43.123-r0   # this version

oss-get remove python3-boto3   # its files only

Its dependencies stay installed: python3, python3-botocore, python3-jmespath, python3-s3transfer. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

[ "$(openssl dgst -sha256 python3-boto3-1.43.123-r0.tar.gz | sed 's/.*= *//')" = f1d5d8e3077c3ba1911a14a6243f820bb6e6ca1dfea854af9f1550f02e51addf ] && echo OK || echo BAD
gzip -dc python3-boto3-1.43.123-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-boto3.list
gzip -dc python3-boto3-1.43.123-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-boto3-1.43.123-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-boto3.list
rm var/lib/manual/python3-boto3.list

Its dependencies stay installed: bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3, python3-six, python3-dateutil, python3-jmespath, python3-urllib3, python3-botocore, python3-s3transfer. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
