Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-dev
apk add python3-dev=3.14.0-r0   # this version

apk del python3-dev   # also drops dependencies nothing else needs

Package: python3-dev-3.14.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-dev
oss-get install python3-dev=3.14.0-r0   # this version

oss-get remove python3-dev   # its files only

Its dependencies stay installed: python3. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/python3-dev-3.14.0-r0.tar.gz (406.5 KiB)
SHA-256
fe6ab88dbb8cac162ce3bfcc32853f94625f34226655072767c4f0301f23fc8d
Install first
bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3 (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/python3-dev-3.14.0-r0.tar.gz
[ "$(openssl dgst -sha256 python3-dev-3.14.0-r0.tar.gz | sed 's/.*= *//')" = fe6ab88dbb8cac162ce3bfcc32853f94625f34226655072767c4f0301f23fc8d ] && echo OK || echo BAD
gzip -dc python3-dev-3.14.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-dev.list
gzip -dc python3-dev-3.14.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-dev-3.14.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-dev.list
rm var/lib/manual/python3-dev.list

Its dependencies stay installed: bzip2, expat, gdbm, libiconv, libunistring, ncurses, gettext, libffi, openssl, readline, zlib, sqlite, xz, zstd, python3. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is python3). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
