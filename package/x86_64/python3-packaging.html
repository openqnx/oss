B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-packaging
oss-get install python3-packaging=25.0-r0   # this version

oss-get remove python3-packaging   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/python3-packaging-25.0-r0.tar.gz
[ "$(openssl dgst -sha256 python3-packaging-25.0-r0.tar.gz | sed 's/.*= *//')" = 58d189d7d42c19505a9a9147ee0110594f6473696ad279e60bc4a493bf610ec1 ] && echo OK || echo BAD
gzip -dc python3-packaging-25.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-packaging.list
gzip -dc python3-packaging-25.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-packaging-25.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-packaging.list
rm var/lib/manual/python3-packaging.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
