Install and remove

A. apk

Dependencies come along, signatures checked:

apk add python3-pip
apk add python3-pip=25.1.1-r0   # this version

apk del python3-pip   # also drops dependencies nothing else needs

Package: python3-pip-25.1.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install python3-pip
oss-get install python3-pip=25.1.1-r0   # this version

oss-get remove python3-pip   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/python3-pip-25.1.1-r0.tar.gz (1.6 MiB)
SHA-256
03e575f968b2a407c8c1b05606b9d7f8447df34e6b8a0a9eee0c8345ec200e85
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/python3-pip-25.1.1-r0.tar.gz
[ "$(openssl dgst -sha256 python3-pip-25.1.1-r0.tar.gz | sed 's/.*= *//')" = 03e575f968b2a407c8c1b05606b9d7f8447df34e6b8a0a9eee0c8345ec200e85 ] && echo OK || echo BAD
gzip -dc python3-pip-25.1.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/python3-pip.list
gzip -dc python3-pip-25.1.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm python3-pip-25.1.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/python3-pip.list
rm var/lib/manual/python3-pip.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
