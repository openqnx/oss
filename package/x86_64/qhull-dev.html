Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qhull-dev
apk add qhull-dev=8.0.2-r0   # this version

apk del qhull-dev   # also drops dependencies nothing else needs

Package: qhull-dev-8.0.2-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qhull-dev
oss-get install qhull-dev=8.0.2-r0   # this version

oss-get remove qhull-dev   # its files only

Its dependencies stay installed: qhull. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/qhull-dev-8.0.2-r0.tar.gz (1.0 MiB)
SHA-256
8ae3df45100c98170378e2adcc418055eeb3ae8ab5efdcfdb3e9c8aa27d43f85
Install first
qhull (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/qhull-dev-8.0.2-r0.tar.gz
[ "$(openssl dgst -sha256 qhull-dev-8.0.2-r0.tar.gz | sed 's/.*= *//')" = 8ae3df45100c98170378e2adcc418055eeb3ae8ab5efdcfdb3e9c8aa27d43f85 ] && echo OK || echo BAD
gzip -dc qhull-dev-8.0.2-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/qhull-dev.list
gzip -dc qhull-dev-8.0.2-r0.tar.gz | (cd /data/oss && tar -xf -) && rm qhull-dev-8.0.2-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/qhull-dev.list
rm var/lib/manual/qhull-dev.list

Its dependencies stay installed: qhull. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is qhull). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
