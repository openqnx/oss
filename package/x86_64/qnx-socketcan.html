Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/qnx-socketcan-1.0-r2.tar.gz
[ "$(openssl dgst -sha256 qnx-socketcan-1.0-r2.tar.gz | sed 's/.*= *//')" = 0b25809f6bfa65aec639e96092be379e1998fb3a92afcdacf20428ea20806900 ] && echo OK || echo BAD
gzip -dc qnx-socketcan-1.0-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/qnx-socketcan.list
gzip -dc qnx-socketcan-1.0-r2.tar.gz | (cd /data/oss && tar -xf -) && rm qnx-socketcan-1.0-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/qnx-socketcan.list
rm var/lib/manual/qnx-socketcan.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
