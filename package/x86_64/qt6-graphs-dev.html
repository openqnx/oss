Install and remove

A. apk

Dependencies come along, signatures checked:

apk add qt6-graphs-dev
apk add qt6-graphs-dev=6.8.1-r0   # this version

apk del qt6-graphs-dev   # also drops dependencies nothing else needs

Package: qt6-graphs-dev-6.8.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install qt6-graphs-dev
oss-get install qt6-graphs-dev=6.8.1-r0   # this version

oss-get remove qt6-graphs-dev   # its files only

Its dependencies stay installed: qt6-graphs. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl

[ "$(openssl dgst -sha256 qt6-graphs-dev-6.8.1-r0.tar.gz | sed 's/.*= *//')" = 335e55753f203594297df1e64b72fd1e4fde3cdc6415507727859d226e9135cd ] && echo OK || echo BAD
gzip -dc qt6-graphs-dev-6.8.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/qt6-graphs-dev.list
gzip -dc qt6-graphs-dev-6.8.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm qt6-graphs-dev-6.8.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/qt6-graphs-dev.list
rm var/lib/manual/qt6-graphs-dev.list

Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is qt6-graphs). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
