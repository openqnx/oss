B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install retroarch
oss-get install retroarch=1.15_git20230408-r2   # this version

oss-get remove retroarch   # its files only

Its dependencies stay installed: fontconfig, freetype, fribidi, libass, libxkbcommon, openssl, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/retroarch-1.15_git20230408-r2.tar.gz
[ "$(openssl dgst -sha256 retroarch-1.15_git20230408-r2.tar.gz | sed 's/.*= *//')" = d1cd3c865411a344cecf997bc9f3df8087249a4cb3018f14d279c023805e51db ] && echo OK || echo BAD
gzip -dc retroarch-1.15_git20230408-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/retroarch.list
gzip -dc retroarch-1.15_git20230408-r2.tar.gz | (cd /data/oss && tar -xf -) && rm retroarch-1.15_git20230408-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/retroarch.list
rm var/lib/manual/retroarch.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, fribidi, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, graphite2, icu, harfbuzz, libass, xz, libxml2, libxkbcommon, openssl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
