Install and remove

A. apk

Dependencies come along, signatures checked:

apk add riegeli-dev
apk add riegeli-dev=0_git20231212-r0   # this version

apk del riegeli-dev   # also drops dependencies nothing else needs

Package: riegeli-dev-0_git20231212-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install riegeli-dev
oss-get install riegeli-dev=0_git20231212-r0   # this version

oss-get remove riegeli-dev   # its files only

Its dependencies stay installed: riegeli. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/riegeli-dev-0_git20231212-r0.tar.gz
[ "$(openssl dgst -sha256 riegeli-dev-0_git20231212-r0.tar.gz | sed 's/.*= *//')" = 2eed27893afff7793b4aad7ef86010d0ac3b2b0c6776eef579793f25855cafea ] && echo OK || echo BAD
gzip -dc riegeli-dev-0_git20231212-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/riegeli-dev.list
gzip -dc riegeli-dev-0_git20231212-r0.tar.gz | (cd /data/oss && tar -xf -) && rm riegeli-dev-0_git20231212-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/riegeli-dev.list
rm var/lib/manual/riegeli-dev.list

Its dependencies stay installed: abseil, brotli, bzip2, highwayhash, lz4, zlib, protobuf, snappy, libiconv, libunistring, ncurses, gettext, xz, zstd, riegeli. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is riegeli). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
