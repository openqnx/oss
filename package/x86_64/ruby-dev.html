Install and remove

A. apk

Dependencies come along, signatures checked:

apk add ruby-dev
apk add ruby-dev=3.4.12-r0   # this version

apk del ruby-dev   # also drops dependencies nothing else needs

Package: ruby-dev-3.4.12-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install ruby-dev
oss-get install ruby-dev=3.4.12-r0   # this version

oss-get remove ruby-dev   # its files only

Its dependencies stay installed: ruby. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ruby-dev-3.4.12-r0.tar.gz (324.5 KiB)
SHA-256
2fe01130bbb59d5a2db240cbc5d7631e7629c355b9b6318faa5017131af44064
Install first
gmp, libffi, libxcrypt, libyaml, openssl, zlib, ruby (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/ruby-dev-3.4.12-r0.tar.gz
[ "$(openssl dgst -sha256 ruby-dev-3.4.12-r0.tar.gz | sed 's/.*= *//')" = 2fe01130bbb59d5a2db240cbc5d7631e7629c355b9b6318faa5017131af44064 ] && echo OK || echo BAD
gzip -dc ruby-dev-3.4.12-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/ruby-dev.list
gzip -dc ruby-dev-3.4.12-r0.tar.gz | (cd /data/oss && tar -xf -) && rm ruby-dev-3.4.12-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/ruby-dev.list
rm var/lib/manual/ruby-dev.list

Its dependencies stay installed: gmp, libffi, libxcrypt, libyaml, openssl, zlib, ruby. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is ruby). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
