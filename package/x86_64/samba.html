Install and remove

A. apk

Dependencies come along, signatures checked:

apk add samba
apk add samba=4.25.1-r2   # this version

apk del samba   # also drops dependencies nothing else needs

Package: samba-4.25.1-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install samba
oss-get install samba=4.25.1-r2   # this version

oss-get remove samba   # its files only

Its dependencies stay installed: gnutls, icu, libiconv, libxcrypt, tdb, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/samba-4.25.1-r2.tar.gz (20.0 MiB)
SHA-256
ea044beb0ddbc0a5e8b85581acc62ece9ddf20bb763c911eaaa761ce617b990e
Install first
brotli, gmp, libiconv, libunistring, ncurses, gettext, libidn2, libtasn1, nettle, zlib, zstd, gnutls, icu, libxcrypt, tdb (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/samba-4.25.1-r2.tar.gz
[ "$(openssl dgst -sha256 samba-4.25.1-r2.tar.gz | sed 's/.*= *//')" = ea044beb0ddbc0a5e8b85581acc62ece9ddf20bb763c911eaaa761ce617b990e ] && echo OK || echo BAD
gzip -dc samba-4.25.1-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/samba.list
gzip -dc samba-4.25.1-r2.tar.gz | (cd /data/oss && tar -xf -) && rm samba-4.25.1-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/samba.list
rm var/lib/manual/samba.list

Its dependencies stay installed: brotli, gmp, libiconv, libunistring, ncurses, gettext, libidn2, libtasn1, nettle, zlib, zstd, gnutls, icu, libxcrypt, tdb. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
