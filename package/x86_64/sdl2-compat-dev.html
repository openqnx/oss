Install and remove

A. apk

Dependencies come along, signatures checked:

apk add sdl2-compat-dev
apk add sdl2-compat-dev=2.32.60-r0   # this version

apk del sdl2-compat-dev   # also drops dependencies nothing else needs

Package: sdl2-compat-dev-2.32.60-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sdl2-compat-dev
oss-get install sdl2-compat-dev=2.32.60-r0   # this version

oss-get remove sdl2-compat-dev   # its files only

Its dependencies stay installed: sdl2-compat. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/sdl2-compat-dev-2.32.60-r0.tar.gz
[ "$(openssl dgst -sha256 sdl2-compat-dev-2.32.60-r0.tar.gz | sed 's/.*= *//')" = 03dc729f47a557cd3a0eb19093c7d3e51418f7aafe4f203680bfa5a1378c57c9 ] && echo OK || echo BAD
gzip -dc sdl2-compat-dev-2.32.60-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sdl2-compat-dev.list
gzip -dc sdl2-compat-dev-2.32.60-r0.tar.gz | (cd /data/oss && tar -xf -) && rm sdl2-compat-dev-2.32.60-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sdl2-compat-dev.list
rm var/lib/manual/sdl2-compat-dev.list

Its dependencies stay installed: sdl2-compat. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is sdl2-compat). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
