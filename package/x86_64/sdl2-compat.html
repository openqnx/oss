B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update

oss-get install sdl2-compat=2.32.60-r0   # this version

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/sdl2-compat-2.32.60-r0.tar.gz
[ "$(openssl dgst -sha256 sdl2-compat-2.32.60-r0.tar.gz | sed 's/.*= *//')" = 9bbb9077a84f858d1707aaf637f8579cfbe86849d45f42bb2ae6edfe014273c2 ] && echo OK || echo BAD
gzip -dc sdl2-compat-2.32.60-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sdl2-compat.list
gzip -dc sdl2-compat-2.32.60-r0.tar.gz | (cd /data/oss && tar -xf -) && rm sdl2-compat-2.32.60-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sdl2-compat.list
rm var/lib/manual/sdl2-compat.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
