Install and remove

A. apk

Dependencies come along, signatures checked:

apk add sdl3
apk add sdl3=3.4.18-r0   # this version

apk del sdl3   # also drops dependencies nothing else needs

Package: sdl3-3.4.18-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install sdl3
oss-get install sdl3=3.4.18-r0   # this version

oss-get remove sdl3   # its files only

Its dependencies stay installed: libiconv, libx11, libxcursor, libxext, libxfixes, libxi, libxrandr, libxrender, libxscrnsaver, libxtst. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/sdl3-3.4.18-r0.tar.gz (1.2 MiB)
SHA-256
d84d8f3f5767450885bf2847f37f8889c990d27d0bf7da5d5381d98ce9c84004
Install first
libiconv, libxau, libxdmcp, libxcb, libx11, libxfixes, libxrender, libxcursor, libxext, libxi, libxrandr, libxscrnsaver, libxtst (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/sdl3-3.4.18-r0.tar.gz
[ "$(openssl dgst -sha256 sdl3-3.4.18-r0.tar.gz | sed 's/.*= *//')" = d84d8f3f5767450885bf2847f37f8889c990d27d0bf7da5d5381d98ce9c84004 ] && echo OK || echo BAD
gzip -dc sdl3-3.4.18-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/sdl3.list
gzip -dc sdl3-3.4.18-r0.tar.gz | (cd /data/oss && tar -xf -) && rm sdl3-3.4.18-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/sdl3.list
rm var/lib/manual/sdl3.list

Its dependencies stay installed: libiconv, libxau, libxdmcp, libxcb, libx11, libxfixes, libxrender, libxcursor, libxext, libxi, libxrandr, libxscrnsaver, libxtst. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
