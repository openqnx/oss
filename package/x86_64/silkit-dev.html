Install and remove

A. apk

Dependencies come along, signatures checked:

apk add silkit-dev
apk add silkit-dev=5.0.8-r0   # this version

apk del silkit-dev   # also drops dependencies nothing else needs

Package: silkit-dev-5.0.8-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install silkit-dev
oss-get install silkit-dev=5.0.8-r0   # this version

oss-get remove silkit-dev   # its files only

Its dependencies stay installed: silkit. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/silkit-dev-5.0.8-r0.tar.gz
[ "$(openssl dgst -sha256 silkit-dev-5.0.8-r0.tar.gz | sed 's/.*= *//')" = a469bebab877e5bf83b761c38d99f1acad6dd171494246405ff726c4f2783d07 ] && echo OK || echo BAD
gzip -dc silkit-dev-5.0.8-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/silkit-dev.list
gzip -dc silkit-dev-5.0.8-r0.tar.gz | (cd /data/oss && tar -xf -) && rm silkit-dev-5.0.8-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/silkit-dev.list
rm var/lib/manual/silkit-dev.list

Its dependencies stay installed: silkit. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is silkit). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
