B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install skalibs-dev
oss-get install skalibs-dev=2.14.5.1-r0   # this version

oss-get remove skalibs-dev   # its files only

Its dependencies stay installed: skalibs. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/skalibs-dev-2.14.5.1-r0.tar.gz
[ "$(openssl dgst -sha256 skalibs-dev-2.14.5.1-r0.tar.gz | sed 's/.*= *//')" = fdf4bf59facc7147264e8cddbf94e7b5df47e421de0b96ab4a0a49f9c17344c3 ] && echo OK || echo BAD
gzip -dc skalibs-dev-2.14.5.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/skalibs-dev.list
gzip -dc skalibs-dev-2.14.5.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm skalibs-dev-2.14.5.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/skalibs-dev.list
rm var/lib/manual/skalibs-dev.list

Its dependencies stay installed: skalibs. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is skalibs). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
