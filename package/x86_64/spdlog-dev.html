Install and remove

A. apk

Dependencies come along, signatures checked:

apk add spdlog-dev
apk add spdlog-dev=1.15.3-r0   # this version

apk del spdlog-dev   # also drops dependencies nothing else needs

Package: spdlog-dev-1.15.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install spdlog-dev
oss-get install spdlog-dev=1.15.3-r0   # this version

oss-get remove spdlog-dev   # its files only

Its dependencies stay installed: spdlog. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/spdlog-dev-1.15.3-r0.tar.gz
[ "$(openssl dgst -sha256 spdlog-dev-1.15.3-r0.tar.gz | sed 's/.*= *//')" = 82f4fb0de217353cf015f7fe43db78216746b829f0aca4c2bf9952356a5ee3fe ] && echo OK || echo BAD
gzip -dc spdlog-dev-1.15.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/spdlog-dev.list
gzip -dc spdlog-dev-1.15.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm spdlog-dev-1.15.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/spdlog-dev.list
rm var/lib/manual/spdlog-dev.list

Its dependencies stay installed: fmt, spdlog. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is spdlog). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
