apk add strongswan

Package: strongswan-6.0.6-r3.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install strongswan
oss-get install strongswan=6.0.6-r3   # this version

oss-get remove strongswan   # its files only

Its dependencies stay installed: openssl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/strongswan-6.0.6-r3.tar.gz (1.7 MiB)
SHA-256
1ed74adf108efb0313a6f19e9d4a98a4d3e9914faf506a5209de7b76f73f1c2c
Install first
openssl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/strongswan-6.0.6-r3.tar.gz
[ "$(openssl dgst -sha256 strongswan-6.0.6-r3.tar.gz | sed 's/.*= *//')" = 1ed74adf108efb0313a6f19e9d4a98a4d3e9914faf506a5209de7b76f73f1c2c ] && echo OK || echo BAD
gzip -dc strongswan-6.0.6-r3.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/strongswan.list
gzip -dc strongswan-6.0.6-r3.tar.gz | (cd /data/oss && tar -xf -) && rm strongswan-6.0.6-r3.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/strongswan.list
rm var/lib/manual/strongswan.list

Its dependencies stay installed: openssl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
