Install and remove

A. apk

Dependencies come along, signatures checked:

apk add swaybg
apk add swaybg=1.2.2-r1   # this version

apk del swaybg   # also drops dependencies nothing else needs

Package: swaybg-1.2.2-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install swaybg
oss-get install swaybg=1.2.2-r1   # this version

oss-get remove swaybg   # its files only

Its dependencies stay installed: cairo, gdk-pixbuf, glib, wayland. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/swaybg-1.2.2-r1.tar.gz
[ "$(openssl dgst -sha256 swaybg-1.2.2-r1.tar.gz | sed 's/.*= *//')" = 803bc443084c6df7a570008f5c50cb6c392942f00350efb3268230c959598b52 ] && echo OK || echo BAD
gzip -dc swaybg-1.2.2-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/swaybg.list
gzip -dc swaybg-1.2.2-r1.tar.gz | (cd /data/oss && tar -xf -) && rm swaybg-1.2.2-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/swaybg.list
rm var/lib/manual/swaybg.list

Its dependencies stay installed: expat, brotli, bzip2, zlib, libpng, freetype, fontconfig, libiconv, libunistring, ncurses, gettext, libffi, pcre2, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, wayland. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
