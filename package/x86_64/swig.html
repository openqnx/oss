Install and remove

A. apk

Dependencies come along, signatures checked:

apk add swig
apk add swig=4.3.1-r0   # this version

apk del swig   # also drops dependencies nothing else needs

Package: swig-4.3.1-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install swig
oss-get install swig=4.3.1-r0   # this version

oss-get remove swig   # its files only

Its dependencies stay installed: pcre2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/swig-4.3.1-r0.tar.gz
[ "$(openssl dgst -sha256 swig-4.3.1-r0.tar.gz | sed 's/.*= *//')" = e8945bec4c0fed3857a83991f4d2bebe9af1c616d777f813930984ba26e4604a ] && echo OK || echo BAD
gzip -dc swig-4.3.1-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/swig.list
gzip -dc swig-4.3.1-r0.tar.gz | (cd /data/oss && tar -xf -) && rm swig-4.3.1-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/swig.list
rm var/lib/manual/swig.list

Its dependencies stay installed: pcre2. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
