Install and remove

A. apk

apk add tensorflow-lite

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install tensorflow-lite
oss-get install tensorflow-lite=2.16.1-r1   # this version

oss-get remove tensorflow-lite   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/tensorflow-lite-2.16.1-r1.tar.gz
[ "$(openssl dgst -sha256 tensorflow-lite-2.16.1-r1.tar.gz | sed 's/.*= *//')" = f88ffb33bc84a4aa5296b805bcf124a4a60e65f97e154b35338f9fbca5fd391d ] && echo OK || echo BAD
gzip -dc tensorflow-lite-2.16.1-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tensorflow-lite.list
gzip -dc tensorflow-lite-2.16.1-r1.tar.gz | (cd /data/oss && tar -xf -) && rm tensorflow-lite-2.16.1-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tensorflow-lite.list
rm var/lib/manual/tensorflow-lite.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
