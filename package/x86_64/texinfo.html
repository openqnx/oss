Install and remove

A. apk

Dependencies come along, signatures checked:

apk add texinfo
apk add texinfo=7.2-r1   # this version

apk del texinfo   # also drops dependencies nothing else needs

Package: texinfo-7.2-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install texinfo
oss-get install texinfo=7.2-r1   # this version

oss-get remove texinfo   # its files only

Its dependencies stay installed: ncurses, perl. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/texinfo-7.2-r1.tar.gz (1.2 MiB)
SHA-256
cd2dd0c72f0ba2c29b82e81ccd7375e9e4d356d6ee09236d06f22893f614d2f6
Install first
ncurses, libxcrypt, perl (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/texinfo-7.2-r1.tar.gz
[ "$(openssl dgst -sha256 texinfo-7.2-r1.tar.gz | sed 's/.*= *//')" = cd2dd0c72f0ba2c29b82e81ccd7375e9e4d356d6ee09236d06f22893f614d2f6 ] && echo OK || echo BAD
gzip -dc texinfo-7.2-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/texinfo.list
gzip -dc texinfo-7.2-r1.tar.gz | (cd /data/oss && tar -xf -) && rm texinfo-7.2-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/texinfo.list
rm var/lib/manual/texinfo.list

Its dependencies stay installed: ncurses, libxcrypt, perl. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
