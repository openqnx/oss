Install and remove

A. apk

Dependencies come along, signatures checked:

apk add tumbler-dev
apk add tumbler-dev=4.20.0-r0   # this version

apk del tumbler-dev   # also drops dependencies nothing else needs

Package: tumbler-dev-4.20.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install tumbler-dev
oss-get install tumbler-dev=4.20.0-r0   # this version

oss-get remove tumbler-dev   # its files only

Its dependencies stay installed: tumbler. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/tumbler-dev-4.20.0-r0.tar.gz
[ "$(openssl dgst -sha256 tumbler-dev-4.20.0-r0.tar.gz | sed 's/.*= *//')" = 40e5fb9dde0bae228cfde3ddf0cbc5404708200e23901f815fa0b90f91e12f8c ] && echo OK || echo BAD
gzip -dc tumbler-dev-4.20.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tumbler-dev.list
gzip -dc tumbler-dev-4.20.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm tumbler-dev-4.20.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tumbler-dev.list
rm var/lib/manual/tumbler-dev.list

Its dependencies stay installed: brotli, c-ares, nghttp2, openssl, zlib, zstd, curl, bzip2, dav1d, lame, libogg, libtheora, libvorbis, libvpx, openh264, opus, x264, x265, libiconv, libunistring, ncurses, gettext, xz, ffmpeg, libjpeg-turbo, libpng, ffmpegthumbnailer, freetype, libffi, pcre2, glib, gdk-pixbuf, gstreamer, gst-plugins-base, libxml2, libgsf, libxfce4util, tumbler. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is tumbler). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
