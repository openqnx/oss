Install and remove

A. apk

Dependencies come along, signatures checked:

apk add tzdata
apk add tzdata=2026f-r0   # this version

apk del tzdata   # also drops dependencies nothing else needs

Package: tzdata-2026f-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install tzdata
oss-get install tzdata=2026f-r0   # this version

oss-get remove tzdata   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/tzdata-2026f-r0.tar.gz (299.2 KiB)
SHA-256
0b36f0cdedd2677866e91b8f95f29cd10b9457b80355a54638a43f28e8d83cb8
Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/tzdata-2026f-r0.tar.gz
[ "$(openssl dgst -sha256 tzdata-2026f-r0.tar.gz | sed 's/.*= *//')" = 0b36f0cdedd2677866e91b8f95f29cd10b9457b80355a54638a43f28e8d83cb8 ] && echo OK || echo BAD
gzip -dc tzdata-2026f-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/tzdata.list
gzip -dc tzdata-2026f-r0.tar.gz | (cd /data/oss && tar -xf -) && rm tzdata-2026f-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/tzdata.list
rm var/lib/manual/tzdata.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
