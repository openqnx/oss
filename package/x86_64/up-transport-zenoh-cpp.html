[ "$(openssl dgst -sha256 up-transport-zenoh-cpp-1.0.0_git20250319-r0.tar.gz | sed 's/.*= *//')" = d344e5f57fae2db9bd9201913fc440e3ee2447a1a671e9b9d773e786f2d05196 ] && echo OK || echo BAD
gzip -dc up-transport-zenoh-cpp-1.0.0_git20250319-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/up-transport-zenoh-cpp.list
gzip -dc up-transport-zenoh-cpp-1.0.0_git20250319-r0.tar.gz | (cd /data/oss && tar -xf -) && rm up-transport-zenoh-cpp-1.0.0_git20250319-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/up-transport-zenoh-cpp.list
rm var/lib/manual/up-transport-zenoh-cpp.list

Its dependencies stay installed: abseil, fmt, zlib, protobuf, spdlog, up-core-api, up-cpp, zenoh-c. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
