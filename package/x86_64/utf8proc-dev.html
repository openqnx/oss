Install and remove

A. apk

Dependencies come along, signatures checked:

apk add utf8proc-dev
apk add utf8proc-dev=2.11.3-r0   # this version

apk del utf8proc-dev   # also drops dependencies nothing else needs

Package: utf8proc-dev-2.11.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install utf8proc-dev
oss-get install utf8proc-dev=2.11.3-r0   # this version

oss-get remove utf8proc-dev   # its files only

Its dependencies stay installed: utf8proc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/utf8proc-dev-2.11.3-r0.tar.gz
[ "$(openssl dgst -sha256 utf8proc-dev-2.11.3-r0.tar.gz | sed 's/.*= *//')" = 2714b6560909a1edbc1fa46e3236241826857c814492cfa21f48bee29d248b1a ] && echo OK || echo BAD
gzip -dc utf8proc-dev-2.11.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/utf8proc-dev.list
gzip -dc utf8proc-dev-2.11.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm utf8proc-dev-2.11.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/utf8proc-dev.list
rm var/lib/manual/utf8proc-dev.list

Its dependencies stay installed: utf8proc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is utf8proc). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
