Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vala
apk add vala=0.56.18-r0   # this version

apk del vala   # also drops dependencies nothing else needs

Package: vala-0.56.18-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vala
oss-get install vala=0.56.18-r0   # this version

oss-get remove vala   # its files only

Its dependencies stay installed: gettext, glib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/vala-0.56.18-r0.tar.gz
[ "$(openssl dgst -sha256 vala-0.56.18-r0.tar.gz | sed 's/.*= *//')" = 98203694f517e789c8fc92d535c70f1009c6bfeb913051409bf5367d6a671c6d ] && echo OK || echo BAD
gzip -dc vala-0.56.18-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vala.list
gzip -dc vala-0.56.18-r0.tar.gz | (cd /data/oss && tar -xf -) && rm vala-0.56.18-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vala.list
rm var/lib/manual/vala.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
