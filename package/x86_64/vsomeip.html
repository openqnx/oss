Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vsomeip
apk add vsomeip=3.5.6-r1   # this version

apk del vsomeip   # also drops dependencies nothing else needs

Package: vsomeip-3.5.6-r1.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vsomeip
oss-get install vsomeip=3.5.6-r1   # this version

oss-get remove vsomeip   # its files only

Its dependencies stay installed: boost. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/vsomeip-3.5.6-r1.tar.gz (34.8 MiB)
SHA-256
f2ca4f48e1ab6fee2b7fca4d1571a661cca3639e46edd2b050b057e5041d1c3f
Install first
bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/vsomeip-3.5.6-r1.tar.gz
[ "$(openssl dgst -sha256 vsomeip-3.5.6-r1.tar.gz | sed 's/.*= *//')" = f2ca4f48e1ab6fee2b7fca4d1571a661cca3639e46edd2b050b057e5041d1c3f ] && echo OK || echo BAD
gzip -dc vsomeip-3.5.6-r1.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vsomeip.list
gzip -dc vsomeip-3.5.6-r1.tar.gz | (cd /data/oss && tar -xf -) && rm vsomeip-3.5.6-r1.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vsomeip.list
rm var/lib/manual/vsomeip.list

Its dependencies stay installed: bzip2, libiconv, libunistring, ncurses, gettext, xz, zlib, boost. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
