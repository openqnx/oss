Install and remove

A. apk

Dependencies come along, signatures checked:

apk add vte
apk add vte=0.78.2-r2   # this version

apk del vte   # also drops dependencies nothing else needs

Package: vte-0.78.2-r2.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install vte
oss-get install vte=0.78.2-r2   # this version

oss-get remove vte   # its files only

Its dependencies stay installed: at-spi2-core, cairo, fribidi, gdk-pixbuf, gettext, glib, gnutls, graphene, gtk3, gtk4, icu, lz4, pango, pcre2. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/vte-0.78.2-r2.tar.gz
[ "$(openssl dgst -sha256 vte-0.78.2-r2.tar.gz | sed 's/.*= *//')" = 9bee0ba4330ea708cd4d0d52728b0e81b0be7e0594d476064127c554a80890ee ] && echo OK || echo BAD
gzip -dc vte-0.78.2-r2.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/vte.list
gzip -dc vte-0.78.2-r2.tar.gz | (cd /data/oss && tar -xf -) && rm vte-0.78.2-r2.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/vte.list
rm var/lib/manual/vte.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, fribidi, libjpeg-turbo, gdk-pixbuf, gmp, libidn2, libtasn1, nettle, zstd, gnutls, graphene, graphite2, icu, harfbuzz, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, libxft, pango, wayland, gtk3, libwebp, libtiff, gtk4, lz4. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
