Install and remove

A. apk

Dependencies come along, signatures checked:

apk add wayland-protocols

apk del wayland-protocols   # also drops dependencies nothing else needs

Package: wayland-protocols-1.47-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install wayland-protocols
oss-get install wayland-protocols=1.47-r0   # this version

oss-get remove wayland-protocols   # its files only

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/wayland-protocols-1.47-r0.tar.gz
[ "$(openssl dgst -sha256 wayland-protocols-1.47-r0.tar.gz | sed 's/.*= *//')" = 1265cd59f4d8f78b0f6c7db1f6297451666585ffcbda8561956b04fdff8debed ] && echo OK || echo BAD
gzip -dc wayland-protocols-1.47-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/wayland-protocols.list
gzip -dc wayland-protocols-1.47-r0.tar.gz | (cd /data/oss && tar -xf -) && rm wayland-protocols-1.47-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/wayland-protocols.list
rm var/lib/manual/wayland-protocols.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
