Install and remove

A. apk

Dependencies come along, signatures checked:

apk add webkitgtk
apk add webkitgtk=2.44.4-r0   # this version

apk del webkitgtk   # also drops dependencies nothing else needs

Package: webkitgtk-2.44.4-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install webkitgtk
oss-get install webkitgtk=2.44.4-r0   # this version

oss-get remove webkitgtk   # its files only

Its dependencies stay installed: at-spi2-core, cairo, fontconfig, freetype, gdk-pixbuf, gettext, glib, gst-plugins-bad, gst-plugins-base, gstreamer, gtk3, harfbuzz, hyphen, icu, lcms2, libavif, libepoxy, libgcrypt, libgpg-error, libjpeg-turbo, libjxl, libpng, libsecret, libsoup, libtasn1, libwebp, libxml2, libxslt, pango, sqlite, woff2, zlib. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/webkitgtk-2.44.4-r0.tar.gz
[ "$(openssl dgst -sha256 webkitgtk-2.44.4-r0.tar.gz | sed 's/.*= *//')" = 01afebc559409749c77a32057c22f2db8571929aa54d39134618d171ff0827d8 ] && echo OK || echo BAD
gzip -dc webkitgtk-2.44.4-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/webkitgtk.list
gzip -dc webkitgtk-2.44.4-r0.tar.gz | (cd /data/oss && tar -xf -) && rm webkitgtk-2.44.4-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/webkitgtk.list
rm var/lib/manual/webkitgtk.list

Its dependencies stay installed: expat, dbus, libiconv, libunistring, ncurses, gettext, libffi, pcre2, zlib, glib, libxau, libxdmcp, libxcb, libx11, libxext, libxi, libxtst, at-spi2-core, brotli, bzip2, libpng, freetype, fontconfig, libxrender, lzo, pixman, cairo, libjpeg-turbo, gdk-pixbuf, aom, fdk-aac, gstreamer, libogg, libtheora, libvorbis, opus, gst-plugins-base, libwebp, openh264, fribidi, graphite2, icu, harfbuzz, libxft, pango, svt-av1, x265, gst-plugins-bad, libepoxy, libxcomposite, libxfixes, libxcursor, libxdamage, libxinerama, xz, libxml2, libxkbcommon, libxrandr, wayland, gtk3, hyphen, lcms2, dav1d, libavif, libgpg-error, libgcrypt, highway, libjxl, libsecret, libidn2, libpsl, nghttp2, sqlite, libsoup, libtasn1, libxslt, woff2. For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
