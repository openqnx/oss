Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xkeyboard-config
apk add xkeyboard-config=2.43-r0   # this version

apk del xkeyboard-config   # also drops dependencies nothing else needs

Package: xkeyboard-config-2.43-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xkeyboard-config
oss-get install xkeyboard-config=2.43-r0   # this version

oss-get remove xkeyboard-config   # its files only

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xkeyboard-config-2.43-r0.tar.gz (1.6 MiB)
SHA-256

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xkeyboard-config-2.43-r0.tar.gz
[ "$(openssl dgst -sha256 xkeyboard-config-2.43-r0.tar.gz | sed 's/.*= *//')" = e59ec12c10bc3fd383e3451ab537c61ebbe49a3bc46867ff157e7ec2182456dd ] && echo OK || echo BAD
gzip -dc xkeyboard-config-2.43-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xkeyboard-config.list
gzip -dc xkeyboard-config-2.43-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xkeyboard-config-2.43-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xkeyboard-config.list
rm var/lib/manual/xkeyboard-config.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
