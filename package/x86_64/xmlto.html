Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xmlto
apk add xmlto=0.0.29-r0   # this version

apk del xmlto   # also drops dependencies nothing else needs

Package: xmlto-0.0.29-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xmlto
oss-get install xmlto=0.0.29-r0   # this version

oss-get remove xmlto   # its files only

Its dependencies stay installed: bash, busybox, docbook-xsl, libxml2-utils, xsltproc. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xmlto-0.0.29-r0.tar.gz (23.6 KiB)
SHA-256
bb65745d24a014960004e34026b0b4553fb0241b1bc2eed0b4e19c6f198b7166
Install first
libiconv, ncurses, readline, bash, busybox, libunistring, gettext, xz, zlib, libxml2, libxslt, docbook-xsl, libxml2-utils, xsltproc (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xmlto-0.0.29-r0.tar.gz
[ "$(openssl dgst -sha256 xmlto-0.0.29-r0.tar.gz | sed 's/.*= *//')" = bb65745d24a014960004e34026b0b4553fb0241b1bc2eed0b4e19c6f198b7166 ] && echo OK || echo BAD
gzip -dc xmlto-0.0.29-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xmlto.list
gzip -dc xmlto-0.0.29-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xmlto-0.0.29-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xmlto.list
rm var/lib/manual/xmlto.list

Its dependencies stay installed: libiconv, ncurses, readline, bash, busybox, libunistring, gettext, xz, zlib, libxml2, libxslt, docbook-xsl, libxml2-utils, xsltproc. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
