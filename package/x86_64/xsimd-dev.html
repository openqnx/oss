Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xsimd-dev
apk add xsimd-dev=14.3.0-r0   # this version

apk del xsimd-dev   # also drops dependencies nothing else needs

Package: xsimd-dev-14.3.0-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xsimd-dev
oss-get install xsimd-dev=14.3.0-r0   # this version

oss-get remove xsimd-dev   # its files only

Install first
nothing

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xsimd-dev-14.3.0-r0.tar.gz
[ "$(openssl dgst -sha256 xsimd-dev-14.3.0-r0.tar.gz | sed 's/.*= *//')" = bf26eccc94200fd3c9b37e00b811327f59f1301ffe66af13277ac94b6170de5e ] && echo OK || echo BAD
gzip -dc xsimd-dev-14.3.0-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xsimd-dev.list
gzip -dc xsimd-dev-14.3.0-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xsimd-dev-14.3.0-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xsimd-dev.list
rm var/lib/manual/xsimd-dev.list

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (here the whole component: it has no run-time package). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
