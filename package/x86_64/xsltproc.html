Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xsltproc
apk add xsltproc=1.1.42-r0   # this version

apk del xsltproc   # also drops dependencies nothing else needs

Package: xsltproc-1.1.42-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xsltproc
oss-get install xsltproc=1.1.42-r0   # this version

oss-get remove xsltproc   # its files only

Its dependencies stay installed: libxml2, libxslt. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

SHA-256

Install first
libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xsltproc-1.1.42-r0.tar.gz
[ "$(openssl dgst -sha256 xsltproc-1.1.42-r0.tar.gz | sed 's/.*= *//')" = 717653a6144ccd0b787dd326709121bc43c8eda0f944c0527165b5b43f5bf404 ] && echo OK || echo BAD
gzip -dc xsltproc-1.1.42-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xsltproc.list
gzip -dc xsltproc-1.1.42-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xsltproc-1.1.42-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xsltproc.list
rm var/lib/manual/xsltproc.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext, xz, zlib, libxml2, libxslt. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
