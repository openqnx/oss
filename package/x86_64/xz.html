Install and remove

A. apk

Dependencies come along, signatures checked:

apk add xz
apk add xz=5.6.3-r0   # this version

apk del xz   # also drops dependencies nothing else needs

Package: xz-5.6.3-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install xz
oss-get install xz=5.6.3-r0   # this version

oss-get remove xz   # its files only

Its dependencies stay installed: gettext. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xz-5.6.3-r0.tar.gz (328.0 KiB)
SHA-256
225d53a2d99a38158a663d48295123d37db1dc0021c25c88979e37bdabf2bd31
Install first
libiconv, libunistring, ncurses, gettext (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/xz-5.6.3-r0.tar.gz
[ "$(openssl dgst -sha256 xz-5.6.3-r0.tar.gz | sed 's/.*= *//')" = 225d53a2d99a38158a663d48295123d37db1dc0021c25c88979e37bdabf2bd31 ] && echo OK || echo BAD
gzip -dc xz-5.6.3-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/xz.list
gzip -dc xz-5.6.3-r0.tar.gz | (cd /data/oss && tar -xf -) && rm xz-5.6.3-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/xz.list
rm var/lib/manual/xz.list

Its dependencies stay installed: libiconv, libunistring, ncurses, gettext. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs. Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
