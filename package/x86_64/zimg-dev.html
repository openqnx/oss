Install and remove

A. apk

Dependencies come along, signatures checked:

apk add zimg-dev
apk add zimg-dev=3.0.5-r0   # this version

apk del zimg-dev   # also drops dependencies nothing else needs

Package: zimg-dev-3.0.5-r0.apk. Setting up apk: INSTALL.md 2A.

B-1. oss-get

No apk: target/oss-get downloads, checks the SHA-256, installs the dependencies first and keeps a file list per package:

oss-get update
oss-get install zimg-dev
oss-get install zimg-dev=3.0.5-r0   # this version

oss-get remove zimg-dev   # its files only

Its dependencies stay installed: zimg. Remove them too (oss-get remove <dep>) if nothing else needs them; oss-get refuses a package another installed one still needs.

B-2. By hand

Archive
https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/zimg-dev-3.0.5-r0.tar.gz (34.8 KiB)
SHA-256

Install first
zimg (in this order, each from its own page the same way; skip any already installed)

Install: download, check, save the file list, unpack under /data/oss:

mkdir -p /data/oss/dl /data/oss/var/lib/manual && cd /data/oss/dl
curl -fsSLO https://github.com/openqnx/oss/releases/download/packages-8.0-x86_64-m-z/zimg-dev-3.0.5-r0.tar.gz
[ "$(openssl dgst -sha256 zimg-dev-3.0.5-r0.tar.gz | sed 's/.*= *//')" = da8d7d9e0c26f0340a8ddbb1b4a6680fb92fad293416e1167a8b6e3913f408d9 ] && echo OK || echo BAD
gzip -dc zimg-dev-3.0.5-r0.tar.gz | tar -tf - | grep -v '/$' > /data/oss/var/lib/manual/zimg-dev.list
gzip -dc zimg-dev-3.0.5-r0.tar.gz | (cd /data/oss && tar -xf -) && rm zimg-dev-3.0.5-r0.tar.gz

Remove: delete exactly the files it installed, then the list:

cd /data/oss && while read -r f; do rm -f "$f"; done < var/lib/manual/zimg-dev.list
rm var/lib/manual/zimg-dev.list

Its dependencies stay installed: zimg. Remove each the same way, from its own page, if nothing else needs it.

For a root shell on the target (QNX sh and the stock curl, openssl, gzip, tar; https needs SSL_CERT_FILE, see INSTALL.md). Empty directories stay. Don't remove a dependency another installed package still needs; a -dev package holds headers, pkg-config/CMake files and static libraries only (the run-time part is zimg). Use one method per /data/oss: apk and oss-get do not know about files unpacked by hand.
