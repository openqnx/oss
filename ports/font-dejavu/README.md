## Build it from upstream

Every step below can be run by hand. `./scripts/qnxbuild font-dejavu` performs exactly the same steps (2–5) in one command.

### 1. Build environment

A Linux host with QNX SDP 8.0 installed and licensed — or the container in [`docker/`](../../docs/build-environment.md), which needs only the SDP mounted. Then, from the repository root:

```bash
export QNX_SDP_ROOT=$HOME/qnx800      # your SDP 8.0 installation
./scripts/build-host-tools.sh          # once per machine
source ./env.sh aarch64le              # or x86_64; once per shell
```

`env.sh` sets up the cross compiler (`qcc`/`q++`), the staging tree `stage/<arch>/usr/local` (= `/usr/local` on the target), pkg-config, and the CMake/Meson toolchain files.

No other component has to be built first.

### 2. Get the upstream source

```bash
URL=https://github.com/dejavu-fonts/dejavu-fonts/releases/download/version_2_37/dejavu-fonts-ttf-2.37.tar.bz2
mkdir -p dist src/font-dejavu
curl -fL -o dist/$(basename $URL) $URL
echo "fa9ca4d13871dd122f61258a80d01751d603b4d3ee14095d65453b4e846e17d7  dist/$(basename $URL)" | sha256sum -c -
tar xf dist/$(basename $URL) -C src/font-dejavu --strip-components=1
```

### 3. Apply the QNX patches

None — the upstream source builds for QNX unmodified; everything QNX-specific is in the configuration below and in the shared toolchain files.

### 4. Configure, build and install into the staging tree

This component uses its own build steps (`do_build`, `do_install`), run with `S` = the source tree, `B` = the build directory:

```bash
S=src/font-dejavu; B=build/$QNX_ARCH/font-dejavu; mkdir -p $B
```

```bash

```

```bash

```

- DejaVu fonts. Font files only. Version as in the QNX Everywhere 8.0.4r1 image.

Or all of steps 2–4 at once: `./scripts/qnxbuild -a $QNX_ARCH font-dejavu`.

### 5. What it installs

The complete list is `stage/<arch>/.manifest/font-dejavu` after a build.

### 6. Package it for the target

```bash
./scripts/qnxpkg -a $QNX_ARCH font-dejavu
ls repo/8.0/*/ | grep '^font-dejavu-'
```

This writes `font-dejavu-<ver>-r0.tar.gz` (run time) and `font-dejavu-dev-<ver>-r0.tar.gz` (headers, pkg-config, CMake files, static libraries), the matching `.apk` files, and updates the repository index. The run-time dependencies recorded in the package are computed from the binaries.

## Run it on a target

Either install from your own repository (serve `repo/8.0/` with any web server):

```sh
# on the target
export OSS_REPO=http://<build-host>:8000
oss-get update && oss-get install font-dejavu
```

or copy the tarball and unpack it yourself:

```bash
scp repo/8.0/aarch64/font-dejavu-*-r0.tar.gz root@<target>:/data/
ssh root@<target> 'cd /data/oss && tar xzf /data/font-dejavu-*-r0.tar.gz'
```

QNX has no `ld.so.conf`; make the libraries findable with `export LD_LIBRARY_PATH=/usr/local/lib` (with `oss-get link`) or `eval $(oss-get env)`.
