## Build it from upstream

Every step below can be run by hand. `./scripts/qnxbuild open-amp` performs exactly the same steps (2–5) in one command.

### 1. Build environment

A Linux host with QNX SDP 8.0 installed and licensed — or the container in [`docker/`](../../docs/build-environment.md), which needs only the SDP mounted. Then, from the repository root:

```bash
export QNX_SDP_ROOT=$HOME/qnx800      # your SDP 8.0 installation
./scripts/build-host-tools.sh          # once per machine
source ./env.sh aarch64le              # or x86_64; once per shell
```

`env.sh` sets up the cross compiler (`qcc`/`q++`), the staging tree `stage/<arch>/usr/local` (= `/usr/local` on the target), pkg-config, and the CMake/Meson toolchain files.

**Build the dependencies first** (1 component(s)), or let `qnxbuild` do it:

```bash
./scripts/qnxbuild libmetal
```

### 2. Get the upstream source

```bash
git clone --depth 1 -b v2024.10.0 --recurse-submodules --shallow-submodules \
    https://github.com/OpenAMP/open-amp.git src/open-amp
```

### 3. Apply the QNX patches

None — the upstream source builds for QNX unmodified; everything QNX-specific is in the configuration below and in the shared toolchain files.

### 4. Configure, build and install into the staging tree

```bash
cmake -S src/open-amp -B build/$QNX_ARCH/open-amp -G Ninja \
      -DCMAKE_TOOLCHAIN_FILE=$PWD/toolchain/qnx-$QNX_ARCH.cmake \
      -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr/local \
      -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DBUILD_TESTING=OFF \
      -DWITH_APPS=OFF \
      -DWITH_PROXY=OFF
cmake --build build/$QNX_ARCH/open-amp -j$(nproc)
DESTDIR=$STAGE cmake --install build/$QNX_ARCH/open-amp
```

Why the configuration looks like this (from [`recipe.sh`](recipe.sh)):

- qnx-ports/open-amp's qnx-v2024.10.0 branch is identical to upstream v2024.10.0: it builds for QNX unmodified.

Or all of steps 2–4 at once: `./scripts/qnxbuild -a $QNX_ARCH open-amp`.

### 5. What it installs

16 files under `/usr/local`, 15 headers.

The complete list is `stage/<arch>/.manifest/open-amp` after a build.

### 6. Package it for the target

```bash
./scripts/qnxpkg -a $QNX_ARCH open-amp
ls repo/8.0/*/ | grep '^open-amp-'
```

This writes `open-amp-<ver>-r0.tar.gz` (run time) and `open-amp-dev-<ver>-r0.tar.gz` (headers, pkg-config, CMake files, static libraries), the matching `.apk` files, and updates the repository index. The run-time dependencies recorded in the package are computed from the binaries.

## Run it on a target

Either install from your own repository (serve `repo/8.0/` with any web server):

```sh
# on the target
export OSS_REPO=http://<build-host>:8000
oss-get update && oss-get install open-amp
```

or copy the tarball and unpack it yourself:

```bash
scp repo/8.0/aarch64/open-amp-*-r0.tar.gz root@<target>:/data/
ssh root@<target> 'cd /data/oss && tar xzf /data/open-amp-*-r0.tar.gz'
```

QNX has no `ld.so.conf`; make the libraries findable with `export LD_LIBRARY_PATH=/usr/local/lib` (with `oss-get link`) or `eval $(oss-get env)`.
